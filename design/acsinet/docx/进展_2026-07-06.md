# ACSI-Net 实现进展 2026-07-06

## 已完成

- 新建 `acsinet` 独立实现包，作为 Design 5 ACSI-Net 的 IXI-T2 x4 主线实验入口。
- 实现 group prediction 数据流：输入 `S0/S4` anchor、全部 linear coarse slices、phase maps、`D=S4-S0`、`A=abs(S4-S0)`，一次输出中间 slice group。
- 实现 `ACSINet2p5D`：
  - anchor/coarse/phase/difference 多分支编码；
  - anatomy block 局部结构建模；
  - group residual decoder；
  - 轻量 `Conv3D` z-context refinement。
- 实现 anatomy consistency loss：
  - reconstruction / Charbonnier；
  - xy gradient；
  - z-gradient；
  - z-Laplacian；
  - edge-z continuity；
  - anatomy weighted L1；
  - residual regularization。
- 实现 3D consistency 评价：
  - `ZGE`；
  - `ZLE`；
  - `EdgeZ`；
  - inter-slice NCC MAE。
- 接入本仓库现有 IXI-T2 数据准备、linear/cubic baseline、常规 metrics、intensity sanity 和 paper table 风格。
- 增加 `smoke` / `mini` / `full_test115` / `full_test115_x2` / `full_test115_x6` profiles。

## 重要实现修正

- `Conv3D` z-refinement 与模型级 `channels_last` 不兼容，已移除模型级 `channels_last` 转换。
- `GradScaler` 在异常梯度跳过时需要 `update()`，已修复。
- smoke profile 已降为 `target_shape=(128, 128)` 且 `window_step=16`，用于快速连通性验证。
- mini profile 使用 `window_step=2`，用于更实际的短跑筛查。
