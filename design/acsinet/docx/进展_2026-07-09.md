# ACSI-Net 进展 2026-07-09

## 本轮定位

用户已经完成 `full_test115`，因此本轮不再把 ACSI-Net 当成“低训练成本想法”继续空跑，而是从论文故事讲述和实验设计两个核心问题重新组织结果。

当前最稳的论文叙事是：

- ACSI-Net 不是 IXI-T2 x4 上的整体重建 SOTA，因为 I3Net 在 PSNR/SSIM 上仍然更强。
- ACSI-Net 的价值应放在 anatomy-consistent volume recovery：通过 group intermediate-slice prediction、phase/coarse guidance 和 z 向一致性约束，减少 through-plane 插值里的 3D 解剖不连续。
- 因此主张应是“在保持强竞争力的重建质量同时，显著改善 z 向结构连续性”，而不是泛化地宣称“所有指标第一”。

## 先澄清：少训练不等于不训练

之前说 ACSI-Net “不怎么需要训练”，准确含义是：这个方向的主要风险不是无限堆大模型或刷 epoch，而是要证明 through-plane MRI interpolation 需要 3D anatomy consistency 这一套评价和设计。它仍然需要一次完整主模型训练来证明方法可用；用户已经完成的 `full_test115` 正好补上了这一步。

因此现在的策略应改成：

1. 主模型 full 已经有了，不再盲目继续训练同一个配置。
2. 接下来优先补实验设计证据：跨 neural baseline 的 3D consistency、sagittal/coronal visual QC、机制消融。
3. 后续训练只做 targeted ablation 或外部验证，不做没有问题意识的重复 full。

这也是为什么 ACSI-Net 不能只讲“训练成本低”。真正卖点应该是：用相对轻量的 2.5D group model，把任务从单 slice fidelity 推到 3D volume coherence。

## 论文主线

建议论文暂定主题：

```text
Anatomy-Consistent Slice Interpolation for Through-Plane MRI Reconstruction
```

核心问题：

```text
现有 through-plane interpolation 往往按 2D slice fidelity 评价，但医学影像最终使用的是 3D volume。
PSNR/SSIM 高不一定代表 sagittal/coronal reformat 里结构连续。
```

核心假设：

1. x4 through-plane interpolation 不应该独立预测单张中间 slice，而应一次恢复中间 slice group。
2. 线性 coarse slices 提供稳定低频位置先验，网络主要学习 anatomy-aware residual。
3. phase maps 让模型知道每张中间 slice 在 S0 和 S4 之间的位置。
4. z-gradient、z-Laplacian、edge-z losses 可以直接约束 3D 解剖连续性。
5. sagittal/coronal visual QC 比 axial 单切片更能暴露 through-plane 断裂。

一句话 claim：

```text
ACSI-Net recovers anatomically coherent dense MRI volumes by jointly predicting intermediate slice groups and explicitly regularizing z-axis structural continuity.
```

需要避免的 claim：

```text
ACSI-Net is the universal reconstruction SOTA on IXI-T2 x4.
```

原因：当前 I3Net 在 IXI full_test115 的 PSNR/SSIM 仍然明显更强。

## 不是只超过 linear/cubic

linear/cubic 是 floor baseline，只能说明 ACSI-Net 不是无效模型，不能单独支撑论文。当前结果里真正有价值的是三层关系：

1. 对 linear/cubic：必须全面赢。当前 full_test115 已经做到 reconstruction metrics 115/115 全胜，3D consistency 也几乎全胜。
2. 对 HAT、SMamba-UNet、SwinIR 等 strong baseline：ACSI-Net 至少要有竞争力。当前 reconstruction summary 里 ACSI-Net PSNR 29.3904，略高于 SMamba-UNet 29.3536，也高于 HAT、SwinIR、ACVTT、ARSSR、CycleINR 的已有 full/full_test115 结果。
3. 对 I3Net：不硬拼 PSNR，而是把 I3Net 作为 reconstruction upper baseline。ACSI-Net 必须在 3D consistency 或 visual QC 上拿出不同维度的证据，否则不能作为主论文方法。

所以当前判定是：

```text
ACSI-Net 已经不是“只赢 linear/cubic”的弱结果；
但它还没有完成“相对 I3Net/强 neural baseline 的 3D anatomy consistency 证明”。
```

### 输入设计

x4 时输入通道顺序为：

```text
[S0, S4, C1, C2, C3, P1, P2, P3, D, A]
```

含义：

- `S0, S4`：两端 sparse anchor slices。
- `C1, C2, C3`：linear coarse intermediate slices，提供稳定初始形状。
- `P1, P2, P3`：phase maps，对应 0.25、0.50、0.75 的相对位置。
- `D = S4 - S0`：方向变化。
- `A = abs(S4 - S0)`：变化强度，用于结构区域提示。

这套输入使模型不是从零生成中间层，而是在 coarse interpolation 上学习解剖一致的 residual。

### 网络结构

`ACSINet2p5D` 当前实现为轻量 2.5D group model：

1. `anchor_encoder` 编码两端 anchor。
2. `coarse_encoder` 编码三张 linear coarse slices。
3. `phase_encoder` 编码 phase maps。
4. `diff_encoder` 编码 `D` 和 `A`。
5. `fuse + AnatomyBlock` 融合局部结构、通道注意力和轻量 residual 表达。
6. `decoder` 一次输出全部中间 slices 的 residual 和 confidence。
7. `z_refine` 把 `[S0, Y1, Y2, Y3, S4]` 作为一个短 stack，用浅层 `Conv3D` 做 z-context refinement。

当前输出形式：

```text
coarse_prediction = coarse + confidence * residual_scale * residual
stack = [S0, coarse_prediction, S4]
prediction = z_refine(stack)[1:-1]
```

这对应论文里的 group prediction + shallow z-context refinement。

### 损失函数

`acsinet/losses.py` 里当前总损失为：

```text
L_total =
    Charbonnier(pred, target)
  + 0.05 * gradient_xy
  + 0.05 * z_gradient
  + 0.02 * z_laplacian
  + 0.05 * edge_z
  + 0.05 * anatomy_weighted_l1
  + 0.001 * residual_regularization
```

各项对应论文含义：

- `Charbonnier`：主 reconstruction fidelity。
- `gradient_xy`：保持 slice 内边缘。
- `z_gradient`：约束相邻 slice 的一阶 z 向变化。
- `z_laplacian`：约束二阶 z 向曲率，减少突然跳变。
- `edge_z`：约束边缘结构沿 z 轴连续。
- `anatomy_weighted_l1`：在 coarse edge 和 anchor difference 高的结构变化区域加权。
- `residual_regularization`：限制 residual 过大，避免偏离 coarse prior。

## 下一步具体实现

短期优先级：

1. 暂停“ACSI-v1 强 claim”。v1 只能说 lightweight competitive reconstruction，不能说 anatomy consistency 超过 I3Net。
2. 先做 failure diagnosis：找出 ACSI-Net 相比 I3Net 在 ZGE/ZLE/EdgeZ/NCC-z-MAE 上差距最大的病例，生成 sagittal/coronal 对比图和 z-profile。
3. 如果继续推进主方法，应做 ACSI-v2，而不是继续微调 v1。核心改动是从 pairwise `[S0,S4] -> [S1,S2,S3]` 升级为 I3Net 同等上下文的 lightweight multi-anchor group interpolation，例如 4 sparse anchors -> 13 HR window。
4. ACSI-v2 仍保持轻量，但必须使用更长 z-context，否则很难在 anatomy consistency 上打过 I3Net。
5. ACSI-v2 成功标准：参数量和 FLOPs 仍显著低于 I3Net，同时 ZGE/ZLE/EdgeZ/NCC-z-MAE 至少 3/4 指标均值优于 I3Net，且 per-case win rate 不低于 60%。
6. 如果 ACSI-v2 仍无法超过 I3Net 的 3D consistency，则把 ACSI 降级为 analysis / ablation / appendix direction，主线应回到 I3Net 或其他更强架构。

## 当前结论

ACSI-Net 已经从“低成本候选方向”升级为可以认真评估的论文方法候选。它不应该被讲成“只超过 linear/cubic 的方法”，因为当前 reconstruction 排名已经接近强 baseline，并且略高于 SMamba-UNet。但它也不能被讲成“轻量且比 I3Net 更解剖一致的方法”，因为 ACSI-vs-I3 审计显示 v1 在四个 3D consistency 指标上都输给 I3Net。

最合适的论文定位是：

```text
ACSI-Net is a lightweight anatomy-consistent group interpolation model that trades the usual single-slice reconstruction framing for volume-level z-axis coherence.
```

接下来成败取决于一个更严格的问题：

```text
能否做出 ACSI-v2：在保持明显轻量的前提下，用更长 z-context 和 group-volume consistency 正面超过 I3Net 的 anatomy consistency。
```

如果可以，ACSI-Net 可以作为主论文方法推进；如果不可以，它就应降级为一个有价值但不够强的分析型设计。
