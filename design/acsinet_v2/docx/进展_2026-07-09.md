# ACSI-v2 进展_2026-07-09

## 1. 为什么继续做 ACSI-v2

ACSI-v1 没有白费。v1 已经验证了一个重要事实：把方法定义成“轻量、显式解剖一致性约束、低训练成本”的插值组件是可实现的，而且复杂度明显低于 I3Net。但 v1 的 full_test115 结果也暴露了问题：它虽然轻量，但在 3D consistency 指标上没有超过 I3Net，因此不能把论文主 claim 写成“解剖一致性更强”。

ACSI-v2 的目标不是简单堆模型，而是把 v1 的故事补完整：

- 从二端点 `[S0, S4] -> S1/S2/S3` 扩展到 I3Net 更接近的窗口设定：4 个稀疏 anchor slice 生成 13 个高分辨率 slice。
- 保留 ACSI 的核心立场：先构造线性 coarse anatomy，再学习轻量 residual，而不是让网络从零生成结构。
- 显式保留 anchor 位置，使输出窗口在已观测 slice 上不漂移。
- 把 z-gradient、z-laplacian、edge-z、NCC-z 这类 3D 一致性指标作为主实验对象，而不是只比 PSNR/SSIM。

因此 ACSI-v2 的论文故事可以从“另一个 SOTA 网络”转为：

> ACSI-v2 is a lightweight anatomy-consistent interpolation component that preserves observed slices, learns residual corrections over an explicit coarse anatomical prior, and targets through-plane consistency rather than only per-slice reconstruction fidelity.

这条线仍然成立，但前提是后续实验至少要证明它在轻量性上明显优于 I3Net，并且在 3D consistency 上至少优于 linear/cubic，最好接近或超过 I3Net。

### 2.1 数据窗口

ACSI-v2 使用 I3Net 风格的窗口：

- 稀疏输入 anchor 数：4
- x4 插值时，HR window 长度：13
- anchor 位置：`0, 4, 8, 12`
- 生成位置：除 anchor 之外的 9 个中间 slice

条件输入通道由以下部分组成：

- 4 个 anchor slice
- 13 个 linear coarse slice
- 13 个 z-phase map
- 3 个相邻 anchor difference map
- 3 个相邻 anchor absolute difference map

总通道数为 36。

### 2.2 模型结构

`ACSINetV2` 的核心结构：

- anchor encoder：提取稀疏观测结构。
- coarse encoder：提取线性解剖先验。
- phase encoder：显式建模 z 位置。
- diff encoder：建模相邻 anchor 间变化。
- residual decoder：预测 13-slice residual 和 confidence。
- shallow 3D refinement：用很浅的 Conv3D 做 z 方向局部平滑。
- anchor preservation：强制 anchor 位置输出等于 coarse/observed slice。

为了避免小训练量下破坏 linear coarse，最后 residual 层和 z-refine 层做了零初始化。这样模型初始状态等价于 linear/coarse，训练只学习必要修正。

### 2.3 损失函数

`acsi_v2_loss` 包含：

- generated-slice masked Charbonnier reconstruction loss
- generated-slice masked xy gradient loss
- full-window z-gradient loss
- full-window z-laplacian loss
- edge-z loss
- anatomy-weighted reconstruction loss
- residual regularization

注意：anchor slice 不参与重建误差主项，但参与 z 方向一致性约束。

## 4. 当前论文判断

ACSI-v2 可以继续做，因为它已经把 v1 的关键缺口补了一半：

- 窗口设定更接近 I3Net，比较更公平。
- 复杂度极低，轻量性非常明确。
- 小训练量下 reconstruction 已经略优于 linear/cubic。

但现在不能直接写成：

> ACSI-v2 outperforms SOTA in anatomy consistency.

目前更诚实的写法应是：

> ACSI-v2 provides a lightweight anatomy-preserving residual interpolation component. It matches or improves interpolation baselines under limited training while using far fewer parameters and FLOPs than heavy CNN baselines. The central experimental question is whether explicit z-consistency optimization can turn this lightweight component into a robust anatomy-consistency enhancer.

也就是说，下一步不是马上 full，而是把 v2 的 3D consistency 调到明显超过 linear/cubic，再决定是否推 full_test115。

## 5. 下一步建议

优先做 ACSI-v2.1，而不是立即 full：

1. 加强 z-consistency 权重，尤其是 `z_gradient`、`edge_z` 和 `z_laplacian`。
2. 把 NCC-z-MAE 纳入训练或验证选择标准，而不是只用 val loss。
3. 增加一个 `mini_consistency` profile：训练 case 不变，但 epoch 从 3 提到 8-10，用来判断 3D 指标是否能被推开。
4. 加一个 ablation：
   - coarse only
   - residual only
   - residual + z_refine
   - residual + z_refine + z-consistency loss
5. 如果 `mini_consistency` 能稳定超过 linear/cubic 的 ZGE、ZLE、EdgeZ，再跑 full_test115。

full_test115 暂不建议现在直接跑。如果要跑，命令如下：

```powershell
D:\conda\envs\MRI\python.exe -B -c "import sys; sys.path.insert(0, r'D:\MRI\pre'); from acsinet_v2.run_all import run; run('full_test115')"
```

我的判断：ACSI-v2 不是白费，但论文主线应该从“打败所有 SOTA”改成“轻量解剖一致性组件”。下一步真正该做的是让 3D consistency 指标明显超过 linear/cubic，并准备和 I3Net 做复杂度-一致性 Pareto 对比。

## 8. 2026-07-14: ACSI-v2.1 mini_consistency 筛查

已实现并运行 `mini_consistency`（8 train / 2 val / 2 test，8 epochs）。v2.1 新增了目标匹配的相邻切片 NCC-profile loss，并提高 z-gradient、z-Laplacian 和 edge-z 的权重；目的不是简单提高平滑度，而是让预测体的 NCC 曲线贴近 GT。

结果：ACSI-v2.1 的 PSNR/SSIM/MAE/NCC 仍略优于 linear，且明显优于 cubic；但 ZGE/ZLE/EdgeZ/NCC-z-MAE 四项均未超过 linear，并且 NCC-z-MAE 仍劣于 cubic。预测相邻 NCC `0.97949` 高于 GT `0.87477`，过平滑现象仍在。

结论：不启动这个配置的 `full_test115`。下一步优先做 z-refinement ablation，检查是否是轻量 3D head 造成过高的 slice-to-slice correlation；不要继续单纯加大平滑或 z-loss 权重。完整记录见 `reports/anatomy_consistency/mini_consistency_2026-07-14.md`。
