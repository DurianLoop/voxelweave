# PAST-Net fastMRI full-200 十方案结果与下一步路线

更新时间：2026-08-06

本文记录 `fastmri_brain_pastnet_2p5d` 十方案 full-200 sweep 的正式结果。当前数据均来自 fastMRI-brain-T2 expanded x4；文件已归档到 `design/design1_pastnet/results/`。本文的目的不是从十次实验中挑一个偶然最高值，而是判断哪些结构假设得到支持，并据此收敛下一阶段的模型设计。

## 结论摘要

十组实验已经全部完成。最重要的新结果是 `G07 / full_pastnet_g07_ma3_wide200`：

- PSNR `24.2910 dB`，相对 `full_ma3jf_150` 提升 `+0.3178 dB`，相对 I3Net 提升 `+0.2808 dB`。
- SSIM `0.8031`、MAE `38.8905`、MSE `7448.9576`、NCC `0.9350`，五项主指标均优于 I3Net 和此前所有 PAST-Net 版本。
- 相对 MA3JF 的逐病例 PSNR 为 `24/24` 全胜；相对 I3Net 的 PSNR 为 `21/24` 胜，SSIM 和 MAE 均为 `23/24` 胜。
- 相对 I3Net 的逐病例 PSNR 差为 `+0.2808 dB`，近似配对 95% 置信区间 `[+0.1780, +0.3835] dB`，说明提升不是由一两个病例偶然抬高。
- G07 在第 `193` 轮取得最佳验证损失，200 轮末仍未出现明显平台，且学习率始终为 `1.5e-4`。它仍有优化空间，但下一步不能只靠延长训练。

十组结果给出的方向也很明确：

1. **宽 MA3 是目前唯一产生显著跨越的方向。** G07 从头训练后全面超过当前本地 I3Net reference。
2. **加深有正收益，但远弱于加宽。** G08 达到 `24.0547 dB`，相对 MA3JF 提升 `+0.0816 dB`，但仍明显落后 G07。
3. **旧强 checkpoint 上的小学习率校准已经接近局部上限。** G01-G06 大多只在 `-0.033` 到 `+0.012 dB` 内波动，无法形成结构性突破。
4. **强 symmetry、teacher trust-region、单纯增强 z consistency 均未显示独立价值。** 它们不应进入下一版主干。
5. **MA4W window 路线失败。** G09/G10 比 MA3JF 分别低 `1.4073/1.5326 dB`，且 24 个病例全指标全败。当前实现不值得继续救援。

因此，下一阶段应围绕 **G07 宽 MA3 主干** 做受控迭代，重点研究“多锚点如何自适应融合”和“如何扩大空间上下文”，而不是再并行发散到十个不相干方向。

## 下一步主线：Wide MA3 + Adaptive Anchor Fusion

下一版不再同时探索十条路线，而是以 G07 为唯一主干，逐层验证两个结构性假设：

1. **自适应多锚点融合。** 当前 MA3 把 prev/left/right/next、phase、方向差分、绝对差分、有效性 mask 和稀疏曲率作为丰富通道输入，主要依赖普通卷积自行分离。G07 加宽后显著变好，说明模型需要更多通道来表示不同锚点的作用。下一版应给四个锚点使用共享浅层编码器，再由 phase 和 anchor validity 生成 softmax 权重，在特征层自适应融合，而不是只做原始通道拼接。
2. **多尺度空间上下文。** G08 的加深收益有限，说明继续串联普通残差块的边际收益较小。建议在 G07 的 64-channel trunk 中引入参数受控的多尺度上下文块，例如 dilation `1/2/3` 的并行 depthwise 分支或大核 depthwise 分支，再用 1x1 融合。这样扩大面内感受野，同时避免把网络继续堆到 14-20 blocks。

建议的新模型结构为：

```text
四锚点图像与差分
    -> 共享浅层 anchor encoder
    -> phase/validity-conditioned adaptive fusion
    -> linear coarse residual skip
    -> 64-channel wide MA3 trunk
    -> multi-scale spatial context blocks
    -> single-slice residual/detail head
    -> coarse + bounded residual
```

明确不进入主干的组件：MA4W window generation、teacher trust-region、强 symmetry、强 z consistency、MA3J joint interval head。它们已经有直接负面或无效证据。

## 分阶段实验计划

### Phase A：建立可信的 G07 锚点

- 从 G07 best checkpoint 继续训练 60-80 轮，降低学习率到约 `2e-5` 并采用 cosine decay，判断 200 轮是否仍欠收敛。
- 用与 G07 相同架构和配置补 2 个随机种子。最终报告 3 seeds 的均值和标准差，不再只报告单次最好结果。
- 检查训练、验证、测试病例严格互斥，并固定所有 split 清单和预处理版本。

该阶段只回答“G07 的真实稳定水平是多少”，不作为新模型创新点。

### Phase B：单组件受控消融

- `B1`: G07 + adaptive anchor fusion，其他设置不变。
- `B2`: G07 + multi-scale spatial context，其他设置不变。
- `B3`: 参数匹配的 width-depth 对照，避免把更多 FLOPs 误判成结构优势。

模型选择只看 validation；当前反复使用过的 24-case fastMRI test 应标记为 development test，不再把它当完全未见的最终测试集。

### Phase C：组合与锁定

- 只有当 B1 或 B2 单独相对 G07 获得稳定正收益时才组合，不做无依据堆叠。
- 候选进入组合的最低标准：验证集 PSNR 至少提升 `0.10 dB`，SSIM/MAE 不退步；development test 的逐病例 PSNR 胜数至少 `16/24`，配对区间下界大于 0。
- 组合模型完成 3 seeds 后锁定架构、损失、训练轮数和 checkpoint 选择规则。

### Phase D：外部泛化

- 锁定后再一次性评估 IXI 和 NingXia，避免根据外部测试结果回头定制结构。
- 同时报告 zero-shot 泛化和“相同训练 recipe 的从头训练”结果；不为每个数据集单独搜索损失权重。
- 保留无 blend、无 test-time checkpoint 挑选、无病例级后处理的原始模型结果。

## 对 26 dB 目标的现实判断

G07 从 `23.97` 提升到 `24.29 dB`，证明之前确实存在容量与特征路由瓶颈，也第一次给出了全面超过本地 I3Net reference 的结果。但距离 `26 dB` 仍有约 `1.71 dB`，这不是再调几个 loss 权重或多训几十轮就能合理承诺的幅度。

下一阶段的合理目标是先用受控结构迭代把 G07 稳定推进到 `24.5-24.8 dB`，并在 IXI/NingXia 保持方向一致。如果自适应锚点融合和多尺度上下文仍只能带来小于 `0.1 dB` 的收益，就说明仅靠当前 2.5D residual formulation 很难到 26 dB，需要转向更大的方法变化，例如显式可变形跨切片对齐或轻量 3D latent refinement，而不是继续在现有损失上堆权重。

## 最终决策

- **主干保留：** G07 wide MA3。
- **结构升级：** adaptive anchor fusion + multi-scale spatial context，逐项验证后再组合。
- **辅助对照：** G08 deep MA3、G04 MA3C-z。
- **停止方向：** G01/G02 校准续训、G03 symmetry、G05 teacher、G06 joint strong-z、G09/G10 MA4W。
- **实验规范：** validation 选型、3 seeds、配对病例统计、锁定后再测 IXI/NingXia，不做 blend 或测试集定向调参。
