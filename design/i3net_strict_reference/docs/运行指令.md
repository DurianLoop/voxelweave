# 本轮 full 与恢复

用户只需要运行这一条实验：

```powershell
Set-Location D:\MRI
powershell -NoProfile -ExecutionPolicy Bypass -File .\design\i3net_strict_reference\full.ps1 -Seed 3407
```

中断后恢复：

```powershell
Set-Location D:\MRI
powershell -NoProfile -ExecutionPolicy Bypass -File .\design\i3net_strict_reference\full.ps1 -Seed 3407 -Resume
```

最大 300 轮；至少 100 轮后，40 轮无 validation PSNR 提升则早停。只按 clean validation 的患者等权平均 PSNR 保存 best。无 test、IXI 或 NingXia 入口。完成后脚本自动执行效率测量。

显存实测：microbatch 8、梯度累积 2、前两组 checkpoint，峰值约 18.755 GiB allocated /19.693 GiB reserved。full 前资源设置已经确定，不需用户再运行 smoke。不要同时启动另一条占用同卡显存的 full。

输出：`D:\MRI\design\i3net_strict_reference\runs\full_i3net_seed3407_vram20`。

- `manifest.json`：模型、优化方案、随机初始化、数据与代码哈希。
- `history.csv`：每轮 L1、validation PSNR、学习率、更新次数、累计时间和显存。
- `best.pth`、`last.pth`：最佳权重、恢复状态；`best.previous.pth` 为提交中断时的回滚备份。
- `validation/per_slice.csv`、`per_case.csv`、`per_patient.csv`、`summary.json`：最佳 checkpoint 的完整指标。
- `completion.json`、`efficiency.json`：完成凭证、预算受限标记和推理效率。

完成后由助手执行 `i3net_strict_reference.review`，独立重算 best 指标，核对 23 患者配对，报告 10,000 次患者 bootstrap、困难四分位、质量和效率。I3Net 与 PAST control 的初始化和累计预算不同，配对统计用于描绘差距，不作因果架构优劣或 SOTA 声明。若预算上限时最后 30 轮 best 仍增加超过 0.03 dB，则标记预算受限、未证实收敛。

旧 test 表、论文和旧 checkpoint 均不因本次 validation 结果而覆盖。
