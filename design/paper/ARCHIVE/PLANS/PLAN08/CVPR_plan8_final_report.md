## 3. 最终科学主张

### 3.1 核心现象

当两个确定性 MRI 插值结果依赖相同或高度重合的有效测量时，它们的错误会出现相同方向的分量。预测差只能观察两个误差之间不相同的部分，因此共享误差会在分歧中被抵消。

同一目标、模型和预处理条件下，测量不相交上下文相对于干净的共享测量对照，错误排序相关性提升为：

| 队列 | Disjoint − Shared 的错误排序 Spearman ρ | 95% 聚类区间 |
|---|---:|---:|
| fastMRI | 0.092 | [0.043, 0.176] |
| IXI | 0.095 | [0.078, 0.126] |
| NingXia | 0.193 | [0.111, 0.371] |

在干净共享条件下，可由预测分歧观察到的配对误差能量仅为：

- fastMRI：**2.61%**；
- IXI：**1.58%**；
- NingXia：**0.25%**。

对应的共享误差比例分别达到 97.39%、98.42% 和 99.75%。高误差、低分歧的“stable-wrong”案例发生率分别增加 27.1、20.9 和 28.2 个百分点。

### 3.2 原始重合数量不是充分机制

共享锚点数量在总体上与误差几何关系很强，但精确的紧凑四锚点阶梯在三个队列中都出现 **0→1 重合反转**。因此，“每增加一个共享锚点都会单调降低误差可观察性”的严格剂量规律被实验否定。

该负结果被保留在正文中，并促使论文从离散的锚点计数转向连续的共享影响量。

### 3.3 共享影响比共享数量解释得更好

对于解析插值器，共同系数质量与误差对齐的相关性为：

| 队列 | 共享影响 ρ | 锚点数量 ρ |
|---|---:|---:|
| fastMRI | 0.815 | 0.503 |
| IXI | 0.789 | 0.466 |
| NingXia | 0.855 | 0.630 |

所有主要解析终点中，共享影响相对于计数的绝对相关优势区间均高于零，优势范围为 **0.189–0.283**。

对于 HAT 和 SwinIR 的局部有限响应，误差对齐相关性同样稳定优于计数：

| 队列 | HAT：影响/计数 | SwinIR：影响/计数 |
|---|---:|---:|
| fastMRI | 0.838 / 0.799 | 0.851 / 0.796 |
| IXI | 0.797 / 0.714 | 0.787 / 0.712 |
| NingXia | 0.786 / 0.743 | 0.772 / 0.735 |

在 18 个主要“误差对齐/误差分解”终点上，影响相对计数的优势为 **0.036–0.089**，所有聚类置信区间均高于零。

### 3.4 固定重合数量检验与 NingXia 边界

在“恰好共享一个锚点”的固定计数子集中，控制几何和检查因素后：

- fastMRI 和 IXI 的两个模型、全部主要终点均支持连续共享影响的附加解释，`|ρ| = 0.135–0.587`；
- NingXia 的结果为 null/mixed，全部区间跨零，部分方向反转。

因此最终论文只把“影响超越计数”作为 fastMRI 和 IXI 的主要结论；NingXia 用于说明跨站点和小样本异质性，不能用于声称普遍规律。

### 3.5 局部机制链成立，全球排序定律较弱

六个“队列 × 架构”层中，局部箭头均得到支持：

- 共享影响 → 误差对齐：偏 Spearman `ρ = 0.219–0.410`；
- 误差对齐 → 归一化分歧：`ρ = −0.933 至 −0.889`；
- 共享影响 → 可观察误差比例：`ρ = −0.412 至 −0.211`。

上述 18 个局部箭头的区间全部排除零。但“更高误差对齐必然导致更差的全局上下文排序”只在 6 个层中的 3 个达到区间排除零。因此论文明确将结果表述为局部机制，而非因果中介定理或普遍的全局排序定律。

### 3.6 局部神经影响的稳定性

扰动幅度、符号、输入场和方向数审计的 42 个层全部通过稳定性门槛，最低秩稳定性为 **0.942**。但是三个物理平面配对中只有一个通过预设门槛，平面间相关性为 0.779–0.954。

这说明有限响应统计在给定目标、平面和上下文中数值稳定，但不能被描述成平面不变的全局模型属性。

## 4. 实际结果：Anchor-CV

Anchor-CV 是机制产生的轻量级检查级后果，而不是论文的核心新颖性或普遍最优方法。它只使用已经采集的锚点，不需要评分时的稠密真实目标，也不需要额外神经网络调用。

### 4.1 ×4 检查难度排序

| 队列 | Anchor-CV ρ | Adjacent MAE ρ | Adjacent RMSE ρ |
|---|---:|---:|---:|
| fastMRI | 0.943 | 0.934 | 0.942 |
| IXI | 0.955 | 0.956 | 0.956 |
| NingXia | 0.958 | 0.973 | 0.959 |

Anchor-CV 能稳定排序检查难度，但与简单相邻锚点差异的统计表现基本相当，并不提供唯一信息。

### 4.2 回顾性 ×4→×2 加密收益

- fastMRI：Anchor-CV 与加密收益 `ρ = 0.871`；
- IXI：Anchor-CV 与加密收益 `ρ = 0.948`；
- IXI 在 10%/20%/30%/50% 预算下的 oracle 归一化收益为 0.920/0.936/0.972/0.973。

输出 PC 在 IXI 上可达到 0.970 的收益相关性，并在 50% 预算达到 0.996 的 oracle 归一化收益。因此最终论文不声称 Anchor-CV 普遍优于相邻差分或输出 PC；其价值在于低成本、仅依赖已采集测量和可解释性。

## 5. 最终贡献结构

论文最终收敛为三项贡献：

1. **现象与理论：** 揭示由对齐重建误差造成的 consensus blindness，并用精确误差分解解释为何共享误差不能被预测差观察。
2. **机制：** 通过保持目标不变的物理测量依赖干预，证明共享局部估计器影响比原始锚点重合数量更能解释误差对齐和分歧抵消。
3. **实际后果：** 给出 acquired-only 的检查级难度/回顾性加密价值信号，同时保留它不具唯一性和普遍优越性的边界。

## 7. 被保留的负结果与声明边界

以下结果没有被隐藏，而是被用于限制最终结论：

| 负结果/限制 | 最终处理 |
|---|---|
| 锚点计数在 0→1 处反转 | 否定严格单调计数规律，转向共享影响机制 |
| NingXia 固定计数结果为 null/mixed | 将 NingXia 定位为异质性边界，不做普遍化 |
| 三组物理平面门槛只有一组通过 | 将影响定义为局部属性，不声称平面不变 |
| 全局上下文排序箭头仅 3/6 显著 | 只主张局部机制，不主张全局排序定理 |
| Adjacent MAE/RMSE 与 Anchor-CV 相当 | 不声称 Anchor-CV 唯一或普遍最优 |
| 输出 PC 在部分 IXI 指标上更强 | 将 Anchor-CV 优势限定为 acquired-only 和低成本 |
| 最小影响上下文选择未通过迁移门槛 | 不作为论文贡献 |
| 多锚点 jackknife 离散度未通过门槛 | 不作为论文贡献 |
| 协方差残差化未通过确认/迁移门槛 | 不作为论文贡献 |

明确禁止的推断包括：

- 平面不变的全局影响系数；
- 所有队列均成立的固定计数规律；
- Anchor-CV 是校准的、像素级的或普遍最优的不确定性方法；
- 已证明前瞻性扫描控制或临床诊断安全；
- 已证明因果中介关系；
- 已在 MRI 切片插值以外完成经验泛化。
