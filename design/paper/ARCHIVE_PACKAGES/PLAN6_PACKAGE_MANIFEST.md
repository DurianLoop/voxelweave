# Plan6 dual-paper deliverables package

Package date: 2026-08-13

## Included top-level artifacts

- `plan6.md`: governing Plan6 specification.
- `PAPER_EXPANSION_GAP_AUDIT.md`: pre-experiment content-gap audit.
- `PLAN6_HYPOTHESES_AND_EXPERIMENTS.md`: hypotheses, gates, outcomes, and experiment registry.
- `PLAN6_REVIEWER_RED_TEAM.md`: TMI/CVPR reviewer red-team audit.
- `NOVELTY_AUDIT.md`: updated literature and novelty audit.
- `PLAN6_FINAL_AUDIT.md`: final completion, page-policy, dataset-rule, and negative-result audit.
- `IXI_X2_FROZEN_EVALUATION.md`: frozen IXI x2 checkpoint and consequence protocol.
- `TMI_ERROR_TAXONOMY.md`: formal TMI failure taxonomy.
- `TWO_PAPERS_PROGRESS_REPORT.md` and `TWO_PAPERS_PROGRESS_REPORT_20260813.md`: progress snapshots.

## TMI deliverables

- `TMI/TMI_MANUSCRIPT_MASTER/`: 19-page research master, source, figures, experiments, scripts, ledgers, and traceability files.
- `TMI/TMI_MANUSCRIPT_SUBMISSION/`: independent 8-page submission version, source, figures, and bibliography.

Primary PDFs:

- `TMI/TMI_MANUSCRIPT_MASTER/main_20page.pdf`
- `TMI/TMI_MANUSCRIPT_SUBMISSION/main.pdf`

## CVPR deliverables

- `CVPR/CVPR_UPGRADE/`: experiment registry, manifest, scripts, machine-readable outputs, figures, main manuscript, supplement, compliance audit, and traceability files.

Primary PDFs:

- `CVPR/CVPR_UPGRADE/PAPER/main.pdf`: eight content pages plus reference continuation.
- `CVPR/CVPR_UPGRADE/PAPER/supplement.pdf`: five-page supplementary manuscript.

## Scope

The package contains Plan6 paper artifacts and derived experiment outputs. It intentionally excludes raw MRI datasets, model checkpoints, unrelated repository projects, and pre-Plan6 manuscript directories.
