## 最稳健的当前结论

在已评估的 MRI 层间插值范式中，复用相同物理测量会改变局部误差对齐、抵消与分歧可观测性；但检查级排序收益以及有限差分影响相对共享计数的优势具有显著架构依赖性。因此可以说“在已评估的多种插值范式中观察到”，不能说“架构无关”或“影响度普适优越”。
