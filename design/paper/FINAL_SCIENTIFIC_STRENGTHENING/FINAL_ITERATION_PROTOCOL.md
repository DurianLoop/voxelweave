# Frozen final-iteration protocol

This is a retrospective project's frozen final-iteration protocol, not preregistration. It permits exactly three new scientific analyses. Existing cohorts have already informed the project. No new scalar score, rare-event label, favorable subset, or outcome-dependent epsilon search is permitted. The optional untouched-cohort confirmation is skipped: no locally authenticated untouched cohort has been established.

## Freeze and authority

Before inference or new result summaries, `prepare_freeze.py` snapshots the current CVPR/TMI papers, hashes all 26 checkpoints involved in current main-paper evidence, all available prediction arrays used by the five-architecture and original HAT/SwinIR analyses, source targets, preprocessing/model code, current MIRA, and all historical evidence CSVs used for reproduction. It materializes and hashes the new masks and acquired-only input pools. Unrelated training checkpoints in the workspace are outside this experiment's input set; the existing candidate inventory is preserved, not mislabeled as used weights. The protocol, exact case/target/pair registries and input manifest are hash-bound in `freeze.json` before summaries. Amendments record technical causes and timing without overwriting the initial freeze.

## Analysis 1: cross-architecture shared-evidence contrast

**Hypothesis:** disjoint companion evidence increases local observable error fraction even when the predictors are different architectures. Use all 20 ordered pairs A != B from HAT, SwinIR, I3Net, SAINT-style, CycleINR-style, separately in fastMRI (24 examinations) and IXI (115 examinations), using the ten current dataset-specific frozen checkpoints. No retraining or outcome-based pair selection.

Shared = A(phase0), B(phase0); disjoint = the identical A(phase0), B(phase2). The target and ordered pair are identical. Five targets per case follow the current fastMRI list {3,5,7,9,11} and IXI deterministic residue-balanced geometry rule. Dense targets are retrospective references; the common support is the current target 1%-of-maximum foreground mask, identical for every pair and both conditions. This analysis is not called acquired-only. Intensity preprocessing remains each frozen wrapper's acquired-phase preprocessing; all differences in signed geometry, normalization and global coordinates are explicit.

Phase0 uses preserved predictions after wrapper verification, except the following explicit coordinate correction. Missing phase2 arrays are regenerated with the frozen interfaces and retained. IXI retains historical in-memory NIfTI staging quantization. For SAINT, both new phase0 and phase2 use the same physical target coordinate z/(source depth-1), including the phase origin. Historical phase-local/output-depth coordinates are reproduced separately for old-number verification; they cannot be silently mixed with physical-coordinate-correct predictions. Thus new SAINT phase0 is regenerated with this declared coordinate mapping, at unchanged weights and input channels. This correction is fixed before outcomes, not selected by its effect. Shape, missing target, non-finite, unavailable weight and incompatible interface failures are NA with reason. No pair is dropped for accuracy or result direction. Reference and companion contexts are fixed across both conditions; only companion phase changes.

Primary endpoint: for each plane O = ||(eA-eB)/2||² / [ (||eA||²+||eB||²)/2 ]; paired delta = O_disjoint-O_shared. Average five plane deltas within an examination; average examinations within each cohort. Secondary endpoints: similarly averaged changes in error cosine and disagreement MAE; Spearman disagreement versus fixed A-error using examination means, and versus condition-specific paired error using examination means. These are examination-level rankings, not pooled-plane correlations. No pooled-cohort estimate.

Use 5,000 paired examination bootstrap draws, shared across all ordered pairs within each cohort (seed 18001 fastMRI, 18002 IXI). For each endpoint, simultaneous two-sided 95% intervals over the complete 20-pair family use the 95th percentile of the maximum standardized bootstrap deviation. Pointwise percentile intervals are also labeled. Zero bootstrap variance gives a degenerate interval, not division by zero. Constant/undefined ranks remain NA with counts; complete-family inference uses jointly finite draws and reports degeneracy. All exclusions and all 20 pairs remain in output tables.

## Analysis 2: strict acquired-only neural influence

IXI115 is primary; fastMRI24 uses exactly the same contract if geometry permits. Use HAT/SwinIR, all eligible examinations, and three target indices from the historical geometric rule: rounded interior quartiles of [3, depth-4], deduplicated. Selection depends only on array depth. Reference offsets (-2,+2), comparators (-2,+1),(-2,+3),(-1,+2),(-3,+2),(-1,+1),(-1,+3),(-3,+1),(-3,+3). Reference self-pairs are never observations.

For each target, the declared acquired pool is the six physical planes at offsets {-3,-2,-1,+1,+2,+3}. The target is absent. A common scale and mask are computed once from this pool and then fixed across all contexts and perturbations. Support is the union of nearest acquired planes z-1 and z+1, each foreground |x| > .01 max(max|x|,1e-6). Scale is Q99-Q1 of finite nonzero acquired-pool intensities; offset Q1. Normalize to that range and clip to [0,1]. This pool-wide normalizer is itself a shared, frozen preprocessing quantity, not an unreported per-context target-derived statistic. The mask/scale cannot be recalculated from perturbations or y. Empty support/range or invalid geometry is a logged exclusion; no replacement target.

Use original centered Rademacher seeds 6101--6104 on the existing 256x256 input grid, primary epsilon +.01; comparison settings +.005,+.02,-.01. Preserve input/output clipping and resizing. Use float32 network evaluation without AMP/TF32 for these finite-response experiments, declared before outputs to reduce arithmetic quantization; this is a documented precision change from historical mixed precision, not a changed checkpoint. Batch size may decrease for memory without selecting observations.

Influence numerator is the sum of matched shared-anchor response inner products; denominator is geometric mean of all-anchor response energies. Both computed on frozen acquired support. Influence arrays and hashes are saved before accessing separate retrospective targets. Targets are read only afterward to compute error cosine, observable fraction and error MAE on that same acquired support.

A. Broad non-self analysis: |Spearman(I,error cosine)| - |Spearman(count,error cosine)| over all case/plane/context observations, with examinations as bootstrap units.
B. Exactly-one-shared-anchor: partial Spearman of influence and alignment controlling ranked span, asymmetry and examination fixed effects, matching historical rank-then-within-case-centering implementation. Repeated bootstrap draws preserve entire examinations; duplicated cases receive distinct bootstrap IDs.
C. Stability: Spearman alternative setting versus +.01 on the nonzero-overlap observations, across case/plane/context. Use the previously declared HAT/SwinIR per-stratum .85 criterion; minimum .70 is the historical catastrophic-failure floor. A stratum PASS requires all three correlations >=.85. The original aggregate '5/6 strata >=.85 and none <.70' gate is NA here because NingXia is not rerun under this contract; do not invent a four-stratum replacement. The new-architecture .90 gate is a separate historical protocol and is not retroactively applied to HAT/SwinIR.

For A and B use 5,000 paired examination bootstrap draws, seed 18003 IXI,18004 fastMRI; independent cohorts, shared draws across HAT/SwinIR. Report simultaneous 95% intervals across the two models separately per endpoint/cohort, plus pointwise intervals. Influence eligibility requires numerical stability and a positive simultaneous beyond-count interval; fixed-count and ranking remain separate fields, not a scalar score. Report raw associations even after gate failure with ineligible labels.

## Analysis 3: Proposition 1 local neural validation

Use 12 IXI examinations selected by SHA-256('MIRA-final-proposition:'+case ID) order, first 12, and the depth-only central target. Both HAT and SwinIR, all four exactly-one-shared-anchor comparators against (-2,+2). No selection by sensitivity or observed error. The same acquired-only contract applies. Nominal contexts, masks, scales, network weights, target and all unperturbed anchors remain fixed.

Perturb only the one physically common anchor. Use seeds 6101--6104 and their negatives (eight fields), same finite empirical marginal distribution on both sides. Coupled uses identical field indices; independent uses the full Cartesian product of the eight fields, with uniform weights. The Cartesian product has exactly the same empirical marginals and zero cross-covariance of centered fields. All other inputs remain nominal. Epsilon values are .0025,.005,.01,.02, all retained. No threshold/epsilon optimization.

Compute observed coupled-minus-independent expected mean squared disagreement directly from perturbed prediction arrays. Compute matched centered response covariance kappa(epsilon). The equality DeltaD²=-2 kappa(epsilon) is a finite-sample algebraic closure check, explicitly not independent validation of linearization. The substantive local test freezes a central finite-response linearization at epsilon0=.0025: odd response [F(x+eps0 u)-F(x-eps0 u)]/2 for each seed. Its matched dot product, scaled by (epsilon/epsilon0)^2, predicts -2 kappa_linear(epsilon). Report signed observed/predicted effect, absolute error, relative error where nonzero, and centered/odd-response approximation differences at every epsilon. This distinguishes covariance identity from the local Jacobian approximation.

All 12x2x4 context/model examples remain. For description only, classify reference-response cosine >=.1 as aligned, <=-.1 as opposing, and absolute cosine <.1 as near-orthogonal; these categories neither select examples nor determine claim eligibility. If no category occurs, report absent. Bootstrap examinations (5,000 draws, seed18005) for cohort-mean observed/predicted effects, paired across epsilon; simultaneous intervals across 2 models x 4 epsilons for mean observed effects. Approximation errors remain descriptive, without inventing a passing threshold. Nonlinear boundaries and absent counterexample categories are explicit.

## Clean-room reproduction, report cards and stopping

Fresh `reproduce_main.py` independently recomputes main headline values from the lowest-level available frozen arrays, including newly preserved regeneration arrays where old responses were not retained. It does not use manuscript summary CSVs as inputs. Historical per-plane/per-context records are separately identified where they are the lowest preserved observations; any claim not independently array-reproduced is explicitly marked rather than passed by comparing a table to itself. Preserve and resolve mismatches before rewriting. Report exact numerical tolerances, source hashes and LaTeX assertions in REPRODUCTION_CHECK.md.

The MIRA report card retains separate local gap, fixed-reference/examination ranking gap, beyond-count advantage, fixed-count association, stability PASS/FAIL/NA, support contract, and claim eligibility. No arbitrary combined scalar. Historical same-estimator controls and all negative analyses stay visible. The main guard discussion is reduced to two sentences.
