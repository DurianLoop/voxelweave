## E02 外部 TopCoW 血管标注实验（结果计算前冻结）

使用本地 imagesTr 全部 125 个 `topcow_mr_*` 与配对 CoW label；不使用 CT，不将标签当输入。该集合对当前论文为新增外部数据，但它是挑战公开训练集，不冒充挑战隐藏 test。固定 Linear 与四点 Lagrange Cubic；不训练、不择优调参。原生图像、同一 affine，沿数组 z 做 ×4 采样。仅纳入两相位均有完整四点支撑的奇数目标，避免边界复制。

比较 L0–C0 与 L0–C2，以及 C0–L0 与 C0–L2。共享与不相交条件使用相同估计器组合，两个相位所有采集索引不相交；每种目标 residue 的最近距离多重集相同，病例内 residue1/3 等权。这个解析对照不能冒充五架构膝关节/血管网络复现，也不识别所有方向混杂。

评分支持统一使用 phase0 两个最近已采集锚点 1% mask 的并集；辅以全图与 GT 1% mask 的配对敏感性。输入归一化范围只来自 phase0 锚点，原始和归一化评分/终点同时保留。主端点为病例等权 observable gain，次端点为固定 phase0 预测误差排序。血管 label 只用于评估 vessel-region MAE 与能量，既不选输入 mask，也不选目标平面。没有血管像素的平面记录为不适用，不填零；显式记录每例血管平面和像素数。

补充同估计器 ×4→×2 的共同奇数平面 benefit，消除倍率专用 checkpoint 混杂；对 Linear 与 Cubic 均用同一固定规则，不挑有利估计器。报告 raw 及 acquired-range normalized 的评分/终点二维交叉，固定 20%/50% 预算，保留零/负收益及血管误差不稳健。推断以 125 个病例为单位，不以平面或血管像素增加样本数。10,000 次共同病例 bootstrap，两个估计器方向同时区间仅针对局部增益。

## E03 IXI 评分与终点尺度的二维对照（结果计算前增补）

Plan 13 的 IXI 115 例 I3Net 共同支持原始数值保持不变。分别组合 raw / acquired-range-normalized score 与 raw / acquired-range-normalized benefit，共四种单位合同；Anchor-CV、adjacent MAE 都保留，不择优报告。标准化两倍率误差和受益使用同一已采集 phase0 范围，不分别计算两个尺度。报告相关、控制当前同单位误差的 partial Spearman 和 20%/50% 预算。该分析诊断量纲与政策目标的一致性，不能将后验变换称为验证过的部署方法，也不能用新增正结果抹去旧 raw-endpoint 负结果。

## 资源资格边界

MRNet 有 120 exams ×3 views，但官方说明对应 111 patients，本地缺少可靠的 exam→patient 映射，不能把120当独立患者。现有异常/ACL 标签可作描述性补充，不能凭分类标签编造病灶分割或诊断保真终点。本轮不因该资源可用就追加无界实验。

OAI-ZIB-prepared 元数据为 uint8 0–7 label-like 数据，不进入强度重建实验。其他项目正在进行的训练保持原状。本轮补充实验先使用 CPU 和现有预测。所有结果均探索性，不能重新命名旧开发 test 为新确认集。
