## 2. 高价值补充实验及所有失败

### E01：条件协方差命题

固定偏差、局部 Jacobian 和边际输入协方差，交叉协方差项为 `κ = tr(J_A C J_Bᵀ)`。相对零交叉协方差，期望误差内积增加 κ，期望平方差减少 2κ；期望能量之比的变化为 `−κ/(2τ)`。这不是逐样本保证，也不是 `E[比值]` 的结论。保留 κ 为负/零的反例及非线性余项限制。12 组、每组 100,000 次模拟全部通过计算检查；不把该验证记作非 MRI 泛化。

### E02：唯一的 acquired-only guard，没有证实优越性

使用既有 HAT、SwinIR、I3Net、CycleINR 预测，固定两配对。fastMRI 24 例按已记录哈希规则分为 12 例开发和 12 例内部评价，另向 115 例 IXI 转移。只试一个公式 `max(F_dev(D_norm), F_dev(AnchorCV_norm))`，完整比较 disagreement、Anchor-CV、相邻锚点 MAE/RMSE、acquired range、header spacing 六个基线。共生成 1,390 行配对逐平面结果、278 行逐病例结果，绑定 695 个输入文件哈希。

内部 fastMRI 两配对均为 **0 个 stable-wrong 阳性**，AP/AUC 不能评价，表格明确写 NA。IXI 两配对各仅 **2 个阳性**：HAT/SwinIR guard AP 0.508696，disagreement 0.508929，Anchor-CV 0.510204；I3Net/CycleINR 分别为 0.017391、0.014448、0.018141。全部 12 个 guard-minus-baseline 同时区间跨零。5,000 次抽样中两配对共同有效的只有 3,918 次，稀疏事件条件区间不应被过度解读。

这些队列历史上已经被查看；新拆分不产生真正 pristine holdout。Q4 的 held-out 可行动优势**仍未满足**，已经停止评分搜索。初始 sklearn 缺失改用定义直接实现的 AP/AUC，并与显式重复病例计算交叉核对；未因环境失败改分数或端点。

### E03A：真实科研定性图

主图使用 fastMRI SwinIR 24 例中按病例平均局部效应选出的下中位病例，再选最接近该病例均值的目标平面；补充图使用固定种子随机病例。规则和选中病例在本轮新推理之前保存，但选择依据是既有结果，故不宣称 outcome-independent sampling。

同一目标、同一 reference prediction 下完整显示 GT、A、B、`|A−B|`、双方真实误差图，两行共用误差色标。主例可观察误差占比由共享时 **1.98%** 到不共享时 **19.77%**；随机例由 **3.34%** 到 **16.00%**。图来自真实数组与冻结 SwinIR CPU 推理，不是生成的 MRI。CPU 与历史 GPU 混合精度输出存在记录在案的差异，主/随机例 reference MAE 差约 0.118/0.153，不能称逐像素完全一致复现。

### E03B：实际方差代理的共享控制

在 acquired-only 支撑和尺度下构造 Linear/Cubic 两成员解析集成，固定 reference，切换另一成员的锚点共享。两个方向的局部可观察占比增益均约 **0.321**；针对固定 reference 误差的方差排名增益分别为 **0.0313 [0.0122, 0.0503]** 和 **0.0361 [0.0158, 0.0564]**，为每端点两方向同时区间。

115 例 IXI 完成。24 例 fastMRI 深度 16，无法同时满足完整四锚点支持和两个 residue 类别，全部按原几何资格条件排除；保留首例断言失败和逐例排除表，不通过边界填充换取结果。二成员方差与差异平方有确定关系，不计为两个独立验证；该结果与原五架构 TTA 控制一起提供实用构造证据，但不外推为完整 Deep Ensembles 或所有 Bayesian 方法的失败。

### E04 与 E06：可复用实现及去自比较检查

MIRA NumPy API 已实现输入合同、物理锚点一致性、预测配对、影响量及可选目标评价。目标改动不改变 acquired-only 分数、共享 ID 冲突拒绝、线性影响解析参照、正负幅度、能量闭合、病例键唯一和开发/评价不重叠检查全部通过。调用者仍须保证模型和预处理冻结，声明来源的标记不能自动证明任意闭包没有泄漏。

## 5. Q1–Q4 结论与未解决投稿风险

| 问题 | 本轮判断 |
|---|---|
| Q1：局部共享测量→误差对齐→隐藏差异机制是否可重复？ | 在已评估设计内支持：同目标控制、真实主/随机例、跨架构局部效应和解析方差代理一致；完整链的因果解释仍受命题假设与上下文变化限制。 |

| Q4：是否有真正 held-out 的可行动优越性？ | **没有。** 唯一 guard 未显示可靠优势，现有队列非未触及确认集，按停止规则结束搜索。 |
