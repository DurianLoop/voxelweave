# 三位严格审稿人的最终自评

本文件是模拟审稿，不是外部专家意见。评价对象是本轮实际证据与最终稿，不提供无法校准的录用概率。

## 审稿人 A：理论是不是标准恒等式换名字？

**最强质疑。** 双预测误差分解本身是代数恒等式；协方差迹公式也来自标准局部线性计算。改变共享上下文时，预测偏差、边际敏感性和归一化可能一起变化，因此 MRI 对照并未纯粹识别“共享导致共同偏差”的单一因果效应。

**本轮回应。** Proposition 1 明确固定偏差、Jacobian 与边际协方差，只改变交叉协方差。结论是期望内积和期望平方差的变化，以及期望之比，不能偷换为比值的期望、逐样本余弦单调性或无条件共同偏差定理。补充材料保留反向敏感性、零交叉项和非线性余项边界。12 个数值设定验证推导，真实 MRI 图显示同目标的实际误差。修正后的 influence 与代码一致。

**仍未解除。** 数学新颖性有限。相位控制固定同目标并约束部分几何，但完整上下文和网络响应仍会变化；更严格的因果识别没有完成。理论应承担机制解释，不能单独承担主要创新。

## 审稿人 B：框架是否只是重新包装分析？

**最强质疑。** MIRA 没有新重建模型，也没有证实更好的部署评分。新增 guard 在可评估转移集上没有可靠超越简单基线；实际深度集成和完整概率不确定性方法并未充分覆盖。

**本轮回应。** 第 3 节与 Algorithm 1 现在定义可复用输入合同、物理锚点身份、上下文干预、全锚点能量归一化影响量、稳定性检查和回顾性评价。提供 NumPy API 及信息来源测试，避免只有名词。实际比较包含原有神经网络 TTA 控制和新增线性/三次插值二成员方差代理；完整标出二者的适用范围。唯一新增 guard 与六个简单基线全部报告，失败后停止调参。

**仍未解除。** 框架可执行并不自动构成足够的方法创新。二成员解析代理不能替代训练深度集成；Q4 可行动优越性仍未满足。若审稿标准要求新方法显著提升性能，这是主要拒稿依据。

## 审稿人 C：是否为反复查看 MRI 测试集后的故事？

**最强质疑。** 历史主要端点、反转控制修订和后来的 local-observability 叙事发生在结果可见的研究过程中。所谓不同队列也已用于既有分析。掩膜及全检查尺度含目标信息，存在过度包装为 target-free 或 prospective 的风险。

**本轮回应。** 台账逐项拆分历史记录、可核验哈希、实际信息访问和不可证明的时间顺序；删除无证据的前瞻性表述。排查 split、绑定 26 个实际权重，公开 train/val 患者重叠。移除宽上下文自比较后的六项同时区间仍为正，但明确标为事后敏感性；NingXia fixed-count、I3Net/CycleINR 稳定性、评分和历史方法失败没有删除。基线的 111 配置与全部五指标继续保留。

**仍未解除。** 当前没有真正未触及的外部分析队列，也无法排除未记录的历史搜索；新增开发/评价拆分不能抹去旧结果已被查看的事实。病例级 bootstrap 解决相关观测计数问题，不解决研究者选择偏倚。

## 投稿判断

**最强接受理由：** 对同一缺失目标改变物理观测共享，结合真实误差图、五架构结果、超越简单重叠计数的影响关联和局部/全局失效区分，形成可执行且诚实陈述适用边界的 MRI 可靠性审计。

**最强拒绝理由：** 贡献可能被判为已有不确定性局限的领域内机制整理；条件性标准理论、反复使用的历史队列以及未成功的部署评分，尚不足以支持强方法创新或前瞻性可靠性提升。

**单个最高价值后续实验：** 在一个此前未用于任何模型或分析选择、患者独立且具有真实致密参考的 MRI 队列，运行预先锁定的 acquired-only 神经网络共享/不共享审计。只使用已有冻结 HAT/SwinIR；预先固定锚点身份、配对几何、掩膜、尺度、幅度、种子、排除条件和一个主要端点（病例级可观察误差占比的配对变化），以患者为单位做确认性推断。影响稳定性与已冻结 guard 仅作明确次要端点。该实验优先填补信息访问与未触及队列两项实质空白，而不是继续在旧队列搜索新分数。当前必要的新队列尚未认证，因此本轮不伪造其完成状态。
