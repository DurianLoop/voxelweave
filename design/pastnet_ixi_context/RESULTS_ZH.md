# IXI 六锚点 STC 配对实验：完整结束，未晋级

2026-10-09 核验完成。local 与 extended 的 seed3407 均完成 80 轮，EMA best 均为 epoch80。**额外两个真实锚点带来的 validation PSNR 增量仅 +0.00340356 dB，未达到预登记 +0.10 dB 门槛；停止当前 STC 六锚点分支。** 不追加续训、学习率扫描、另外两 seeds 或该候选的 test。

## 模型和可归因比较

两臂共同使用固定 IXI wavelet3 best 初始化，保留 linear coarse、有界残差、四锚点 conditioning、64 通道 MA3、小波深度卷积、多尺度 latent、dual-domain、AdamW/warmup-cosine/EMA。共同新增原 STC 模块，在 1/4、1/8 分辨率对查询中心的潜特征值、斜率和曲率做加权拟合，零投影注入解码前 latent。

输入槽位为 [-8,-4,0,4,8,12]。local 屏蔽首尾两槽，extended 解除 mask；两臂容量、初始化、计算结构、数据顺序、损失、优化与预算相同。真实六锚点区间约占 train/validation 的 87.5%。本次检验额外真实观测经过**当前 STC 表示**后是否有实用价值；并不测量所有长上下文方法的信息上限。
