# MAE 约束残差诊断（独立实验，2026-09-14）

本轮结果产生前登记。旧三种ridge残差探针及STC继续停止。本实验检验一个新的目标函数假设：**给低容量残差估计器加入MAE不退约束，能否保留值得继续研究的PSNR收益？** 不训练PAST-Net full。

## 唯一主要变量与共同设置

沿用已缓存的冻结control预测，以及原56名拟合、55名检查训练患者划分。该检查组已被前一轮研究观察过，是开发诊断组，不是新的独立holdout。旧网络也已见过这些训练患者。当前不读取validation/test图像。

只使用self的5种特征（常数、预测强度、强度平方、平滑差、梯度幅度），同样在32²产生，然后**上采样特征**到256²。每个phase拟合5个系数，共15个，不加入锚点。两臂均在256²计算患者等权MSE，并使用相同标准化、ridge和幅度约束；与上一轮32²拟合结果不能混作单变量比较。

- MSE臂：最小化标准化MSE + .001·非截距系数平方和。
- MAE约束臂：相同目标，额外要求**每个phase拟合组患者等权MAE不超过未修正基点**。

标准化只由拟合组计算。输出修正为 `.01 * standardized_features @ beta`，拟合样本上要求最大绝对修正≤.05；两个臂完全相同。检查组仍固定clip至±.05，不修改预测的最终动态范围。幅度约束和MAE约束均在拟合标签上计算；检查标签仅评估。

使用SLSQP，零系数可行起点，maxiter=150、ftol=1e-9；不调权重、不扫约束预算、不按检查分数选迭代。记录收敛状态及实测可行性（MAE数值容差1e-8，幅度1e-6）。未收敛或不可行只报告失败，不宣称最优。数学拟合问题是凸的，但数值求解含非光滑约束，不能以求解器退出替代可行性核验。

## 筛选条件

只有约束臂满足：所有phase数值收敛且可行；检查组相对未修正基点PSNR≥+.05 dB；10,000次患者配对bootstrap95%下界>0；至少60%患者改善；MAE不退（数值容差1e-8）；基点最差四分位PSNR不退，才进入一次冻结系数的validation诊断。另报告与MSE臂的配对差和MAE代价，不用对照臂MAE恶化掩盖约束臂对基点的失败。

若失败，停止此低容量约束假设，不追加参数搜索。即使通过也只是允许低成本validation诊断，不等于新模型或full晋级。没有SOTA、3seed或外部结果承诺。
