两臂具有完全相同的5种预测自身特征、每phase5个系数、256²拟合口径、ridge和幅度限制；唯一主要变量是加入每phase的拟合MAE不退约束。相较前次32²残差拟合，本次另设了同口径MSE对照，避免把分辨率口径变化和约束混在一起。

三个phase均收敛，独立float64检查的拟合MAE变化约4.3e-13、8.9e-13、1.5e-11，满足预设1e-8数值容差；最大拟合修正.00960，低于.05约束。检查组最差四分位PSNR改善.003035 dB。失败原因是**实用效应**：PSNR仅+.002331，未达到+.05门槛。不会通过放宽MAE预算继续调参。

当前结论仅限这个固定、低容量的预测偏差估计器：保住MAE后，大部分MSE/PSNR收益消失。该结果不足以支持直接启动新loss full，更不是所有深度模型的Pareto边界或信息论上限。SLSQP收敛和可行性核验也不作为严格全局最优证明。

本次56名拟合、55名检查患者来自旧train，检查组在前次开发中已被观察过，并且曾用于历史网络训练。因此是开发诊断，不能写成全新独立泛化确认。旧STC、geometry、correspondence和ridge探针的停止结论全部保留。
