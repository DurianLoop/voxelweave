# 从对应模块转向尾部权重分配

## 已完成证据

QGCR full为25.571022 dB，对同预算control+.009011，未达+.10；79轮早停、best epoch64。此前LACV、geometry、local correspondence、STC也未达到各自门槛，冻结latent线性读出没有提供实质分频收益。这些结果不证明G086达到信息上限，但没有继续叠加对应模块的强证据。

本轮选择用户最初指定的独立方向“平滑tail-risk objective”。**它是训练目标的受控实验，没有新增网络架构，也不宣称CVaR或平滑首次用于学习。** 不用QGCR/LACV checkpoint，不把本实验写成其续训或救援。

## 从梯度看具体变化

对每个slice的N个平方误差，原hard top-k均值的导数权重是选中位置1/k，其余0。当误差在第k名附近互换时，权重发生跳变。令p=k/N，把正部函数换成softplus，可得到平滑CVaR包络；最优eta满足平均sigmoid=p，导数权重为sigmoid((e²−eta)/tau)/k。

尾部质量p、risk权重.2、所有其他loss项及整个模型固定。只改变权重过渡的平滑程度：tau=.002，不扫描、不按epoch变化。N=65536时k=6554，因此使用p=6554/65536，避免与原ceil规则产生额外尾部质量差别。

CVaR的阈值最小化表示已有成熟理论。本实验使用该表示和平滑函数，不把数学工具本身当作原创贡献。[Rockafellar与Uryasev关于一般分布CVaR的原论文](https://www.sciencedirect.com/science/article/pii/S0378426602002716)

## 已完成的训练内机制检查

冻结同预算control的1,020层train预测，对预测加入固定seed、标准差.001的独立高斯扰动，比较risk对预测的梯度相对变化。先slice→series→patient等权：hard平均变化.060926，soft为.013451，下降77.923%。soft权重有效像素数平均占18.807%，而hard约10%；soft约66.475%的质量仍落在原hard top-k像素上。

这是人工小扰动下的risk梯度诊断，不是全部objective梯度、参数空间梯度方差或真实SGD训练轨迹。训练患者曾参与原模型训练，不能作为泛化证据。它支持“过渡更平滑”这一机制，不保证PSNR提升。

平滑会把一部分权重移到原hard-tail之外，可能影响最差像素，因此full新增明确的hard tail10 MSE不退guard，且继续保留MAE/SSIM等均值方向要求。不能用平均PSNR上涨掩盖尾部恶化。

## 实验隔离

hard实现与旧objective的loss完全相等，参数梯度最大差0；soft与hard仅差.2倍risk差。两个模型的992,179参数、初始化、forward逐位相同，没有新增参数或推理算子。CVaR阈值仅在训练loss内从训练target误差计算，不是推理时读取target。

原G086初始化、64通道MA3、四锚点、linear coarse+bounded residual、原multi-scale query latent、dual-domain及AdamW/warmup cosine/EMA全部保留。full复用同预算hard control，无需再跑一个重复hard full。前三轮同样冻结旧参数，两臂都不更新参数。

正式full是对泛化的第一次有效比较：23名clean validation选epoch，须达到control+.10 dB及全部guards才能补三seed。IXI/NingXia与近期强基线比较仍在最终锁定之后；本轮没有外部或SOTA结果。
