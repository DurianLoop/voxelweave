# 核心模型与预注册实验协议

## 1. 模型只押一个核心假设

工作名：**PAST-Net v2 / Physical Query Correspondence（PQC）**。

目标是估计 `Y(q)=linear(anchors,q)+bounded residual`。旧 G086 的四锚点先经同位置软融合，再交给宽主干。若相同组织在相邻锚点横向移动，这一步可能在建立对应之前混合不同组织；后端 refiner 只能修补已混合的表征。

PQC 在融合前保留每个锚点的 1/4、1/2 多尺度特征，并由线性 coarse 的特征产生 query。每尺度在每锚点的 3×3 空间邻域进行相似度加权，使用真实 anchor-query 毫米距离形成距离先验；无效锚点和 padding 候选严格屏蔽。两个尺度的匹配特征通过零初始化投影加入 transferred feature，再进入原有宽 MA3 trunk。它没有估计输出图像 flow，也没有对三个 offset token 做注意力。

物理 FiLM 的 17 维条件包括：resize 后的三轴 log-spacing、9 个方向余弦、spacing/orientation 两个 known mask、phase、query 到左右端点的实际毫米距离（固定除以 20 mm）。未知几何的数值贡献归零；对应距离退化为 grid 单位并有明确缺失标记。FiLM 的末层及对应投影零初始化，迁移时不改变 G086 输出。

**新增有效信息：** DICOM 的真实几何，及后续 context 开关可能纳入的原本局部窗口外观测。**没有新增测量、但改变提取方式：** query-conditioned 空间候选、多尺度对应、频率解码。不能把新增参数或相似度操作本身说成新采集信息。

## 2. 保留与变更位置

```text
真实稀疏层 + validity + 物理 query grid
  ├─ linear coarse（不变）
  ├─ rich four-anchor condition（不变）
  └─ shared 2D anchor encoder（326 个旧状态张量完整迁移）
       ├─ geometry FiLM → auxiliary feature              [P1]
       └─ 每锚点、多尺度、query 局部对应 → transferred feature [P2]
            → 64ch / 10-block MA3 + spatial context
            → 原有 1/2、1/4 latent interval interaction
            → bounded decoder + 原有 dual-domain residual
            → 可选 latent frequency-factorized residual    [P3]
```

`frequency` 的三个独立 latent head 分别经 low/mid/high FFT 掩码后求和，掩码为 partition of unity；整体再经 bounded tanh，因而最终输出不是严格带限。它在 decoder 输入处取特征，不以 target 频谱做输入，也不新增 3D。

`risk` 只把共同 hard top-10% 项替换为平滑 CVaR。实现求解

`min_eta eta + E[tau * softplus((error² - eta)/tau)]/(1-alpha)`，

每 slice 用 28 步二分求其平滑驻点，训练用 envelope gradient。不是把 hard quantile detach 后宣称精确 smooth-CVaR。前 20% epoch 风险权重为零，在 20–60% 区间从 0 升至 .2，alpha 从 .5 升至 .9，tau=.002（归一化平方误差单位）。目标形式来源于 Rockafellar–Uryasev 的 [CVaR 优化工作](https://sites.math.washington.edu/~rtr/papers.html)，此处 softplus 和退火是本项目的显式设计选择。

`context` 只将真实锚点索引由 `[-4,0,4,8]` 扩为 `[-8,-4,0,4,8,12]`。复用同一个 shared encoder 和对应模块，参数量不变；新增计算量可测。越界槽重复合法观测但 mask=0。fastMRI 最多 4 个真实层，不能宣传“六层真实输入”。

`inference.interpolate_sparse` 只接收稀疏采集数组和 query 几何，返回 native-size 体数据，观测位置直接复制输入，精确 anchor clamp。当前协议限 x4；x2/x6 或可变倍率预训练未混入这一轮，需以后独立立项。

## 3. 单变量顺序与硬门槛

所有候选从同一个 G086 迁移，不从上阶段 best 连续追加训练，因此相邻架构对照拥有相同数据、初始化来源、优化预算和 seed。旧续训在这里只是**预算匹配的 control**，不作为新研究贡献。

| 阶段/variant | 唯一新增变量 | 相对谁 | validation PSNR 最低增益 |
|---|---|---|---:|
| P0 `control` | 同规范预算匹配的 G086 对照 | 冻结基点另报 | 不作为晋级模型 |
| P1 `geometry` | 物理 feature FiLM | control | +.08 dB |
| P2 `correspondence` | 融合前多尺度空间对应 | geometry | +.10 dB |
| P3 `frequency` | latent 分频解码 | correspondence | +.05 dB |
| P4 `risk` | hard tail → 平滑退火 CVaR | frequency | +.03 dB |
| P5 `context` | 额外真实稀疏上下文槽 | risk | +.15 dB |
| Final | 固定架构，3 seeds | 三 seed control | 总增益 ≥+.10 dB |

每道门还要求：配对 bootstrap PSNR CI 下界 >0；至少 60% 病例获胜；按 parent PSNR 定义的最差四分位病例平均增益 ≥0；SSIM/MAE/MSE/NCC/Dice proxy/HD95 proxy 均值方向不退；单 interval latency 和 forward 峰值显存各不超过 parent 的 1.5 倍。Final 成本对照为 control。

固定训练最多 80 epoch，前 3 epoch 旧参数冻结（control 同时不更新旧参数），前 5 epoch warmup，随后 cosine 至 .05 倍。旧参数 lr=2e-5、新模块 lr=1e-4，AdamW betas=(.9,.99)、wd=2e-5、EMA=.999、梯度裁剪1、有效 batch=16。2026-09-08 按24 GB显卡调整为实际 batch=2、累积8次；control/geometry 仅前5个主干块 checkpointing，较重配置默认10块。AMP 初始缩放设4096以避免实测的首次梯度溢出。有效 batch、样本顺序和学习率保持不变；末尾不足整组时按实际样本数加权。所有结构沿用同一 Charbonnier/MSE/gradient/Laplacian/轻 symmetry/z-curvature/residual/base-guard 骨架；不做 LR 或 loss sweep。

只按完整 validation 的患者等权 PSNR 选 EMA checkpoint。至少训练 30 epoch，连续 15 epoch 无改善停止；epoch=0 是合法基线候选，若训练无改进可保留它。NaN/Inf 直接报错，不把数值失败当缺失病例忽略。正式 run 目录不可覆盖，恢复必须匹配数据/代码/参数哈希，并恢复 optimizer、EMA、scaler 和 RNG。

**停止规则：** 单变量未过门槛，则记录负结果并停止其累加链；不增加轮数、权重或搜索次数救援。如果 P1 失败，当前预注册链停止，而不是自动绕过它堆 P2–P5。基于失败结果重新提出独立假设时，需另写协议，不能后验改本门槛。optional 开关全部 smoke 通过不代表它们获准一起 full。

## 4. 三 seeds、配对统计和锁定

固定 seeds 为 **3407 / 2027 / 9103**。首 seed 做有限顺序筛选；选定保留下来的架构后，运行另外两个 seed 与对应 control，不选择“最好 seed”。报告每 seed 均值、跨 seed 样本标准差、患者配对增益、win count、失败患者列表。10,000 次 crossed seed/patient bootstrap 使用共同患者重采样，以免把每 seed 的同一患者误当独立新患者。

三个 seed 都从同一个历史 G086 出发，因此只估计 **v2 优化阶段**的随机性，不包括 v1 预训练方差。若论文要求完全独立端到端训练，需另行生成三份独立 v1 底座，不能把当前三 seed 说成该证据。

`report final` 检查三 seed 与 control，并要求该候选自身的单变量 gate 已通过；通过后 `report lock` 固定 variant、recipe、全部 Python SHA256、候选和 control checkpoint SHA256。此后外部 test 只接收锁定配方训练完成、validation 选出的 best checkpoint。fastMRI development-test 不在 v2 evaluator 可调用范围内。

锁定后对 IXI 与 NingXia 分别按同配方训练 matched control / candidate，各跑三 seeds。它是**固定架构跨数据集训练复评**，不是 zero-shot；不因外部 test 结果改 recipe。IXI 汇总完整 115 名患者；NingXia 每 seed 完整 8-fold、每患者只作一次 held-out test，同患者不同 series 始终在同 fold，先 series 再 patient 等权。NingXia bootstrap n=8，很不稳定，且没有估计重叠 CV 训练集导致的全部依赖，不作强显著性宣传。

## 5. 质量与效率合同

主表输出 PSNR、SSIM、归一化 MAE/MSE、NCC、tail10-MSE，以及阈值 .1 前景的 Dice/HD95 proxy。后两者只衡量固定强度前景，不是组织标签或临床结构分割；当前没有在此包提供解剖标签，不能声称通过了 anatomical Dice/HD95。HD95 对 known spacing 使用 resize 后的毫米单位；unknown 使用像素单位并在 geometry mask 中标记，不能混写临床毫米精度。

效率固定 batch=1、三张 256×256 缺失层、AMP、10 次 warmup/30 次同步测量；报告 interval 与生成层延迟、p95、参数和 forward 峰值显存。FLOPs 明确为 Conv/Linear 的 MAC×2，未覆盖 FFT/unfold/相似度归约/逐元素运算，不当作完整总 FLOPs。

本机 RTX 5090 D v2 的初测：

| 配置 | 参数 | Conv/Linear GFLOPs/层 | 延迟/层 | forward 峰值 GiB |
|---|---:|---:|---:|---:|
| control | 992,179 | 148.863 | 48.088 ms | .859 |
| correspondence | 1,011,988 | 169.776 | 50.804 ms | 1.222 |

全开关真实 256×256、完整对称损失的 AMP backward 峰值约 10.00 GiB；正式训练常驻 EMA、optimizer 和运行状态可能增加显存，应以每次 run 记录为准。正式候选 checkpoint 仍需用同一脚本重新测量。
