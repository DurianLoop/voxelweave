# 分开的运行指令

本次已经跑完审计和 smoke，没有后台 full 训练。以下 full 为需要另外执行的正式实验。单 GPU 顺序运行，不把多个 full 放到同一 GPU 并发。每条失败时先处理失败，不能继续后面的阶段。

2026-09-08 显存配置更新：24 GB 显卡以约 20 GiB 为目标，control/geometry 默认实际 batch=2、累积8次、前5个主干块 checkpointing；有效 batch 仍为16。后续较重配置默认对10个主干块 checkpointing，正式运行前单独 smoke。control 实测 allocated 19.62 GiB、reserved 20.31 GiB。`full_stage.ps1` 现在输出 `_vram20` 后缀目录；此前 `full_control_seed3407_vram20` 的初始验证文件保留，不能将其作为新配置的 resume 来源。

## 2. Smoke（不产生 full 研究结果）

`smoke.py` 检查六个 variant 的零差迁移、target 不可见、反向几何、无效锚点、新参数梯度和完整分辨率 AMP backward。用新输出名重跑：

```powershell
& $py -B -m pastnet_v2.smoke --out design\pastnet_v2\results\smoke_manual.json
& $py -B -m pastnet_v2.run train --variant correspondence --smoke --out design\pastnet_v2\runs\smoke_manual_correspondence
& $py -B -m pastnet_v2.run train --variant correspondence --smoke --resume --out design\pastnet_v2\runs\smoke_manual_correspondence
```

所有目录默认拒绝覆盖；训练续跑须使用 `--resume`，且源代码/recipe/manifest/seed 一致。若源码改了，创建新 run，不允许悄悄恢复旧 run。

每个 full 固定 80 epoch 上限、early stop≥30 epoch；完整 train=112 series、val=23 series，256×256。其耗时远超 smoke。

```powershell
.\design\pastnet_v2\commands\full_stage.ps1 -Variant control -Seed 3407
.\design\pastnet_v2\commands\full_stage.ps1 -Variant geometry -Seed 3407

& $py -B -m pastnet_v2.report gate `
```

## 5. Optional Full P3/P4/P5：每次一项

每条命令需要上一项已晋级的 gate；不能整段盲跑。`report gate` 每次都要求紧邻的单变量 parent。

```powershell

& $py -B -m pastnet_v2.report gate --candidate design\pastnet_v2\runs\full_frequency_seed3407_vram20 --parent design\pastnet_v2\runs\full_correspondence_seed3407_vram20 --out design\pastnet_v2\results\gate_frequency.json

# P4：只有 frequency 晋级才运行。
.\design\pastnet_v2\commands\full_stage.ps1 -Variant risk -Seed 3407 -Gate design\pastnet_v2\results\gate_frequency.json
& $py -B -m pastnet_v2.report gate --candidate design\pastnet_v2\runs\full_risk_seed3407_vram20 --parent design\pastnet_v2\runs\full_frequency_seed3407_vram20 --out design\pastnet_v2\results\gate_risk.json
```

```powershell

```

## 6. 最终候选：补齐 3 seeds，再锁定

以下以**已晋级且决定保留的 correspondence** 为例；若最后保留 geometry/frequency/risk/context，统一替换候选名及其前置 gate。不是默认选择全开关，也不是挑单 seed 分数最高者。

```powershell
.\design\pastnet_v2\commands\full_stage.ps1 -Variant control -Seed 2027
.\design\pastnet_v2\commands\full_stage.ps1 -Variant control -Seed 9103
.\design\pastnet_v2\commands\full_stage.ps1 -Variant correspondence -Seed 2027 -Gate design\pastnet_v2\results\gate_geometry.json
.\design\pastnet_v2\commands\full_stage.ps1 -Variant correspondence -Seed 9103 -Gate design\pastnet_v2\results\gate_geometry.json

& $py -B -m pastnet_v2.report final `
  --candidate design\pastnet_v2\runs\full_correspondence_seed3407_vram20 design\pastnet_v2\runs\full_correspondence_seed2027_vram20 design\pastnet_v2\runs\full_correspondence_seed9103_vram20 `
  --parent design\pastnet_v2\runs\full_control_seed3407_vram20 design\pastnet_v2\runs\full_control_seed2027_vram20 design\pastnet_v2\runs\full_control_seed9103_vram20 `
  --gate design\pastnet_v2\results\gate_correspondence.json `
```

Final 未通过则 lock 命令拒绝执行。外部 test 前不得改源码或 recipe；修改会使哈希检查失败。已读过的 fastMRI test-24 不在新 evaluator 的可测试范围内。

## 7. 分开的 IXI full

需要上一节实际生成的 candidate_lock。脚本先准备 IXI train/val sidecar，按固定 recipe 从历史 G086 为 matched control 和锁定架构分别训练，三 seeds；每个 run 只按 validation 选 best，再测固定 test-115。

```powershell
.\design\pastnet_v2\commands\full_external.ps1 -Dataset ixi -Lock design\pastnet_v2\results\candidate_lock.json
```

输出 `results/ixi_paired_final.json`，同时保留每 seed/per patient 原始 CSV。这个比较衡量 v2 对共同迁移底座的改进。旧 I3Net/IXI G07 的发表口径与新规范不同，不能直接将新归一化分数填入旧主表；做强 baseline 排名需在同一评价合同下重评它们。

## 8. 分开的 NingXia full

固定 8 个患者 fold，每 fold/seed 分别训练 matched control 与锁定候选，总计 8×3×2 个 run。患者所有 series 共用 fold，测试每患者一次。它是正式 CV，耗时较长。

```powershell
.\design\pastnet_v2\commands\full_external.ps1 -Dataset ningxia -Lock design\pastnet_v2\results\candidate_lock.json
```

输出 `results/ningxia_paired_final.json`；完整性检查要求 3 seeds、8 folds、每 seed 恰好 8 个 held-out patient，缺失或重复均报错。外部 test 结果无论好坏都不用于派生新 recipe。
