# 证据复盘与本轮创新假设

## 1. 先承认已失败的检验

统一观测归一化、256²、23 validation 患者口径下：

| 实验 | PSNR | 相对同预算 control | 结论 |
|---|---:|---:|---|
| 原结构 control | 25.562011 | — | 参照 |
| geometry FiLM | 25.564138 | +.002126 | 未达 .08，停止 |
| correspondence-only | 25.564482 | +.002471 | 未达 .10，停止 |

对训练后模块急性置零，correspondence active 比 off 高 .015067 dB，但 off 又低于 control .012596 dB。这说明当前模块参与了共同适应，却没有形成足够净收益；不能由此证明所有对应建模无效，也不能把急性置零当作从头训练消融。两次结果不足以归因“旧 trunk 锁死”“零初始化有罪”或“loss 错误”。不按结果放宽门槛。

## 2. 可操作的信息缺口

现有模型知道最近四槽图像，但首尾槽重复导致实际只有三个观测；完整采集网格上还有一个真实远端图像。新的输入必须来自这个网格，不能从目标体中偷取更近的隐藏层，也不能把生成层计为新观测。

重新逐 manifest 核验：validation 23 例全部16层。z=0/4/8 三个区间的局部有效观测数分别为3/4/3；六槽对应4/4/4。中位毫米覆盖从首尾40mm扩到60mm，中央维持60mm。训练112 series 中111例16层、1例32层；后者就是既有顺序异常且 geometry unknown 的样本。旧文档“fastMRI 都只有16层”仅适用于本轮 validation，不能泛化到整个 train。

原 control 的中心查询（phase=.5）最困难：首尾区间均值24.321644 dB、中间区间24.568901 dB；不能简单说所有边界 phase 都更差，phase=.75 的首尾均值反而更高。新上下文是否改善这个分布，必须报告全部预定义 strata。

旧频段审计中 low/mid/high 分别承载约59.46%/34.03%/6.51% MSE，但来自**旧归一化的冻结 G086 诊断**；不能混写为新 control 的频谱实测。它仅支持先研究结构尺度、而非只加强高频纹理的动机。

## 3. 已完成的训练内验证

将训练患者按患者 ID 的 SHA256 排序交替分成56名拟合和55名诊断患者；同患者系列不能跨组。固定32²低频图像、ridge=.001、按区间和phase拟合像素线性预测器，不调参数。对比 local 与 extended 的真实强度特征，没有用 validation/test。

诊断患者等权 MSE：.002609482 → .002581096，降幅1.0878%；50/55患者改善，10,000次患者bootstrap的 MSE 降幅95%CI为 `[.000017914,.000039993]`。中间区间两臂图像完全相同，仅ridge尺度的数值差异约4.7e-9；收益主要在首尾区间。

这说明极简单的估计器能利用额外观测，提供了启动正式单变量实验的依据。**它不证明额外观测能预测 G086 已剩下的残差**，也不是可实现的网络收益承诺。诊断患者仍属于 G086 历史训练集；此次未向原模型拟合新 checkpoint。完整 CSV、患者分组和脚本已保存。

条件均方误差的最优风险形式为 `E[Var(Y|可用观测)]`；加入真实观测不会提高无限容量最优估计器的理论最小风险，但实际有限样本网络可能变差。本仓库没有相同输入条件下重复独立真值，无法测出该条件方差。凸包、target辅助对齐或低频替换都不是整个 PAST-Net 的信息论上限。

## 4. 相对既有工作，究竟检验什么

I3Net 已包含面内频域处理、through-plane 信息交互及 cross-view block；不能把“加入频域/多尺度/跨切片信息”当作本项目的原创贡献。[I3Net 原论文](https://arxiv.org/abs/2405.02857)；[作者代码](https://github.com/eeeric-code/I3Net)。

本轮研究假设更具体：**把不完整局部窗口转为真实稀疏轨迹，并显式保留查询位置的特征值、斜率和曲率，能否利用远端图像补充局部重建缺失的信息？** 二次加权最小二乘是经典工具，本身不主张首次提出；论文层面的新颖性还需更完整相关工作比对和成功消融支撑。

本轮不增加物理 FiLM，以免把信息数量和物理条件混在一起。轨迹坐标是稀疏网格单位，非毫米。若真实上下文单独未通过，停止此分支；不会把它与 FFT、Flow、3D 或风险 loss 堆叠后重新声称已验证。

## 5. 可证伪次序

E1 在原局部信息上增加相同轨迹模块，只建立容量对照；E2 在相同模型、初始化和预算下开放远端真实槽。E2 需对 local ≥.10 dB、对原 control ≥.15 dB，并同时过配对统计、尾部质量和效率 guards。详见 [预注册协议](../PROTOCOL_ZH.md)。最终3 seeds与外部复评属于通过pilot之后的后续工作，当前没有成功候选或外部结果。
