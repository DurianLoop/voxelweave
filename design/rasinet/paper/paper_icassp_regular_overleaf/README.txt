ICASSP regular paper compilation package

Main file: main.tex
Compiler: pdfLaTeX
Bibliography: BibTeX

Local compilation:
  pdflatex main.tex
  bibtex main
  pdflatex main.tex
  pdflatex main.tex

For Overleaf, upload the ZIP and set main.tex as the Main document.
The package contains only the source, bibliography, IEEE style files,
generated tables, and figures required by the regular paper.
