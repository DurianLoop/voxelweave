# 6.1 日报：DICOM 解码扩容与 T2 横向对比

## 一、今日目标

今天开始把实验重心从“单个模型能不能跑通”推进到“同一口径下比较数据集、方法和指标的规律”。主要做三件事：

1. 补齐 fastMRI brain DICOM 的 JPEG2000 解码依赖，解决部分 DICOM 不能转 NIfTI 的问题。
2. 扩容 `fastMRI-brain-T2`，让它从 sanity 子集变成更像正式外部数据集的规模。
3. 开始整理 `IXI-T2 / fastMRI-brain-T2 / NingXia-T2` 的同口径横向对比。

## 六、初步规律

1. `IXI-T2` 相对平滑、干净，Linear/Cubic 本身就不差，学习方法的提升更像是在“锦上添花”。
2. `fastMRI-brain-T2` 明显更难，传统插值指标低很多，但 SAINT-style 相对 Linear 的提升更大，说明学习型模型在复杂真实 DICOM 数据上更有发挥空间。
3. `NingXia-T2` 是目前最重要的外部验证候选。它和 IXI 的器官部位、设备来源、临床采集条件都不同，后续能直接检验模型是不是只在 IXI 上好看。
4. 目前不适合急着创新。更重要的是先把 `数据集难度 -> baseline 表现 -> 模型增益 -> 结构指标/视觉质量` 之间的关系摸清楚。

## 七、下一步计划

1. 用扩容后的 `fastMRI-brain-T2 160-case split` 重跑 SAINT full，得到 test n=24 的正式结果。
2. 对 `NingXia-T2` 先跑 Linear/Cubic/SAINT-style，补齐外部验证第一列结果。由于当前 NingXia test 只有 1 个病例，短期更适合作为流程验证和外部 sanity，不适合单独支撑论文结论。
3. 如果时间允许，再在 fastMRI-brain-T2 和 NingXia-T2 上补 ResUNet residual，形成 CNN baseline 与 Transformer baseline 的对照。
4. 每个实验先固定打印主指标：`PSNR / SSIM / MAE / MSE / NCC`。派生指标如 `RMSE / NMSE / NRMSE` 先不频繁打印；等某个实验进入论文候选，再统一补算。
5. 后续继续读论文时重点记录：某方法在哪些数据集上验证、使用了哪些倍率、是否跨域测试、是否只和传统插值比，还是和 EDSR/RDN/RCAN/SwinIR/HAT/SAINT/I3Net 等强 baseline 比。
