## 三、Visual QC 观察

### 3.1 fastMRI-brain-T2 expanded

fastMRI 中 SAINT 的优势和指标方向基本一致。small-gap case 中两者视觉差异不大，误差图也比较接近；large-gap case 中，SAINT 在脑室、脑沟和外缘高对比结构处的误差更小，SwinIR 更容易出现局部模糊和亮度扩散。

需要注意的是，SAINT 和 SwinIR 都没有完全恢复 GT 中细小脑沟纹理。二者相比 Linear coarse 都更平滑，说明当前模型的收益主要来自减少插值误差和整体结构对齐，而不是完全恢复高频细节。

### 3.2 NingXia-T2 case-level CV

NingXia 中 SwinIR 的均值优势在 visual QC 上也能看到一部分对应关系。SwinIR-better case 中，SwinIR 对外轮廓和局部高亮结构的保持略好，误差图中结构边界误差更低；near-tie case 中，两者都偏平滑，肉眼差异很小，指标差异也确实很小。

SAINT-better case 中，SAINT 的 PSNR/NCC 略优，但 SSIM 与 SwinIR 基本持平。这说明 NingXia 上二者并非单向压制，而是不同病例、不同结构区域上各有优势；主表中 SwinIR 均值更强，但不应写成全面压倒 SAINT。


统计口径：

```text
one generated 256x256 slice, model forward only, no NIfTI IO or resize
```

| Method | Input | Params(M) | FLOPs(G) | Forward ms | CUDA peak MB |
|---|---|---:|---:|---:|---:|
| SAINT-style | 1x6x256x256 | 1.1973 | 35.7606 | 3.0969 | 117.30 |
| SwinIR-style 2.5D | 1x4x256x256 | 0.2239 | 28.3682 | 4.2980 | 251.23 |

说明：

1. SAINT-style 参数更多，但单 slice forward 更快，CUDA peak allocated 也更低。
2. SwinIR-style 2.5D 参数更少，但 attention 路径导致 forward time 和显存峰值更高。
3. FLOPs 由 Conv2d / ConvTranspose2d / Linear hook 估算；当前没有完整计入 attention 的 matmul / softmax / normalization，因此 SwinIR 的 FLOPs 是保守估计。更精确的 Transformer FLOPs 后续可以单独补。
4. 该效率表目前只用于本项目同脚本横向比较，不直接等价于论文 reported FLOPs。

## 五、当前判断

1. fastMRI 上 SAINT 的指标优势有视觉对应，主要体现在脑室、脑沟、外缘等高对比结构处误差更小。
2. NingXia 上 SwinIR 的均值优势也有视觉对应，但优势不是每个病例都稳定存在，应该写成“均值更优 / 部分病例更优”，不要写成全面压倒。
3. 两个模型都有平滑问题，说明下一步创新不应只追求更深模型，而要关注结构边界、高频纹理和层间连续性。
4. 效率上 SAINT 参数更多但更快，SwinIR 参数少但显存和耗时更高。后续如果加入 HAT，需要特别关注效率代价。

## 六、下一步

1. 对 visual QC 中的 selected cases 做更细的 slice-level 定量，例如边缘区域 MAE、梯度误差、局部 SSIM。
2. 把效率脚本扩展到 ArSSR-style、ResUNet residual 和 I3Net，形成完整效率补充表。
3. 如果继续做方法创新，优先围绕“边界/纹理保真 + 相邻层连续性”设计轻量模块，而不是只堆更大的 Transformer。
4. I3Net 到位后，先跑同样的 visual QC 和效率 profiling，再决定它在第一梯队中的位置。
