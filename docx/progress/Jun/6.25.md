## 1. 当前研究目标

当前项目已经从“补 baseline”逐步进入“准备自研模型”的阶段。前一阶段的核心目标是把 T2/x4 through-plane interpolation 的强 published baselines 补齐，明确现有方法的上限、短板和论文 claim 空间。

目前已经形成的研究主线是：

1. 用 IXI-T2 作为开发和快速筛选 benchmark。
2. 用 fastMRI-brain-T2 expanded 作为公开复杂 T2 验证集。
3. 用 NingXia-T2 case-level 8-fold CV 作为本地临床外部验证。
4. 主表只维护统一重跑结果，不混入 reported-but-not-comparable 的论文原表结果。
5. 后续自研模型需要围绕 baseline 暴露的问题设计，而不是单纯堆更大的通用 SR backbone。

## 2. 数据集状态

| Dataset | 当前定位 | 数据规模 | 当前主表/实验口径 |
|---|---|---:|---|
| IXI-T2 | 开发和公开干净 benchmark | 578 usable T2 volumes；split 404/58/115 | 旧主表为 test n=25；新实验逐步改用 full_test115 |
| fastMRI-brain-T2 expanded | 公开复杂 brain T2 验证 | 160 strict T2 NIfTI；112/24/24 split | full test n=24 |
| NingXia-T2 | 本地临床外部验证 | 8 cases / 22 T2 series | case-level 8-fold CV，报告 fold mean |

补充说明：

- fastMRI 虽有 160 个 3D volumes，但多数 depth 较短，当前 full train samples 为 4080。
- IXI full train samples 为 153195，约为 fastMRI 的 37.55 倍，因此 IXI full 训练耗时远高于 fastMRI。
- NingXia 必须保持 case-level CV，不能把同一 patient 的不同 series 随机拆到 train/test。

## 3. 已进入主表的 baseline

当前主表已经包含：

| Method | 定位 |
|---|---|
| Linear / Cubic | 非学习传统插值下限 |
| ResUNet residual | 内部 CNN residual baseline |
| ArSSR-style | published INR baseline |
| CycleINR-style | published INR baseline |
| SwinIR-style 2.5D | 通用 Transformer SR 强 baseline |
| SAINT-style | spatially-aware medical slice synthesis style baseline |
| I3Net | published medical slice synthesis baseline |

主表当前关键结论：

- I3Net 在 IXI-T2 test n=25 和 fastMRI-brain-T2 expanded test n=24 上最强。
- SwinIR-style 2.5D 在 NingXia-T2 8-fold CV 平均指标最强。
- SAINT-style 在 fastMRI 上非常强，在 NingXia 上也接近第一梯队。
- ArSSR-style 和 CycleINR-style 已经补齐 INR 类 published baselines，但不是后续优先调参方向。
- Linear 在 IXI 上已经不弱，Cubic 经常低于 Linear，说明本任务不是简单高阶插值越强越好。

## 5. I3Net 进展

I3Net 是当前最重要的 published medical slice synthesis baseline，原因是它的任务定义与 through-plane interpolation 高度贴合：4 sparse input slices -> 13 dense output slices。

已完成：

- `ixi_i3net/`
- `fastmri_brain_i3net/`
- NingXia 8-fold CV via `processing/run_ningxia_case_cv.py --models i3net`

关键结果：

- IXI-T2 test n=115：I3Net PSNR 30.7526 / SSIM 0.9231 / MAE 18.5089 / MSE 2858.7057 / NCC 0.9771。
- IXI-T2 n=115 中，I3Net 对 Linear 和 Cubic 均为五指标 115/115 case wins。
- fastMRI n=24 中，I3Net 对 Linear 和 SAINT 均为五指标 24/24 case wins。
- NingXia 中，I3Net 明显强于 Linear/Cubic/INR/ResUNet 多数指标，但低于 SwinIR/SAINT。

阶段结论：

I3Net 可以作为本项目最关键的 task-matched published baseline。它证明医学 slice synthesis 结构在 IXI 和 fastMRI 上非常有效；但 NingXia 结果说明，任务匹配不等于跨域临床鲁棒。

## 7. 视觉 QC 和效率分析

已完成 SAINT vs SwinIR 的 visual QC：

```text
docx/experiment_notes/visual_qc/saint_vs_swinir/
```

视觉趋势：

- fastMRI 中，SAINT 的优势常见于脑室、脑沟和高对比外边界。
- NingXia 中，SwinIR 的平均优势体现在部分局部轮廓和亮结构保持，但并非每个 case 都一致。

效率 profiling：

| Method | Params | FLOPs(G) | Forward time | Peak CUDA memory |
|---|---:|---:|---:|---:|
| SAINT-style | 1.1973M | 35.7606 | 3.0969 ms | 117.30 MB |
| SwinIR-style 2.5D | 0.2239M | 28.3682 | 4.2980 ms | 251.23 MB |

结论：

- 参数量不是唯一效率指标。
- SwinIR 参数更少，但当前实现的 peak memory 和 forward time 反而更高。
- 后续自研模型必须同时报告 Params / FLOPs / inference time / GPU memory。

## 8. 当前已形成的模型设计依据

已整理文档：

```text
docx/experiment_notes/baseline_exposed_problems_for_model_design.md
```

当前自研模型的建议关键词：

```text
Residual
Phase-aware
Spatially-adaptive
Structure-preserving
Domain-robust
```

推荐第一版模型方向：

```text
Linear coarse + left/right sparse slices
        -> phase-aware 2.5D feature encoder
        -> spatially-aware cross-slice fusion
        -> lightweight structure residual decoder
        -> z-consistency / edge-aware auxiliary constraint
```

这个设计来自现有 baseline 暴露出的具体问题：

- Linear 是强下限，因此应做 residual correction。
- SAINT/I3Net 证明相邻 slice 条件非常重要。
- SwinIR/HAT 证明局部窗口/Transformer restoration 有价值，但通用 SR 不足以解决全部问题。
- I3Net 在 NingXia 不占优，说明 task-matched architecture 仍需 domain robustness。
- HAT/SMamba 证明换更强 backbone 有收益，但不如 SAINT/I3Net 的 task-matched conditioning。

## 11. 当前论文 claim 边界

目前可以较稳地 claim：

- 项目已经在 T2/x4 through-plane interpolation 上构建了公开 benchmark + 公开复杂 T2 + 本地临床 CV 的三数据集验证框架。
- 已覆盖传统插值、CNN residual、INR、通用 Transformer SR、spatially-aware slice synthesis、I3Net medical slice synthesis 等多类 baseline。
- I3Net 和 SAINT/SwinIR 构成当前强 baseline 梯队，但不同数据集最强方法不一致，说明仍有自研模型空间。
- 后续新模型应解决 residual correction、phase-aware conditioning、spatially-adaptive cross-slice fusion、structure preservation 和 domain robustness，而不是简单堆大模型。

暂时不应过早 claim：

- 不应说某个已有 baseline 在所有数据集绝对最强。
- 不应把 smoke/mini 或 partial fold 结果写入主表。
- 不应把 HAT/SMamba NingXia 6/8 fold partial mean 当作最终结果。
- 不应把 reported paper numbers 与本地统一重跑主表直接混合比较。
