# 5.11 项目接手记录

## 项目目标判断

当前代码主要做医学 3D 体数据的 Z 轴层间图像生成/超分辨率。师兄的路线是 pix2pix/GAN：输入相邻或间隔切片，生成中间切片，再把生成切片插回原体数据，达到 through-plane super-resolution / inter-slice interpolation 的效果。

目录里有两版代码：

- `v2`：输入前后两层 + 全局位置编码，共 3 通道，输出中间 1 层。等价于 Z 轴 2x 插值。
- `v4`：输入第 `i` 层和第 `i+4` 层 + 1 个全局位置编码 + 3 个相对位置编码，共 6 通道，输出中间 3 层。等价于 Z 轴 4x 插值，是更完整的一版。

优先复现 `v4`，`v2` 可作为历史 baseline。

## 数据集内容

### 1. `dataset/CAS2023`

- 文件结构：
  - `data/`：100 个 `.nii.gz` 体数据，命名 `000.nii.gz` 到 `099.nii.gz`。
  - `mask/`：100 个对应 mask，命名与 data 一致。
- 作用判断：医学 3D NIfTI 图像 + 分割掩膜，可用于层间插值训练，也可用 mask 只在前景/血管/器官区域评估。
- 处理建议：
  - 当前 `v2/v4` 训练代码只读取一个目录下的 `.nii.gz` 图像，不读取 mask。
  - 若用 CAS2023 训练，可把 `dataset/CAS2023/data/*.nii.gz` 作为 `gan_train` 输入。
  - mask 暂时用于评估或裁剪前景，不建议一开始混进 GAN 输入。

### 2. `dataset/TopCaw2024`

- 文件结构：
  - `imagesTr/`：250 个 `.nii.gz`，包含 CT 和 MR，命名如 `topcow_ct_001_0000.nii.gz`、`topcow_mr_001_0000.nii.gz`。
  - `imagesVal/`：10 个 `.nii.gz`，5 个 CT + 5 个 MR。
  - `cow_seg_labelsTr/`：250 个标签，CT/MR 都有对应标签，命名如 `topcow_ct_001.nii.gz`、`topcow_mr_001.nii.gz`。
- 作用判断：Circle of Willis 相关 CT/MR 体数据，带血管标签。该数据更适合血管结构保持、局部前景区域评估，也适合 MR-only 或 CT/MR 分开做实验。
- 处理建议：
  - 不要直接混合 CT 和 MR 训练层间插值，强度分布差异很大。
  - 若目标是 MRI 层间生成，先筛选 `imagesTr/topcow_mr_*_0000.nii.gz`。
  - 标签可用于 mask PSNR/SSIM、Dice/HD95 的下游结构保持评估。

### 3. `dataset/OAI-ZIB`

- 文件结构：
  - `V00, V01, V03, V05, V06, V08, V10` 七个访问时间点文件夹。
  - 总计 46824 个 `.npz`。
  - 每个 `.npz` 目前抽样看到只有一个 key：`x`，shape 为 `(364, 364, 150)`，dtype 为 `uint8`，值域约 `0-7`。
- 作用判断：OAI-ZIB 膝关节 MRI 预处理数据，`Vxx` 是不同随访时间点，文件名含受试者 ID、左右膝、visit 编号。
- 注意：
  - 当前 `v2/v4` 数据集类只支持 `.nii.gz`，不能直接读取 OAI-ZIB 的 `.npz`。
  - `x` 的值域很像标签/量化后的组织类别或预处理图，而不是常规 MRI 原始强度。正式使用前要确认 OAI-ZIB 数据说明。
- 处理建议：
  - 若要用 OAI-ZIB，需要新写 Dataset：读取 `np.load(path)["x"]`，再按 Z 轴构造 `(slice_i, slice_i+gap) -> middle slices`。
  - 先不要和 NIfTI 数据混训。

## 当前代码逻辑

### `v4/dataset.py`

核心流程：

1. 遍历训练目录下所有 `.nii.gz`。
2. `nibabel` 读取体数据。
3. min-max 归一化到 `[0, 1]`。
4. `create_slice_pairs(volume, gap=4)`：
   - 输入：第 `i` 层、第 `i+4` 层。
   - 目标：第 `i+1, i+2, i+3` 层。
5. resize 到 `512 x 512`。
6. 组成 6 通道输入：
   - previous slice
   - next slice
   - global z position
   - relative position 0.25
   - relative position 0.50
   - relative position 0.75

### `v4/models.py`

模型由三部分组成：

- `MotionEstimator`：根据前后两层估计 forward/backward flow，共 4 通道。
- `Warper`：用 flow 对前后切片做 grid_sample，得到粗略中间层。
- `GeneratorUNet`：把 warped slices、原始两层、flow、位置编码拼起来做 refinement，输出 3 张中间切片。
- `Discriminator`：PatchGAN 判别器，输入真实/生成的 3 层 + 条件 6 通道，共 9 通道。

### `v4/train.py`

损失函数：

- GAN loss：MSE，对 PatchGAN 输出做 LSGAN。
- brightness-weighted L1：亮区域权重大，`1 + real_B * 9`。
- coarse loss：早期约束 warping 粗预测，权重随 epoch 衰减。
- SSIM loss：`(1 - SSIM) * 10`。
- flow smoothness loss：约束 flow 平滑。
- VGG loss 已写但乘以 `0.0`，实际未启用。

验证指标目前只用：

- `L1 + (1 - SSIM)`

这不是完整论文指标，只是训练期间选 best checkpoint 的 val loss。

### `v2/eval_step.py`

这里补了一些评估指标：

- MSE
- PSNR
- SSIM
- NCC
- NMI
- MAE
- Pearson correlation
- 近似 Hausdorff distance

但路径写死为 Linux 旧路径，需要改成当前数据路径后才能运行。

## 复现步骤

### 1. 创建 conda 环境

仓库根目录已添加 `environment.yml`，推荐：

```powershell
conda env create -f environment.yml
conda activate mri-interp
```

如果 CUDA 版本不匹配，先按本机显卡驱动调整 `pytorch-cuda=11.8`，或者改用 CPU 版 PyTorch。

### 2. 准备训练数据目录

当前训练入口默认读 `./gan_train`，推理默认读 `./gan_inputs`，输出到 `./gan_outputs`。代码只识别目录第一层的 `.nii.gz`。

推荐先用 TopCaw MR 做最小复现：

```powershell
New-Item -ItemType Directory -Force v4\gan_train
Copy-Item dataset\TopCaw2024\imagesTr\topcow_mr_*_0000.nii.gz v4\gan_train\
```

或者用 CAS2023：

```powershell
New-Item -ItemType Directory -Force v4\gan_train
Copy-Item dataset\CAS2023\data\*.nii.gz v4\gan_train\
```

### 3. 训练 `v4`

```powershell
cd v4
python train.py
```

默认参数：

- epochs: 50
- batch size: 4
- input size: 512 x 512
- num_workers: 16
- checkpoint 输出：`v4/checkpoints/pix2pix_epoch_*.pth`
- loss 曲线输出：`v4/training_plots/progress.png`

显存不足时优先改：

- `v4/train.py` 最下面 `batch_size=4` 改成 `1` 或 `2`。
- `v4/config.py` 里 `input_size` 从 `(512, 512)` 改为 `(256, 256)`。
- `v4/dataset.py` 里 `num_workers=16` 改小。

### 4. 推理

准备输入：

```powershell
New-Item -ItemType Directory -Force v4\gan_inputs
Copy-Item dataset\TopCaw2024\imagesVal\topcow_mr_*_0000.nii.gz v4\gan_inputs\
```

运行：

```powershell
cd v4
python inference.py
```

注意：`v4/inference.py` 默认加载 `./checkpoints/pix2pix_epoch_40.pth`。如果训练后只有 best/final，需要改成：

```python
interpolator = MRIInterpolator("./checkpoints/pix2pix_epoch_best.pth")
```

推理输出为：

```text
v4/gan_outputs/up_*.nii.gz
```

### 5. 使用已有权重

根目录有：

```text
dataset/pix2pix_epoch_best.pth
```

它大概率是 `v2` 的 3 输入/1 输出模型权重，不一定能直接加载到 `v4`。如果要试：

- 用 `v2/inference.py`，把权重复制或路径改到 `dataset/pix2pix_epoch_best.pth`。
- 不要用 `v4` 直接加载，`v4` 是 6 输入/3 输出，结构不匹配。

## 推荐补充指标

师兄没有给具体指标，可以按层间生成/SR 常见指标补齐：

- 生成层 PSNR：只在生成出来的中间层算，不要把原始输入层也算进去。
- 生成层 SSIM：同上。
- MAE / MSE：像素级误差。
- NRMSE：不同强度范围数据之间更可比。
- NCC / Pearson：看强度相关性。
- LPIPS 或医学特征感知指标：可选，MRI 灰度图需谨慎解释。
- mask-SSIM / mask-PSNR：对 TopCaw/CAS 有标签时，只在结构区域评估。
- 下游结构指标：如果生成后跑分割，可比较 Dice、HD95、clDice。
- Z 轴一致性：相邻切片均值/梯度曲线是否平滑，避免生成层忽明忽暗。

## 更现代的方法路线

### 路线 A：扩散模型替代 GAN

适合做主线升级。把任务定义为条件扩散：

```text
condition = [slice_i, slice_i+gap, position encoding]
target = middle slices
```

优点：

- 医学 SR 2025-2026 主流方向之一。
- 比 GAN 更稳定，指标和主观质量通常更好。
- 可以加入物理退化模型，把训练变成 inverse problem。

可参考 reading 中：

- Likelihood-Separable Diffusion Inference for Multi-Image MRI Super-Resolution
- Scale-Cascaded Diffusion Models for Super-Resolution in Medical Imaging
- MoEDiff-SR
- Geodesic Diffusion Models
- Res-SRDiff

### 路线 B：INR / Neural Field 做任意倍率层间插值

最贴近“任意 Z 位置生成”。输入相邻切片特征和连续坐标 `z/t`，输出该位置图像。

优点：

- 不限于固定 2x 或 4x。
- 可以自然支持不同 slice spacing。
- 对 OAI-ZIB、TopCaw 这种不同分辨率/不同体数据更友好。

可参考：

- Zero-X21: Scale-agnostic image feature conditioned INR for multi-modal and multi-planar anisotropic MRI inter-slice interpolation

### 路线 C：Transformer/Mamba SR

适合做强 baseline。用 2D/2.5D 网络建模相邻层上下文，训练成本比扩散低。

可参考：

- Taming diffusion transformers for high-fidelity MRI super-resolution
- CNN-Transformer gated fusion network for medical image super-resolution
