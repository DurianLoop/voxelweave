## 下一步计划

### Phase 1：先把现有 GAN baseline 做成可评估实验

目标：把“能跑通”升级成“能量化比较”。

任务：

1. 固定一套 TopCaw MR 数据划分。
   - 训练集：`imagesTr/topcow_mr_*`
   - 测试集：`imagesVal/topcow_mr_*`
2. 明确实验协议。
   - 输入稀疏层
   - 生成中间层
   - 只在生成层上计算指标
3. 整理评估指标。
   - PSNR
   - SSIM
   - MAE / MSE
   - NCC / Pearson
   - 必要时做 mask 内指标
4. 改造现有 `v2/eval_step.py` 或单独写一个干净的 `v4` 评估脚本。
5. 输出一份表格：
   - 每例指标
   - 均值 / 标准差

### Phase 2：做正式训练而不是 1 epoch smoke test

目标：拿到一个可观察收敛趋势的 GAN baseline。

建议：

- 先使用 TopCaw MR-only 全量训练集。
- 把 epoch 提到 30-50。
- batch size 根据 5090 显存调到 2、4 或更高。
- 记录：
  - 训练时间
  - 显存占用
  - best val loss
  - 推理时间

### Phase 3：建立传统 baseline

在深度模型之外，加入简单但必须有的参照：

- 线性插值
- B-spline / cubic 插值
- 若实现成本可控，再加 nearest 作为 sanity baseline

原因：

- 论文与汇报时，必须说明 GAN 相比基础插值到底提升了什么。

### Phase 4：切入更新方法

建议分两条线：

#### A. 条件扩散模型

任务定义：

```text
condition = [slice_i, slice_i+gap, position encoding]
target = middle slices
```

优点：

- 比 GAN 更符合 2025-2026 医学图像生成主流。
- 更适合和最近文献对齐。
- 后续可扩展到不确定性估计与 inverse problem 形式。

#### B. INR / continuous coordinate interpolation

任务定义：

- 输入前后切片特征
- 输入连续相对坐标 `t`
- 输出任意位置层

优点：

- 不局限 2x 或 4x。
- 更贴近“任意层间插值”。
- 概念上和 Zero-X21 一类工作接近。
