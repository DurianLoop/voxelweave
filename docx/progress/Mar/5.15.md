# 5.15 当前实验结果分析与下一步规划

## 一、当前已经得到的结果

目前最值得作为主结果分析的是 `case_full`，因为它已经改成病例级划分，并且完整跑完。

### 1. 数据划分

`case_full` 使用固定随机种子 `3407`：

- 训练病例：100 个
- 验证病例：25 个
- 官方评估病例：5 个

这说明当前流程已经从原来的 slice-level split 改成了 case-level split，能够避免同一病例的不同切片同时出现在训练集和验证集里。

### 2. 训练过程

`case_full` 原计划最多训练 50 个 epoch，实际在第 23 个 epoch 后 early stopping。

- 最优验证损失：`0.024894`
- 最优 checkpoint：出现在 epoch 14
- 最终训练在 epoch 22 后停止
- 学习率从 `2e-4` 逐步下降到 `6.25e-6`

这一点很重要：  
模型不是训练得越久越好。训练损失总体下降，但验证损失在 epoch 14 后没有继续稳定改善，所以自动保留 epoch 14 的最优模型是合理的。

## 二、如何理解这组结果

### 1. GAN 对“整体重建质量”确实有帮助

与线性插值相比，GAN：

- PSNR 提高约 `0.99 dB`
- MSE 从 `210.80` 降到 `167.66`
- NCC 从 `0.9575` 提高到 `0.9668`
- mask-PSNR 也最高

这说明 GAN 已经学到了一部分比传统插值更好的强度恢复能力，尤其在整体像素误差和前景区域误差上有优势。

### 2. 但 GAN 对“结构连续性”的优势还不稳

目前：

- GAN 的 SSIM 只略高于 linear，差距很小
- GAN 的 mask-SSIM 低于 linear
- auto-HD95 没有优于 cubic

这说明 GAN 当前更擅长把灰度值恢复得更接近 GT，但在边界、细长结构、局部几何连续性方面还没有形成稳定优势。  
对血管类任务来说，这一点尤其值得重视，因为最终真正重要的往往不是单纯 PSNR，而是细小血管是否断裂、边界是否偏移。

### 3. 病例之间难度差异明显

从逐病例结果看：

- `091 / 093 / 094 / 121` 上 GAN 的 PSNR 都优于 linear
- `092` 是最难病例，所有方法的 PSNR 和 SSIM 都偏低
- `094` 和 `121` 的 auto-HD95 明显偏大，说明这两个病例的自动前景边界更容易发生较大偏差

这提示后续不能只看平均值，还要做：

- per-case 分析
- 可视化质检
- 难例病例单独讨论

### 4. `case_smoke` 不能用于方法优劣判断

`case_smoke` 只训练了 1 个 epoch，GAN 明显落后于 linear / cubic，这是正常现象。  
它的作用只是验证“病例级划分 + 训练 + 推理 + 评估”这条流水线可以完整运行，不应该拿来判断模型是否有效。

### 5. 旧 `full` 结果只能作为参考

旧 `full` 中 GAN 的表现也优于传统插值：

- PSNR：`35.5418`
- SSIM：`0.9145`

但旧 `full` 采用的不是病例级验证流程，而且当时还没有新增结构性指标，所以它更适合作为早期参考，不适合作为最终主结果。

## 三、目前结论

现阶段可以得到一个比较稳妥的判断：

1. 当前 GAN 方法已经优于传统插值基线，尤其体现在 PSNR、MSE、NCC、mask-PSNR 上。
2. 但它还没有在所有结构性指标上建立优势，说明现有损失函数和网络目标仍然偏向像素重建，而不是血管结构保持。
3. 当前最需要继续推进的，不是继续盲目增加 epoch，而是把“结构保持”真正纳入模型训练目标和评价体系。

## 四、下一步规划

### Phase 4：先把当前结果做扎实

1. 对 `case_full` 生成 visual QC 图，并按病例整理：
   - 最好病例
   - 最差病例
   - 典型血管断裂 / 边缘模糊区域

2. 补充统计：
   - 每个指标的 per-case 表
   - GAN 相对 linear / cubic 的提升量
   - 难例病例 `092 / 094 / 121` 的单独分析

3. 统一正式汇报口径：
   - 主结果只采用 `case_full`
   - 使用 `pix2pix_epoch_best.pth`
   - `case_smoke` 仅作流程验证

### Phase 5：把结构目标真正加进训练

优先考虑以下改动：

1. 在现有 L1 基础上加入 SSIM / MS-SSIM loss
2. 尝试 gradient loss 或 edge-aware loss，约束层间边缘连续性
3. 对前景区域加权，降低大面积背景对训练的主导作用
4. 若后续接入分割标签，可加入 segmentation-aware loss 或 vessel-aware loss

这一步的目标不是简单提高 PSNR，而是争取同时提升：

- mask-SSIM
- auto-Dice
- auto-HD95

### Phase 6：建立更可信的结构评估

当前 `auto-Dice / auto-HD95` 只是自动前景 mask 的代理指标。后续应至少完成一项：

1. 在有标签的训练病例上做 held-out labeled evaluation，计算真正的 Dice / HD95
2. 引入现成血管分割模型，对 GT 和重建体分别做分割，再评价分割一致性

如果目标最终是服务血管结构分析，那么这一步会比继续堆 GAN 训练更重要。

### Phase 7：再考虑更新模型

在当前基线和评估体系稳定后，再进入新模型比较更合适。候选方向可以包括：

1. diffusion-based interpolation / restoration
2. 3D 或 2.5D transformer / UNet 结构
3. 结合跨切片注意力的 video-style frame interpolation 思路
4. 以分割一致性为导向的联合训练

建议顺序是：

1. 先把现有 GAN 的结构损失补强
2. 再拿 1-2 个新模型做替代
3. 最后用统一的 case-level split 和统一指标做横向比较

## 五、下一次最值得立刻做的事

下一步最实用、投入产出比最高的动作是：

1. 给 `case_full` 补一套 visual QC 图
2. 在当前 GAN 中加入 `SSIM / gradient / foreground-weighted` 训练损失
3. 重新跑一次病例级 full，并与当前 `case_full` 做严格对照

这样下一轮实验就能回答一个真正有价值的问题：  
**在不牺牲整体重建质量的前提下，能不能让模型对血管结构更友好。**

## 八、GAN 阶段结论

到这里，GAN 这条线可以先收工：

1. 数据划分已经改成病例级
2. best checkpoint 选择、学习率调度和 early stopping 已经规范化
3. 当前结果已有：
   - 官方验证集上的整体重建指标
   - 逐病例分析
   - visual QC
   - 真实血管标签引导的 holdout 结构评估
4. 训练目标已经从“主要做像素重建”推进到“同时约束边缘和前景结构”

后续如果继续投入精力，优先级不应再是继续微调当前 GAN，而应转向：

1. 训练或接入血管分割模型，得到真正的 segmentation Dice / HD95
2. 选择 1-2 个更新模型做横向替代比较
3. 用现在这套统一的 case-level split 和指标体系做公平实验
