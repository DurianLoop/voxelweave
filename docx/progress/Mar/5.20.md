## 二、TopCaw2024：当前主实验与结构评价基准

本地结构：

```text
dataset\TopCaw2024
  imagesTr: 250
  imagesVal: 10
  cow_seg_labelsTr: 250
```

从文件名看，`imagesTr` 同时包含 CT 和 MR：

```text
topcow_ct_xxx_0000.nii.gz
topcow_mr_xxx_0000.nii.gz
```

标签目录 `cow_seg_labelsTr` 也对应 CT / MR 的血管结构标签。

### 定位

TopCaw 是当前最适合作为第一阶段主数据集的原因：

1. 有 MR 图像
2. 有血管标签
3. 和当前任务“层间插值 / through-plane super-resolution”高度相关
4. 可以评价重建后的血管结构保持能力

### 当前已经完成的工作

GAN 主线已经在 `topcow_gan` 中阶段性收工：

- 病例级划分
- best checkpoint
- early stopping / LR scheduler
- visual QC
- 逐病例分析
- PSNR / SSIM / MAE / MSE / NCC 等基础指标
- mask-PSNR / mask-SSIM / auto-Dice / auto-HD95 等结构代理指标
- 使用真实血管标签的 labeled holdout 评估

### 适合承担的论文角色

TopCaw 应该作为：

```text
主方法验证数据集 + 血管结构保持评价数据集
```

它适合回答：

```text
模型能不能在脑血管相关 MRI 上恢复层间细节？
模型是否比 linear / cubic / GAN baseline 更好？
生成的中间切片是否更保护血管边界？
```

但 TopCaw 不足以单独支撑 foundation model，因为它：

- 数据量相对有限
- 解剖部位集中
- 任务集中在脑血管
- 模态和扫描协议多样性有限

## 三、CAS2023：跨数据集结构泛化验证

本地结构：

```text
dataset\CAS2023
  data: 100
  mask: 100
```

### 定位

CAS2023 的最大价值不是替代 TopCaw，而是作为第二个结构数据集，用来测试模型是否只是在 TopCaw 上过拟合。

它应该承担：

```text
跨数据集泛化验证 + 结构 mask 评价
```

建议实验方式：

1. `TopCaw train -> CAS2023 test`
2. `TopCaw + CAS2023 train -> TopCaw / CAS2023 test`
3. `TopCaw train -> CAS2023 finetune small subset -> CAS2023 test`

### 适合回答的问题

```text
模型学到的是通用层间结构恢复，还是只记住了 TopCaw 的数据分布？
模型能否迁移到另一个有 mask 的血管/结构数据集？
结构性指标在跨数据集上是否仍然稳定？
```

### 当前需要补的工作

CAS2023 需要先做数据审计：

- 每个病例的 shape
- spacing
- mask label 的语义
- 是否为 MRI
- 是否和 TopCaw 的方向 / 分辨率 / 强度范围一致

之后再决定是否直接纳入统一训练。

## 五、近两年文献中的数据集使用趋势

### 1. Foundation model 论文不是只用一个数据集

2025 年 Nature Biomedical Engineering 的 MRI enhancement foundation model 是一个很重要的参照。  
该工作面向 motion correction、resolution enhancement、denoising、harmonization 等多任务 MRI enhancement，使用了大规模、多年龄段、多扫描仪来源数据。

文中报告：

- 2,448 张人为退化图像
- 10,963 张真实低质量图像
- 覆盖 19 个公开数据集
- 覆盖胎儿到老年人的全生命周期
- 覆盖多种临床扫描仪

其公开数据来源包括：

```text
dHCP
NDAR
BCP
SALD
CCNP
DLBS
IXI
Chinese Adult Brain
ABIDE
ABVIB
ADNI
AIBL
HBN
HCP
ICBM
OASIS3
SLIM
MR-ART
```

这说明如果要讲 foundation model，数据集数量和异质性非常关键。  
只在 TopCaw 上做，很难叫 foundation model；最多是一个 task-specific model。

参考：

- Nature Biomedical Engineering 2025, *A foundation model for enhancing magnetic resonance images and downstream segmentation, registration and diagnostic tasks*  
  https://www.nature.com/articles/s41551-024-01283-7

### 2. 2026 diffusion super-resolution 论文强调跨解剖验证

`Scale-Cascaded Diffusion Models for Super-Resolution in Medical Imaging` 明确在：

```text
brain MRI
knee MRI
prostate MRI
```

上评估其 diffusion SR 方法。

这类设置很适合我们参考：  
不是只证明一个数据集上 PSNR 更高，而是证明模型能跨 anatomy 工作。

参考：

- arXiv 2026, *Scale-Cascaded Diffusion Models for Super-Resolution in Medical Imaging*  
  https://arxiv.org/abs/2601.23201

### 3. 大规模 MRI restoration / denoising 论文重视多中心、多协议

2026 年 real-world fast MRI denoising 工作使用了多器官、多协议、大规模临床数据。文献摘要中提到：

- 148,930 对 noisy-clean MRI slices
- 6 个解剖区域
- 96 个 MRI protocols
- 多厂商扫描仪

这类工作说明，如果目标是通用 MRI restoration，后续最好补：

```text
多中心
多厂商
多协议
多解剖部位
```

参考：

- npj Digital Medicine 2026, *Real-world unified denoising for multi-organ fast MRI: a large-scale prospective validation*  
  https://www.nature.com/articles/s41746-026-02548-y

### 4. reconstruction / SR 方向常用 fastMRI

fastMRI 是 MRI reconstruction / SR / restoration 方向非常重要的数据集。  
它提供 raw k-space 和 DICOM，覆盖 knee、brain、prostate 等方向。

公开信息中提到：

- knee MRI k-space
- brain MRI
- prostate MRI
- 大规模临床 MRI 数据

如果我们要从“图像域插值”扩展到“更正统的 MRI reconstruction / restoration foundation model”，fastMRI 很值得加入。

参考：

## 六、建议后续补充的数据集

按优先级排序。

### 第一优先级：IXI

原因：

- 脑 MRI
- T1 / T2 / PD 多模态
- 和 MRI SR 文献非常常见
- 数据相对好处理
- 适合补“脑 MRI 通用预训练”

用途：

```text
IXI pretrain
TopCaw finetune
CAS2023 external test
```

### 第二优先级：fastMRI

原因：

- reconstruction / restoration 领域标准数据集
- 数据量大
- 有 knee / brain / prostate
- 可支撑跨解剖泛化

用途：

```text
fastMRI knee/brain/prostate pretrain
TopCaw / CAS finetune
OAI-ZIB external test
```

注意：fastMRI 有 k-space，处理成本比 NIfTI 图像更高。  
如果前期只做图像域 SR，可以先用官方重建图像或 DICOM，不一定马上处理 k-space。

### 第三优先级：OASIS3 或 ADNI

原因：

- 老年 / 病理 / 纵向脑 MRI
- 可以支撑“年龄 / 病理泛化”
- foundation model 论文里常见

用途：

```text
训练：IXI / HCP / OAI
测试：OASIS3 / ADNI
```

### 第四优先级：HCP

原因：

- 高质量脑 MRI
- 数据规模大
- 适合做高质量 HR target

缺点：

- 数据管理较复杂
- 下载和预处理成本更高

### 第五优先级：BraTS

原因：

- 多模态脑肿瘤 MRI
- 病灶场景明显
- 可测试模型是否 hallucinate 或破坏病灶结构

用途：

```text
pathology generalization / lesion-preserving evaluation
```

## 九、当前结论

目前已有数据集的定位应该是：

```text
TopCaw2024 = 主结果 + 血管结构评价
CAS2023    = 跨数据集结构泛化
OAI-ZIB    = 大规模预训练 / 跨解剖泛化
```

如果要往 foundation model 方向走，后续最应该补的是：

```text
IXI
fastMRI
OASIS3 / ADNI
HCP
BraTS
```

其中最优先的是：

```text
IXI + fastMRI
```

因为它们分别补上了：

```text
脑 MRI 多模态通用性
MRI reconstruction / SR 标准大规模 benchmark
```

这会比继续只在 TopCaw 上调模型更符合 foundation model 的叙事。

## 十、重新校准：不必一开始就以 foundation model 为目标

更现实、也更适合当前阶段的路线是：

```text
先在 TopCaw / CAS / OAI 这样的小到中等规模数据上做出一个清楚的方法创新
-> 用严谨指标和可视化证明它确实解决了一个具体问题
-> 再逐步扩展到 IXI / fastMRI / OASIS / BraTS 等数据集证明泛化
-> 最后如果数据规模、任务范围和预训练方式都足够，再升级为 foundation model 叙事
```

也就是说，当前论文不一定要写成“我提出了一个 MRI foundation model”。更合适的第一篇叙事可能是：

```text
结构保持的 MRI 层间插值 / through-plane super-resolution 方法
面向小血管结构、薄层细节和真实标签引导评估
```

foundation model 可以作为后续扩展目标，而不是一开始就给自己设置过大的门槛。

## 十一、reading 里几篇文章的创新方式和验证套路

### 1. Partial Diffusion Models, IEEE TMI 2025

PDF：

```text
reading\MRI Super-Resolution with Partial Diffusion Models.pdf
```

核心创新：

这篇文章的创新不是换一个更大的网络，而是观察到 LR 和 HR 图像在扩散到一定噪声水平后，latent 分布会逐渐接近。因此它不再从纯噪声完整反推 HR，而是用 LR latent 近似 HR latent，跳过一部分扩散和反扩散步骤。

方法关键词：

```text
Partial Diffusion Models
latent convergence
latent alignment
fewer denoising steps
```

验证数据集：

```text
ProstateX
fastMRI knee
Clinical Prostate
```

实验设计：

- 做 in-plane SR：2x 和 4x
- 做 through-plane SR：模拟各向异性 MRI 的层间超分
- 做下游任务：前列腺 zonal segmentation
- 指标包括 PSNR、SSIM、Consistency、运行时间
- 有 ablation，专门验证 latent alignment 和不同 K 步数的影响

对我们的启发：

它和我们的层间插值任务非常贴近。我们也可以不追求“更大模型”，而是提出一种更适合层间插值的 diffusion 轨迹，例如从相邻真实切片出发，而不是从纯噪声出发。

### 2. LearnDiff, CMIG 2025

PDF：

```text
reading\LearnDiff MRI image super-resolution using a diffusion model with.pdf
```

核心创新：

标准 diffusion 假设噪声来自固定标准正态分布。LearnDiff 认为 MRI SR 中这种固定噪声不一定合适，于是让噪声分布的均值和方差可学习，使扩散过程能适应 MRI 数据本身的噪声结构。

方法关键词：

```text
learnable noise
learnable Gaussian distribution
MRI-specific noise modeling
```

验证数据集：

```text
OASIS
BraTS 2020
Prostate MRI
```

实验设计：

- OASIS 做 8x SR
- BraTS 做 4x SR
- Prostate MRI 做额外验证
- 指标包括 PSNR、SSIM、LPIPS、RMSE、MS-SSIM
- 做 cross-modality generalization：在 BraTS 上训练 FLAIR，再测试 T1、T1Gd、T2
- 做下游 tumor segmentation，证明 SR 不是只让图像好看，而是能改善结构任务

对我们的启发：

如果我们后续继续 diffusion，可以把“噪声/退化过程不是固定的”作为创新点。比如不同病例、不同血管区域、不同 z-spacing 的退化程度不同，模型应当自适应估计退化强度。

### 3. DiTMSR / Taming Diffusion Transformers, CBM 2025

PDF：

```text
reading\Taming diffusion transformers for high-fidelity MRI super-resolution.pdf
```

核心创新：

它认为 U-Net diffusion 在 MRI SR 中有两个问题：全局建模不足、latent decoder 不够强。因此用 conditional Diffusion Transformer 做 denoising，再用 Hybrid Mamba Decoder 恢复高分辨率细节，并加入 content preservation module 保持结构。

方法关键词：

```text
Diffusion Transformer
Hybrid Mamba Decoder
Content Preservation Module
frequency-domain loss
multi-contrast conditioning
```

验证数据集：

```text
fastMRI knee
BraTS
Clinical Brain
Clinical Tumor
Clinical Pelvic
```

实验设计：

- 同时做 public dataset 和 clinical dataset
- public 数据集：fastMRI、BraTS
- clinical 数据集：脑、肿瘤、盆腔
- 指标包括 PSNR、SSIM、FID、LPIPS
- 报告 Params、FLOPs
- 做 ablation：DiT backbone、Hybrid Mamba Decoder、CPM、reference guidance
- 做临床专家偏好实验

对我们的启发：

这篇是“架构创新 + 多数据集验证”的典型路线。但它的规模比我们当前阶段大很多。我们可以借鉴两个较轻量的点：结构保持模块和频域/结构域约束，而不是一开始复刻完整 DiT + Mamba。

### 4. MoEDiff-SR, arXiv 2025

PDF：

```text
reading\2025_MoEDiff-SR_Mixture_of_Experts-Guided_Diffusion_Model_for_Region-Adaptive_MRI_SR.pdf
```

核心创新：

它认为 MRI 不同解剖区域的纹理和结构不一样，统一 denoiser 容易过平滑。因此用 Mixture of Experts，让不同专家处理不同区域，例如白质、皮层沟回、灰白质交界等。

方法关键词：

```text
Mixture of Experts
region-adaptive denoising
token-level gating
expert specialization visualization
```

验证数据集：

```text
HCP 3T / 7T brain MRI
MGH clinical cases
```

实验设计：

- 做 3T 到 7T-like MRI SR
- 指标包括 PSNR、SSIM、LPIPS、RMSE、Params、FLOPs
- 做专家 specialization 可视化
- 做真实临床病例验证，例如 MS 病灶显示

对我们的启发：

TopCaw 里血管区域和非血管区域的重要性完全不同。这篇给我们的直接启发是：可以做“结构区域自适应”的方法，例如 vessel-aware gating、mask-guided expert、或者 vessel-prior weighted diffusion loss。

### 5. Geodesic Diffusion Models, arXiv 2025

PDF：

```text
reading\2025_Geodesic_Diffusion_Models_for_Efficient_Medical_Image_Enhancement.pdf
```

核心创新：

它从 diffusion noise schedule 入手，认为传统噪声调度不是最优路径，于是用 Fisher-Rao 几何下的 geodesic schedule，让扩散轨迹更短、更省步数。

方法关键词：

```text
geodesic noise schedule
Fisher-Rao metric
truncated sampling
efficient diffusion
```

验证数据集：

```text
CT denoising dataset
Prostate MRI super-resolution
```

实验设计：

- 两个医学图像增强任务：CT denoising 和 MRI SR
- MRI SR 中用相邻切片预测中心切片，和我们的层间插值非常接近
- 指标包括 PSNR、SSIM、MS-SSIM、HFEN、training time、inference time
- 做采样步数、截断噪声强度、noise schedule 的 ablation

对我们的启发：

如果我们想继续做 diffusion，一个很自然的创新方向是“面向 MRI 层间插值的高效采样路径”。这比堆大网络更贴近我们现有算力和数据规模。

### 6. Res-SRDiff, arXiv 2025

PDF：

```text
reading\2025_MRI_SR_using_Efficient_Diffusion_Probabilistic_Model_with_Residual_Shifting.pdf
```

核心创新：

它把 diffusion forward process 从“HR -> 纯噪声”改成“HR -> LR 分布”，通过 residual error shifting 让 reverse process 更像图像恢复，而不是从零生成图像。

方法关键词：

```text
residual shifting
efficient diffusion
Swin Transformer block
4 sampling steps
```

验证数据集：

```text
7T brain T1 MP2RAGE
public ProstateX / prostate MRI
```

实验设计：

- brain 和 prostate 两个数据集
- 与 Bicubic、Pix2pix、CycleGAN、SPSR、I2SB、TM-DDPM 比较
- 指标包括 PSNR、SSIM、GMSD、LPIPS
- 统计显著性检验
- Likert 图像质量评分
- ablation：是否使用 Swin Transformer block

对我们的启发：

这篇非常适合我们当前阶段借鉴。我们已经有 GAN baseline 和 diffusion baseline，下一步可以提出“相邻切片残差引导的 diffusion/interpolation”，把目标从纯生成改成受相邻真实切片约束的恢复。

### 7. Scale-Cascaded Diffusion, ISBI/arXiv 2026

PDF：

```text
reading\2026_Scale-Cascaded_Diffusion_Models_for_Super-Resolution_in_Medical_Imaging.pdf
```

核心创新：

它把图像拆成 Laplacian pyramid 多尺度频带，在不同尺度训练 diffusion prior，再用 scale-cascaded posterior sampling 逐级恢复高频。

方法关键词：

```text
Laplacian pyramid
scale-cascaded diffusion prior
posterior sampling
multi-anatomy MRI
```

验证数据集：

```text
fastMRI brain
fastMRI knee
fastMRI prostate
```

实验设计：

- 2x 和 4x SR
- 跨 brain / knee / prostate 三个解剖部位
- 指标包括 PSNR、SSIM、LPIPS
- 和 DiffPIR、DPS、Multi-Grid PnP 比较

对我们的启发：

这篇说明“泛化”不一定一开始就用 19 个数据集。三个解剖部位就已经能支撑一个比较强的跨解剖泛化叙事。我们后续可以用 TopCaw/CAS/OAI 先形成三数据集版本，再加 fastMRI。

### 8. Likelihood-Separable Diffusion Inference, arXiv 2026

PDF：

```text
reading\2026_Likelihood-Separable_Diffusion_Inference_for_Multi-Image_MRI_Super-Resolution.pdf
```

核心创新：

它解决的是 multi-image super-resolution：不是只用一组 LR 输入，而是利用不同方向、不同分辨率的多个低分辨率观测。它把多个观测的 likelihood 分开建模，并做 noise-weighted posterior sampling。

方法关键词：

```text
multi-image super-resolution
orthogonal-plane acquisitions
likelihood separation
noise-weighted posterior sampling
3D volumetric diffusion
```

验证数据集：

```text
AIBL
SLEEP
pretrained 3D brain MRI diffusion model from 36 open datasets
```

实验设计：

- 做 4x / 8x / 16x through-plane degradation
- 比较 SISR 和 MISR
- 使用 axial、coronal、sagittal 多方向低分辨率输入
- 指标包括 PSNR、SSIM、FID
- 共 100 subjects，两个 withheld sites 做测试

对我们的启发：

这篇和“层间插值”高度相关，但它做得更进一步：从 single-direction interpolation 升级到 multi-plane / multi-image interpolation。我们当前可以先做 TopCaw 的单方向插值，后续如果数据允许，再扩展到多方向一致性。

## 十二、这些文章共同的论文套路

这些文章大多不是先说“我要做 foundation model”，而是遵循下面这个逻辑：

```text
1. 找一个明确痛点
   采样太慢 / 结构不稳 / 区域差异大 / 多方向信息没用上 / 固定噪声不合适

2. 提出一个小而清楚的方法创新
   partial diffusion / residual shift / learnable noise / MoE gating / geodesic schedule / scale cascade

3. 在一个主数据集上做扎实
   指标、可视化、逐病例、消融、训练细节

4. 再扩展到 2-5 个数据集证明泛化
   public + clinical，或者 brain + knee + prostate，或者 train modality -> unseen modality

5. 最后补充临床可信度
   下游分割、专家评分、结构指标、显著性检验、运行时间
```

这正好对应我们现在应该走的路线。

## 十三、建议我们现在采用的论文路线

当前最适合你的不是“直接做 foundation model”，而是：

```text
阶段 A：TopCaw 小规模方法创新
```

目标：

```text
提出一个 vessel-aware / structure-aware / residual-guided 的 MRI 层间插值方法
```

主实验：

```text
TopCaw case-level split
linear / cubic / GAN / diffusion baseline / ours
PSNR, SSIM, RMSE, MAE, LPIPS
mask-PSNR, mask-SSIM, Dice, HD95
per-case analysis
visual QC
```

```text
阶段 B：CAS2023 外部结构验证
```

目标：

```text
证明方法不是只在 TopCaw 有效，而是在另一个血管结构数据集上仍然保结构
```

```text
阶段 C：OAI-ZIB 或 fastMRI 跨解剖验证
```

目标：

```text
证明方法对非脑血管 MRI 也有基本泛化能力
```

```text
阶段 D：再考虑 foundation model
```

只有当我们已经完成多数据集统一索引、预训练、跨数据集测试之后，再把叙事升级成：

```text
multi-dataset MRI interpolation / restoration foundation model
```

这样写论文会更稳：先有一个清楚的新方法，再让数据规模和泛化实验逐步支撑更大的说法。

## 十四、TopCaw、IXI、fastMRI 在当前阶段的定位修正

目前从公开文献来看，TopCaw / TopCoW 更多被用于 Circle of Willis 血管分割、拓扑保持评估、centerline graph 和 challenge benchmark。它的强项是：

```text
脑血管结构
真实 vessel mask
拓扑敏感评估
CTA / MRA vascular anatomy
```

但它不是 MRI super-resolution / through-plane interpolation 方向最常见的主流 benchmark。因此，当前使用 TopCaw 的定位应该更明确：

```text
TopCaw = 方法可行性验证 + 血管结构保持验证 + 小规模快速试错
```

它适合回答：

```text
我的 pipeline 能不能跑通？
case-level split、checkpoint、指标、可视化是否规范？
方法是否真的保护小血管结构？
结构 mask 指标是否比普通 PSNR / SSIM 更能体现优势？
```

但它不适合单独回答：

```text
我的方法是否已经达到 MRI SR 领域 SOTA？
我的方法是否能代表通用 MRI interpolation / restoration？
```

如果要知道自己离 SOTA 还有多远，后续应该把创新方法迁移到更权威、更常见的数据集上。

### 建议的权威数据集路线

第一优先级：

```text
IXI
fastMRI
```

原因：

```text
IXI = 经典 brain MRI SR / restoration 数据集，适合做脑 MRI 通用方法验证
fastMRI = MRI reconstruction / SR 领域最有辨识度的数据集之一，适合和主流论文对齐
```

推荐实验节奏：

```text
Step 1: TopCaw 上快速验证方法可行
Step 2: IXI 上做正式 brain MRI SR / interpolation 主实验
Step 3: fastMRI brain 或 knee 上对齐主流 SOTA 指标
Step 4: 回到 TopCaw / CAS 做血管结构和真实 mask holdout 评估
```

这样论文叙事会更合理：

```text
IXI / fastMRI 证明方法在权威 MRI SR benchmark 上有竞争力
TopCaw / CAS 证明方法在血管结构保持上有额外优势
OAI-ZIB 或 fastMRI knee/prostate 证明跨解剖泛化
```

### 当前更推荐的主线

不建议把 TopCaw 直接写成主 benchmark，而是把它作为结构验证数据集：

```text
主 benchmark:
  IXI
  fastMRI brain / knee

结构验证:
  TopCaw
  CAS2023

跨解剖泛化:
  OAI-ZIB
  fastMRI knee / prostate
```

这样你既能保留当前已经完成的 TopCaw 工作，又不会被“为什么主流论文不用 TopCaw”这个问题卡住。TopCaw 的价值不是对标所有 MRI SR 论文，而是提供其他 benchmark 缺少的血管结构标签，让你的方法可以强调 clinically relevant structure preservation。
