## 十、方向核对：相邻切片辅助 diffusion 是否合理

结论：合理，而且和我们的具体任务高度一致。

更准确的说，我们现在不是泛泛地“用低分辨率图片辅助扩散”，而是在做：

```text
已观测相邻切片 z 和 z+k
    -> 作为 through-plane low-resolution / sparse observation
生成缺失中间切片 z+1 ... z+k-1
    -> 补足各向异性 MRI 的层间分辨率
```

这和医学图像 inter-slice interpolation / through-plane super-resolution 的问题设定是一致的。

### 1. HiFi-Diff 直接支持这个方向

HiFi-Diff，全名 `Arbitrary Reduction of MRI Inter-slice Spacing Using Hierarchical Feature Conditional Diffusion`，任务就是减少 MR 层间距。

它的核心设定是：

```text
input:
  two adjacent MR slices
  relative positional offset

output:
  any desired in-between MR slice

sampling:
  diffusion 从 Gaussian noise 逐步生成中间切片
```

这和我们现在的 `z, z+4 -> z+1,z+2,z+3` 非常接近。

我们当前代码和 HiFi-Diff 的差距主要在：

```text
1. 条件编码器太弱
2. 还没有 hierarchical feature conditioning
3. 相对位置只是简单 channel，不是强位置建模
4. U-Net 规模较小
5. 没有针对 arbitrary-scale inter-slice SR 做专门结构设计
```

所以，方向是对的，但当前 vanilla diffusion 实现还太粗。

### 2. 2025 TMI 的 Partial Diffusion Models 说明 pure-noise 不是唯一做法

`MRI Super-Resolution with Partial Diffusion Models` 在 2025 年发表于 IEEE TMI。

它的关键信息是：

```text
MRI SR 可以分为 in-plane SR 和 through-plane SR。
plain diffusion 从纯噪声开始成本高、约束弱。
PDM 让扩散从中间 latent 状态开始，并利用低分辨率图像的 latent 近似高分辨率 latent。
```

这支持我们后续从 pure-noise 转向：

```text
partial diffusion
coarse-to-fine diffusion
linear/cubic coarse + refinement
```

但它不等于所有论文都用 linear residual。

### 3. 2026 multi-image MRI SR 支持“多观测约束”

`Likelihood-Separable Diffusion Inference for Multi-Image MRI Super-Resolution` 讨论的是 MRI 中多个互补低分辨率观测的问题。

它强调 MRI 常见场景不是单张图恢复，而是多个低分辨率测量互相补充，并用 diffusion posterior / likelihood 约束生成结果。

这对我们的启发是：

```text
相邻切片、不同方向重采样、多模态或多平面观测，都可以作为条件约束；
扩散模型不应该只靠随机噪声和弱条件自己幻想整张图。
```

### 4. 2025/2026 cycle-consistent through-plane SR 提醒要防 hallucination

`Cycle-Consistent Zero-Shot Through-Plane Super-Resolution for Anisotropic Head MRI` 明确讨论 anisotropic head MRI 的 through-plane SR。

它的核心问题不是单纯追求图像好看，而是担心深度模型生成 hallucination。

它通过 cycle-consistency 让高分辨率估计重新退化后能严格对应低分辨率观测。

这说明后续我们不能只报 PSNR/SSIM，还需要强调：

```text
data consistency
cycle consistency
slice consistency
结构一致性
```

## 十一、当前方法路线修正

可以继续做 diffusion，但不要把当前 vanilla pure-noise 版本当最终方案。

更稳的下一步是：

```text
Stage A: 建立确定性 interpolation baseline
  input: z, z+k, relative position
  output: z+r
  model: 2D/2.5D U-Net or ResUNet
  loss: L1 + SSIM + gradient/edge loss

Stage B: 做 HiFi-Diff-like 条件 diffusion
  input: z, z+k, relative position
  model: stronger conditional encoder + position embedding
  output: arbitrary in-between slice

Stage C: 加强医学可信度
  linear/cubic coarse consistency
  cycle/data consistency
  intensity sanity check
  per-case visual QC

Stage D: 再考虑创新点
  residual/refinement diffusion
  partial diffusion
  uncertainty map
  structure-aware or edge-aware loss
  multi-plane / multi-contrast conditioning
```

阶段判断：

```text
“相邻切片辅助 diffusion”不是无用功；
它是医学 MRI inter-slice interpolation / through-plane SR 的正当方向。

但当前 pure-noise 代码只是最小验证版；
如果继续做论文方法，需要升级成强条件、强约束、可解释的 interpolation diffusion。
```

```text

  left observed slice
```
