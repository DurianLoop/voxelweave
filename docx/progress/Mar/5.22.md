# 5.21 MRI 插值 / Through-plane SR 文献梳理与方向判断

## 一、这次阅读的定位

这次不是逐篇翻译，而是围绕我们的任务做方向型阅读：

```text
任务:
  MRI inter-slice interpolation
  through-plane super-resolution
  anisotropic MRI isotropic reconstruction

我们的具体设定:
  输入相邻切片 z 和 z+k
  生成中间切片 z+1 ... z+k-1
  当前重点数据集: TopCaw, IXI
```

我按关键词、引用链和近两年方法趋势筛查了约 100 篇相关工作，重点看它们怎么定义问题、用什么条件输入、怎么避免 hallucination、怎么评价，以及有什么可以转化成我们自己的创新点。

## 二、最重要的总判断

我们的方向不是“低分辨率图片辅助扩散”这么泛，而是：

```text
相邻已观测切片 + 相对空间位置
  -> 约束生成缺失中间切片
  -> 提升 through-plane resolution
```

这个方向是成立的，而且已经有强相关论文直接这样做。

但我们当前代码还远弱于这些论文：

```text
目前:
  简单 U-Net
  简单位置 channel
  简单 residual / partial diffusion
  没有强条件编码器
  没有 cycle/data consistency
  没有跨视角/跨模态约束

文献趋势:
  强条件特征调制
  arbitrary-scale interpolation
  cycle consistency
  slice-profile / acquisition operator
  partial diffusion / posterior sampling
  implicit neural representation
  multi-view / multi-contrast constraints
```

所以，不应该放弃 diffusion，但也不能继续用 vanilla diffusion 硬跑。下一步应做“强约束的相邻切片条件生成”。

## 三、文献主线 1：传统插值和模型驱动 SRR 是底线

代表思路：

```text
linear / cubic / B-spline / Fourier interpolation
multi-acquisition SRR
sparse coding SR
TV / bilateral TV / multi-scale gradient prior
slice-profile acquisition model
```

这些方法通常不是 SOTA，但非常重要，因为它们是论文里的强 baseline。

关键启发：

```text
1. linear/cubic 不能只当玩具 baseline，它们在 MRI 插值里经常很强。
2. MRI through-plane SR 不是普通自然图像超分，必须考虑 slice thickness / slice gap / slice profile。
3. 任何生成方法都要和观测切片保持 data consistency，否则容易 hallucination。
```

我们现在看到 diffusion 低于 linear，其实不意外。许多论文也强调，简单深度模型如果没有物理约束，未必稳过传统插值。

代表文献：

```text
MRI inter-slice reconstruction using super-resolution
MRI superresolution using self-similarity and image priors
Isotropic MRI SRR with multi-scale gradient field prior
DeepResolve / clinical MRI AI super-resolution
```

## 四、文献主线 2：相邻切片条件插值是正路

这一类和我们最贴近。

典型设定：

```text
input:
  two adjacent slices
  sometimes extra spatial position / spacing / scale

output:
  one or multiple intermediate slices
```

代表工作：

```text
SAINT: Spatially Aware Interpolation Network for Medical Slice Synthesis, CVPR 2020
Deep Slice Interpolation via Marginal SR, Fusion and Refinement
TSCNet: Two-Stage Self-Supervised Cycle-Consistency Network for Thin-Slice MR
Autoencoding Low-resolution MRI for Semantically Smooth Interpolation
I3Net: Inter-Intra-slice Interpolation Network
PixelMiner for texture accurate medical slice interpolation
HiFi-Diff: adjacent MR slices + relative position + diffusion
```

关键共识：

```text
1. 只输入一张 LR 图不够，邻近切片是最直接、最可信的信息源。
2. 位置/spacing/scale 要显式输入，否则模型不知道生成第几个中间层。
3. 生成的中间切片要在滚动浏览时连续，不能只看单张 PSNR。
4. arbitrary-scale 是临床友好的卖点，因为真实 slice gap 不固定。
```

这说明我们当前 `z,z+4 -> z+1,z+2,z+3` 的问题设定是合理的。

## 五、文献主线 3：HiFi-Diff 是目前最贴近我们的 diffusion 参考

HiFi-Diff 的核心设定：

```text
input:
  two adjacent MR slices
  relative positional offset

model:
  hierarchical feature extraction
  conditional diffusion
  feature modulation

output:
  arbitrary desired in-between slice
```

它最值得我们借鉴的不是“用了 diffusion”四个字，而是：

```text
1. 用相邻切片做强条件。
2. 用相对位置支持任意层间比例。
3. 用 hierarchical feature conditioning，而不是简单拼 channel。
4. 评价下游 segmentation，证明生成不是只为 PSNR 好看。
```

我们现在的 `hifidiff.py` 只是最小原型：

```text
left/right/coarse/relative_position
residual target
partial diffusion from zero residual
```

它比 pure-noise 稳，但还没达到 HiFi-Diff 的强条件程度。

## 六、文献主线 4：partial diffusion / posterior diffusion 更适合恢复任务

相关论文里有一个越来越明确的趋势：

```text
不要把 restoration 当作无条件生成。
不要从纯噪声自由幻想整张图。
要从 LR/coarse/measurement constraint 出发。
```

代表方向：

```text
Partial Diffusion Models for MRI SR
DPS / DDNM / posterior sampling
Likelihood-Separable Diffusion for Multi-Image MRI SR
diffusion plug-and-play / ADMM
residual or bridge diffusion
```

这和我们实验完全吻合：

```text
pure-noise diffusion:
  TopCaw / IXI 都强度崩坏

residual + partial diffusion:
  强度 p99 接近 GT
  但 median 偏低，指标仍低于 linear
```

所以下一步不是回退，而是继续加强约束。

## 七、文献主线 5：cycle consistency 和 data consistency 是防 hallucination 的关键

医学图像生成不能只讲“看起来更清楚”。近两年的文章很强调：

```text
hallucination risk
cycle consistency
data consistency
slice-profile operator
re-degradation consistency
```

代表工作：

```text
Cycle-Consistent Zero-Shot Through-Plane SR for Anisotropic Head MRI
TSCNet self-supervised cycle consistency
Incremental cross-view mutual distillation
DDNM / DPS-style diffusion inverse problem
```

可转化成我们的约束：

```text
生成完整 HR volume
  -> 按原始 stride 下采样
  -> 必须回到原始 sparse volume

或者:
  predicted z+1,z+2,z+3 和 z,z+4 拼成 HR
  再做 slice averaging / blur / decimation
  应该重建原始 observed z,z+4
```

这是一个很适合写进方法创新的点。

## 八、文献主线 6：INR / 连续坐标是另一个强创新方向

INR 类方法把体数据看成连续函数：

```text
f(x, y, z, modality/contrast) -> intensity
```

优势：

```text
1. 天然支持 arbitrary scale。
2. 可以在任意 z 位置采样。
3. 更适合表示连续解剖结构。
4. 可以结合单病例 test-time optimization。
```

代表工作：

```text
CycleINR for arbitrary-scale volumetric SR
Single-subject multi-view MRI SR via INR
SeCo-INR
implicit neural representation for anisotropic medical volumes
```

对我们的启发：

```text
diffusion 可以做纹理/不确定性；
INR 可以做连续空间建模；
两者可结合成 coordinate-conditioned diffusion 或 INR-guided diffusion。
```

这比单纯“再换一个 U-Net”更像论文创新。

## 九、文献主线 7：multi-view / multi-contrast 是更强的后续扩展

很多高水平 MRI SR 论文不只用单个 volume。

常见设定：

```text
orthogonal axial/coronal/sagittal scans
T1/T2/PD 多模态
3T/7T paired or guided SR
multi-contrast reference
multi-image posterior sampling
```

代表工作：

```text
Likelihood-Separable Diffusion Inference for Multi-Image MRI SR
TESLA: Test-time Reference-free Through-plane SR for Multi-contrast Brain MRI
Transformer-empowered multi-contrast MRI SR
7T-guided SR of 3T MRI
multi-input cardiac MRI SR
SIMS-MRI: single-subject multi-view MRI SR via INR
```

对我们后续数据集的意义：

```text
IXI 有 T1/T2/PD，是天然的 multi-contrast 数据。
TopCaw 可做结构验证，但不适合作为主 SOTA 数据。
fastMRI 更适合补充 MRI reconstruction/SR 叙事，不一定适合相邻切片插值主线。
```

如果老师希望更像 foundation model，multi-contrast / multi-dataset 是必经阶段。

## 十、约 100 篇文献筛查后的方法谱系

这 100 篇左右大致可以分成 10 类：

```text
1. 传统插值:
   linear, cubic, B-spline, Fourier interpolation

2. 模型驱动 MRI SRR:
   multi-acquisition SRR, slice-profile modeling, TV/MSTV, gradient prior

3. 监督 CNN SR:
   SRCNN-like, DCSRN, mDCSRN, RDN, 3D CNN, ResUNet

4. 相邻切片插值:
   SAINT, Deep Slice Interpolation, I3Net, PixelMiner

5. 自监督 MRI 插值:
   TSCNet, SSR, zero-shot anisotropic MRI SR

6. cycle/data-consistent SR:
   cycle-consistent through-plane SR, cross-view mutual distillation

7. diffusion restoration:
   HiFi-Diff, Partial Diffusion Models, DPS/DDNM/PnP/ADMM

8. multi-image / multi-view MRI SR:
   likelihood-separable diffusion, orthogonal-plane SRR, SIMS-MRI

9. multi-contrast MRI SR:
   TESLA, multi-contrast transformer SR, 7T-guided SR

10. INR / continuous representation:
   CycleINR, SeCo-INR, single-subject implicit MRI SR
```

这个谱系里，最适合我们当前阶段的是：

```text
相邻切片条件
+ arbitrary relative position
+ residual / partial diffusion
+ cycle/data consistency
+ optional INR continuous z embedding
```

## 十一、我们现在该怎么定下一步方向

我建议把下一步定成：

```text
不是 “做一个普通 diffusion baseline”
而是 “做一个 data-consistent adjacent-slice conditional interpolation model”
```

论文叙事可以是：

```text
Problem:
  临床 MRI 常见 through-plane 分辨率不足。
  传统 linear/cubic 稳但模糊。
  纯生成 diffusion 容易 hallucination / 强度漂移。

Method:
  用相邻切片和相对位置作为条件。
  用 linear/cubic coarse 保证基础强度和结构。
  diffusion 只学习 residual / uncertainty。
  加入 cycle/data consistency，保证回采样后与原始 sparse volume 一致。

Validation:
  IXI 上做主实验。
  TopCaw 做血管结构验证。
  后续扩展 HCP/OASIS/ADNI/ABIDE 或 fastMRI。
```

## 十二、最值得尝试的 6 个创新点

### 1. HiFi-Diff-style hierarchical condition encoder

不要只把 left/right/coarse/position 拼 channel。

改成：

```text
condition encoder 提取多尺度特征
U-Net 每层用 FiLM / cross-attention / adaptive normalization 调制
```

这最贴近 HiFi-Diff，也最容易提升当前结果。

### 2. Cycle/data consistency loss

训练时加入：

```text
pred_hr -> degrade/downsample -> sparse_lr
loss = sparse_lr reconstruction error
```

这个创新点医学可信度强，能回答 hallucination 质疑。

### 3. Relative position continuous embedding

当前是简单 position map。可以升级成：

```text
sin/cos positional encoding
MLP embedding
scale-aware modulation
```

目标是支持 arbitrary slice gap，而不是固定 stride=4。

### 4. Residual uncertainty diffusion

让模型输出：

```text
mean residual
uncertainty / variance map
diffusion residual sample
```

这样可以解释哪些区域是模型不确定的，医学论文里很有价值。

### 5. Structure-aware loss

加入：

```text
gradient loss
edge loss
Laplacian loss
vessel/structure weighted loss
slice continuity loss
```

TopCaw 可以在这里发挥作用。

### 6. IXI multi-contrast conditioning

用 IXI 的 T1/T2/PD 做：

```text
input:
  PD adjacent slices
  optional T1/T2 aligned context

output:
  PD intermediate slice
```

或做 multi-task：

```text
同一个模型支持 T1/T2/PD 插值。
```

这个方向更接近 foundation / generalist model。

## 十三、当前 full 训练期间应该关注什么

你的 `hifidiff_full` 正在跑时，先不用只盯 GPU 占用，要关注这些：

```text
1. train_loss 是否持续下降
2. val_loss 是否下降
3. training_history.csv 里 best_val 是否更新
4. 训练完 intensity_sanity.csv 里 diffusion median / p99 是否接近 GT
5. PSNR/SSIM 是否至少接近 linear/cubic
```

如果 full 仍然低于 linear/cubic，结论不是 diffusion 方向错，而是：

```text
当前条件编码器不够强；
需要加入 hierarchical conditioning 和 cycle/data consistency。
```

## 十四、建议的下一步执行顺序

### Step 1：等 hifidiff_full 跑完

先看：

```text
ixi_diffusion/runs/hifidiff_full/metrics/summary_metrics.csv
ixi_diffusion/runs/hifidiff_full/metrics/intensity_sanity.csv
ixi_diffusion/runs/hifidiff_full/training_history.csv
```

判断它是否至少接近 linear/cubic。

### Step 2：实现强条件编码器

把当前简单拼接改成：

```text
condition encoder
multi-scale feature injection
FiLM / attention modulation
```

这是最像 HiFi-Diff、也最可能提升结果的一步。

### Step 3：加入 cycle/data consistency

新增 loss：

```text
predicted HR volume downsampled back to sparse volume
must match original sparse volume
```

这是我们区别于普通 diffusion baseline 的核心医学可信度创新点。

### Step 4：再加 continuous relative position

支持任意 offset：

```text
0.25
0.50
0.75
任意 0-1 位置
```

之后可以把任务从固定 4x 插值扩展为 arbitrary-scale inter-slice SR。

### Step 5：扩大数据集

顺序建议：

```text
IXI PD -> IXI T1/T2/PD multi-task
TopCaw vessel holdout
OASIS / HCP / ADNI / ABIDE external brain MRI
fastMRI 作为补充，不作为主插值数据
```

## 十五、可以写进论文的初步方向名

暂定几个方法名方向：

```text
Slice-Consistent Residual Diffusion for MRI Through-plane Super-Resolution

Data-Consistent Adjacent-Slice Diffusion for Arbitrary MRI Inter-slice Interpolation

Position-Aware Residual Diffusion for Anisotropic MRI Super-Resolution

Cycle-Consistent Conditional Diffusion for MRI Slice Interpolation
```

我更推荐第二个或第四个，因为它们把我们的关键点讲清楚：

```text
adjacent-slice conditioning
arbitrary inter-slice interpolation
data/cycle consistency
diffusion as residual refinement
```
