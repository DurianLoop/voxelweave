## 八、下一步方向

当前最该做的不是继续堆 epoch。

建议下一步做三件事：

### 1. 加强条件编码器

当前只是把：

```text
left
right
linear coarse
relative position map
```

简单拼接进 U-Net。

下一步应改成：

```text
multi-scale condition encoder
FiLM / adaptive normalization
cross-attention conditioning
hierarchical feature injection
```

这是最贴近 HiFi-Diff 原文的关键。

### 2. 加 data / cycle consistency

加入：

```text
predicted HR volume -> downsample/degrade -> original sparse volume
```

约束生成结果不能脱离已观测切片。

### 3. 修 median 偏低问题

可尝试：

```text
residual range 从 [-1,1] 改成更窄的 adaptive range
增加 low-intensity weighted loss
增加 SSIM loss 权重
增加 identity / zero-residual regularization
推理时降低 partial_start_fraction
```

## 十五、为什么 HiFi-Diff 原文能从 Gaussian noise 生成，而我们当前 strict 版不稳定

HiFi-Diff 原文确实描述为：

```text
given two adjacent MR slices + relative positional offset
iteratively convert a Gaussian noise map into the target in-between MR slice
```

但这不等于“随便写一个 conditional DDPM 就能稳定复现”。原文成功依赖几个很强的条件：

```text
1. 数据规模更大
   原文使用 HCP-1200 的 1,113 个 3T MR subjects。
   891 个用于训练，222 个用于测试。

2. 数据质量更统一
   HCP 是高质量、近各向同性 0.7mm MRI。
   原文做了 N4 bias correction 和 skull-stripping。

3. 任务模拟更规范
   从 isotropic HR volume 人工下采样得到 LR slice spacing。
   因此 LR-HR 对齐关系非常干净。

4. 训练设定更充分
   HiFi-Diff 用 mixed scaling ratios 训练 arbitrary-scale interpolation。
   不是只在很小的 case subset 上做 mini。

5. 网络和采样细节更完整
   原文 HiFE 是完整的 hierarchical feature conditioning。
   每一层用不同尺度条件特征调制 denoising branch。
   我们当前 strict 版只是近似实现，不是官方代码逐行复现。
```

因此当前结果不能说明“HiFi-Diff 原文不行”，只能说明：

```text
我们当前的 strict reimplementation 还没有达到原文级别。
直接把它放进最终大表并写成 HiFi-Diff official result 是不严谨的。
```

后续大表建议这样处理：

```text
1. 传统基线：
   linear
   cubic

2. 已跑通深度基线：
   pix2pix / GAN on TopCaw
   residual / partial diffusion on IXI

3. 论文复现栏：
   HiFi-Diff reimplementation，标注 ours / unofficial reimplementation
   如果 strict 复现失败，可以写 N/A 或 under reproduction，而不是硬填一个坏结果。

4. 我们的方法：
   后续基于 adjacent slices + coarse/refinement + data consistency 的改进模型。
```

下一步建议：

```text
短期：
  不再把 strict full 当作主线。
  先把 residual / partial diffusion 版本做扎实，补充 PSNR、SSIM、RMSE、LPIPS、FID、Params、FLOPs、逐病例指标和可视化。

中期：
  复现一个更容易对齐的公开方法，例如 SA-INR / ArSSR / DeepResolve 之一。
  这些方法不依赖复杂 reverse diffusion sampling，更适合先填大表。

长期：
  如果仍要严格复现 HiFi-Diff，需要优先补：
  HCP-style preprocessing
  N4 bias correction
  skull stripping
  mixed scale training
  exact DDPM reverse sampling with variance
  更完整的 HiFE / U-Net 配置
```
