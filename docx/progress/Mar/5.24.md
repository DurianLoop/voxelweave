阶段判断：

```text
resunet_mini 已经基本追平并略微超过 linear。
它没有 strict diffusion 的强度偏亮崩坏。
它比 diffusion residual 便宜很多：约 15.07G FLOPs / slice，而 hifidiff residual 约 361.44G FLOPs / slice。
```

但是优势还很小：

```text
PSNR 只高 0.075 dB；
SSIM 仍略低于 linear；
Auto-Dice 几乎持平；
当前不能说它已经形成显著优势。
```

## 四、和 hifidiff_full 的关系

注意：

```text
resunet_mini 使用 5 个 test cases；
hifidiff_full 使用 25 个 test cases。
```

所以二者目前不能直接作为最终横向结论。

但从趋势看：

```text
hifidiff residual:
  结构指标更强，尤其 Auto-Dice / Auto-HD95；
  但 SSIM / MAE 不如 linear；
  计算成本高。

resunet residual:
  像素指标更接近 linear；
  计算成本低；
  当前结构指标只略有提升。
```

这说明下一步需要一个统一口径实验：

```text
resunet_full vs hifidiff_full
```

二者都用 25 个 test cases，才能判断 diffusion 是否真的值得。

## 五、下一步建议

优先执行：

```powershell
D:\conda\envs\MRI\python.exe -m ixi_diffusion.run_all --profile resunet_full *> temp\resunet_full.log
D:\conda\envs\MRI\python.exe -m ixi_diffusion.paper_table --profile resunet_full
D:\conda\envs\MRI\python.exe -m ixi_diffusion.visualize_results --profile resunet_full --case-limit 3
```

如果 `resunet_full` 结果接近或超过 `hifidiff_full`：

```text
说明当前 diffusion residual 的收益不足。
后续创新应转向更轻量、更稳定的 deterministic + structure-aware 方法，
或者必须证明 diffusion 在不确定性、结构边界、任意倍率上有额外价值。
```

如果 `resunet_full` 明显低于 `hifidiff_full`：

```text
说明 diffusion residual 确实提供了额外收益。
后续可以继续发展 data-consistent adjacent-slice diffusion。
```

当前最稳妥的研究路线：

```text
1. 固定 IXI-PD 的评估口径。
2. 跑 resunet_full，建立 deterministic deep baseline。
3. 和 hifidiff_full 做同一测试集比较。
4. 再决定创新主线：
   A. lightweight deterministic residual interpolation
   B. data-consistent residual diffusion
```
