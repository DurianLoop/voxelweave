## 六、当前结论

当前最重要的结论：

```text
在 IXI-PD 25 个测试病例上，轻量 deterministic ResUNet residual 明显优于 linear / cubic / hifidiff residual。
```

这意味着下一阶段不应该继续把 diffusion 作为唯一主线。更合理的方向是：

```text
lightweight deterministic residual interpolation
+ structure-aware loss
+ data/cycle consistency
+ arbitrary relative position
```

diffusion 可以保留为对照和后续扩展方向，但当前实验结果显示它不是现阶段最有效、最高性价比的方案。

ResUNet 的定位需要明确：

```text
ResUNet / U-Net 类结构是医学图像重建、超分辨率和分割中非常常见的基础网络。
当前实现不应包装成我们的创新，也不应写成严格复现某一篇论文。
它更适合放在大表中，命名为：

ResUNet residual baseline
或
Deterministic ResUNet refinement baseline
```

它的作用是回答：

```text
如果不用 diffusion，只用普通深度网络做 residual refinement，能达到什么水平？
```

从当前结果看，这个 baseline 非常强，因此后续创新必须在它之上继续提升，不能只和 linear/cubic 比。

## 九、ResUNet 的论文定位

ResUNet / U-Net 类方法是前人广泛使用过的医学图像基础网络。

因此当前 `resunet_full` 不能写成创新方法，应该放在大表中作为强 baseline：

```text
ResUNet residual baseline
Deterministic ResUNet refinement baseline
```

它的作用是：

```text
证明普通深度 residual refinement 在当前 IXI 插值任务上已经很强；
后续任何新方法都必须超过这个 baseline，而不能只超过 linear / cubic。
```

大表建议分层：

```text
Traditional:
  linear
  cubic

GAN baseline:
  pix2pix / GAN

Deterministic deep baseline:
  ResUNet residual
  后续可补 SAINT / I3Net / ArSSR / CycleINR 等公开方法

Diffusion baseline:
  hifidiff residual / partial diffusion
  strict HiFi-Diff reimplementation, marked as unofficial / under reproduction

Ours:
  后续真正提出的方法
```

## 十、接下来的研究方向

基于目前所有结果，建议把后续方向分成 5 条。它们不是都要做，应该先做最能形成论文贡献的一条。

### 方向 1：补齐更强公开 baseline

目的：

```text
确认 ResUNet 强不是因为 baseline 太少；
把大表做得更有说服力。
```

候选方法：

```text
SAINT
I3Net
ArSSR
CycleINR
DeepResolve / DCSRN-style CNN SR
```

优先级建议：

```text
先做一个确定性插值/SR 方法，例如 SAINT 或 ArSSR；
不要一开始再复现复杂 diffusion。
```

### 方向 2：Structure-aware ResUNet refinement

这是目前最稳的主线。

基本想法：

```text
以 ResUNet residual 为强 baseline；
加入结构和边界约束；
目标是提升细节、边界和连续性，而不是只堆 PSNR。
```

可做改进：

```text
L1 + SSIM loss
gradient loss
Laplacian / frequency loss
edge-aware loss
foreground / tissue boundary weighted loss
```

适合解决当前 visual QC 看到的问题：

```text
ResUNet 结构稳定，但局部纹理偏平滑。
```

### 方向 3：Data / cycle consistency 插值

这是最有医学可信度的创新方向。

核心约束：

```text
predicted HR volume
  -> degrade / downsample
  -> must reconstruct original sparse observed volume
```

这样可以回答：

```text
模型有没有 hallucination？
生成结果是否仍符合原始观测切片？
```

可写成论文贡献：

```text
Data-consistent adjacent-slice residual interpolation
Cycle-consistent through-plane MRI super-resolution
```

### 方向 4：Arbitrary-scale / relative position modeling

当前任务固定为：

```text
stride = 4
offset = 0.25 / 0.50 / 0.75
```

后续可以扩展为：

```text
任意 slice gap
任意 relative position
```

实现方式：

```text
sinusoidal relative position embedding
MLP position embedding
FiLM / adaptive normalization
scale-aware residual prediction
```

这条方向和 HiFi-Diff / ArSSR / INR 类文献更接近，也更容易形成方法亮点。

### 方向 5：Multi-contrast / multi-dataset 泛化

IXI 有 T1/T2/PD，适合从单模态扩展到多模态：

```text
single-task:
  PD -> PD interpolation

multi-task:
  T1/T2/PD shared model

multi-contrast conditioning:
  用 T1/T2 辅助 PD 或互相辅助
```

后续数据路线：

```text
IXI T1/T2/PD: 主实验扩展
TopCaw: 血管结构验证
CAS2023: 外部结构泛化
OAI-ZIB / fastMRI: 跨解剖或更权威 benchmark
```

这条方向适合后续往 foundation / generalist MRI interpolation 叙事扩展，但当前不必一开始就做太大。

## 十一、建议的执行顺序

当前最推荐的顺序：

```text
Step 1:
  固化 resunet_full 作为强 baseline。

Step 2:
  补一个公开 deterministic baseline，例如 SAINT / ArSSR / CycleINR 之一。

Step 3:
  在 ResUNet 上加入 structure-aware loss，形成第一个 ours prototype。

Step 4:
  加 data/cycle consistency，增强医学可信度。

Step 5:
  扩展到 IXI T1/T2/PD multi-task。

Step 6:
  回到 TopCaw / CAS 做血管结构验证。
```

如果需要快速形成论文雏形，我建议主线暂定为：

```text
Structure-aware and data-consistent adjacent-slice residual interpolation
for MRI through-plane super-resolution
```

在这个叙事里：

```text
ResUNet residual baseline = 强基线；
我们的贡献 = 结构感知约束 + 数据一致性 + 任意位置建模；
TopCaw/CAS = 结构验证；
IXI = 主 benchmark。
```

### Step 2：把 ResUNet 升级为主方法雏形

当前 ResUNet 只是 baseline，后续可以围绕它做方法创新：

```text
1. structure-aware residual loss
   L1 + SSIM + gradient + Laplacian/frequency loss

2. relative position embedding
   当前只是 position map，可升级为 sinusoidal / MLP embedding。

3. data / cycle consistency
   predicted HR volume downsample 回 sparse volume，约束必须重建原始观测切片。

4. uncertainty or confidence map
   输出不确定性图，标注哪些区域插值不可靠。

5. multi-contrast extension
   IXI T1/T2/PD 多模态联合训练。
```

### Step 3：补充更完整的大表

建议下一张正式大表包含：

```text
linear
cubic
GAN / pix2pix
hifidiff residual
strict HiFi-Diff reimplementation
ResUNet residual
后续 ours
```

指标：

```text
PSNR
SSIM
RMSE
MAE
NCC
Mask-PSNR
Mask-SSIM
Auto-Dice
Auto-HD95
Params
FLOPs
Inference time
```

LPIPS / FID 可以作为补充，但不建议作为医学 MRI 主指标。

### Step 4：数据集扩展

短期：

```text
IXI-PD -> IXI T1/T2/PD
```

中期：

```text
TopCaw / CAS2023 做血管结构验证
```

后续：

```text
fastMRI / OAI-ZIB 做跨数据集或跨解剖泛化
```

### Step 5：论文叙事调整

当前建议暂时不把论文主线写成：

```text
diffusion-based MRI interpolation
```

而是调整为：

```text
structure-aware adjacent-slice residual interpolation for MRI through-plane super-resolution
```

这样更贴合当前结果，也更容易解释为什么方法稳定、轻量、强于 linear/cubic。
