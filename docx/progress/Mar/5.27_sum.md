# 5.27 汇总：数据集、公开 baseline、指标体系与下一步主线

## 一、最重要的口径修正

严格来说，正式论文大表不能只放 `ResUNet residual` 这类我们自己搭的工程 baseline。

`ResUNet residual` 的定位应该是：

```text
internal sanity baseline
工程验证 baseline
不是复现某篇论文的方法
```

正式大表更应该像 I3Net / SAINT 论文那样，把方法分成：

```text
Traditional:
  Linear / Cubic

Published baselines:
  EDSR2D / EDSR3D / RDN / RCAN / SwinIR / HAT / ArSSR / AdaCoF / RSTT / IFRNet / TVSRN / SAINT / I3Net

Ours:
  后续真正提出的方法
```

但需要注意：

```text
别人论文里的结果可以引用，但不能直接和我们的 IXI/TopCaw/CAS/OAI/fastMRI 结果混成同一个公平比较表。
```

原因是不同论文的：

```text
dataset 不同；
scale factor 不同；
train/test split 不同；
preprocessing 不同；
metric normalization 不同；
2D / 3D / slice-wise evaluation 口径不同。
```

因此建议以后表格分成两类：

1. **Reported Results Table**  
   引用别人论文中报告的结果，用来说明这些方法在原论文 benchmark 上有多强。

2. **Our Re-run Table**  
   在我们的统一数据、统一 split、统一倍率、统一指标下重跑，作为正式公平比较。

正式主表优先用第二类；第一类放 related work 或 supplementary。

## 三、方法池定位

### 1. 传统插值

| Method | 类型 | 作用 | 是否必须重跑 |
|---|---|---|---|
| Linear | 传统插值 | 最基本 baseline | 必须 |
| Cubic | 传统插值 | 稍强传统 baseline | 必须 |

这两类必须在所有数据集上重跑，因为它们是比较锚点。

### 2. 通用图像超分 baseline

| Method | 原始方向 | 用于我们任务的方式 | 优先级 | 备注 |
|---|---|---|---|---|
| EDSR2D | 2D image SR | 把相邻切片或 coarse slice 当 2D 输入 | 高 | 经典 CNN SR |
| RDN | 2D image SR | 2D SR baseline | 高 | 残差稠密特征 |
| RCAN | 2D image SR | 2D SR baseline | 高 | channel attention，高频恢复强 |
| SwinIR | Transformer image restoration / SR | 2D Transformer SR baseline | 高 | 强通用 baseline |
| HAT | Hybrid Attention Transformer SR | 强 Transformer SR baseline | 中高 | 很强但重 |

这些方法的原论文通常不是医学层间插值，但 I3Net 把它们作为强 baseline 对照是合理的。

### 3. 医学体数据 / 医学切片合成 baseline

| Method | 原始方向 | 与我们任务关系 | 优先级 | 备注 |
|---|---|---|---|---|
| SAINT | medical slice synthesis | 非常接近 | 很高 | CVPR 2020，利用 spacing 信息，支持不同 upsampling factor |
| ArSSR | 3D MRI arbitrary-scale SR | 非常接近 | 很高 | 3D MRI 任意倍率 SR，适合 IXI |
| CycleINR | arbitrary-scale volumetric medical SR | 非常接近 | 很高 | 强调任意尺度、cycle consistency、减少过平滑 |
| TVSRN | transformer volumetric SR | 接近 | 高 | 来自 RPLHR-CT，CT 厚层-薄层 SR |
| I3Net | medical slice synthesis | 最接近之一 | 暂缓 | 同学正在 IXI 上复现，先不重复投入 |

这组最适合出现在正式大表。

### 4. 视频插帧 / 视频时空超分 baseline

| Method | 原始方向 | 与我们任务关系 | 优先级 | 备注 |
|---|---|---|---|---|
| AdaCoF | video frame interpolation | 相邻帧插值类似相邻切片插值 | 中低 | 医学切片没有真实运动场，迁移不一定好 |
| IFRNet | efficient video frame interpolation | 可迁移为 slice interpolation | 中 | 轻量，若做视频类 baseline 可优先 |
| RSTT | space-time video SR | 同时做空间和时间 SR | 中低 | 复杂，和医学插值差距更大 |

这些适合当“跨领域方法迁移”的对照，不建议作为第一批重跑。

### 5. 我们自己的工程 baseline

| Method | 定位 | 是否写进论文主表 |
|---|---|---|
| ResUNet residual | internal sanity baseline | 可以放，但必须明确不是 published baseline |
| HiFiDiff residual | unofficial low-cost reproduction / exploratory diffusion baseline | 可以放失败/探索表，不宜作为强 baseline |
| strict HiFiDiff | unstable reproduction | 不建议放主表 |
| GAN / pix2pix on TopCaw | 历史 baseline / inherited code | 可作为 TopCaw 小规模历史对照 |

## 四、别人论文的结果能不能直接引用

可以引用，但要分清用途。

### 可以直接引用的场景

```text
Related Work:
  说明 SAINT / I3Net / ArSSR / CycleINR 在原论文数据集上表现很强。

Motivation:
  说明医学切片合成已经有一批强 baseline。

Background Table:
  列出 reported dataset / scale / metric / best result。
```

### 不建议直接引用的场景

```text
不要把 I3Net 在 MSD x2 的 43.90dB
直接和我们 IXI x4 的 28.89dB 放在同一个“公平比较”表里。
```

这两个数字不是同一任务难度：

```text
MSD CT vs IXI MRI；
x2 vs x4；
CT abdomen vs MRI brain；
preprocessing 不同；
强度 normalization 不同；
slice thickness / spacing 不同。
```

推荐写法：

| Table type | 内容 |
|---|---|
| Literature reported table | 引用原论文结果，标明 dataset / scale / metric |
| Unified re-run table | 我们在 IXI / fastMRI / TopCaw / CAS 上重跑的结果 |
| Ablation table | 我们方法内部模块对比 |
| Cross-dataset table | IXI train -> fastMRI/OAI/TopCaw/CAS test |

## 五、目前指标是否齐全

### 现在默认进入表格的代表性指标

| Metric | 当前状态 | 作用 |
|---|---|---|
| PSNR | 已接入 | 像素级重建质量，越高越好 |
| SSIM | 已接入 | 结构相似性，越高越好 |
| SSIMa / SSIMc / SSIMs | 已接入 | axial/coronal/sagittal 三视图结构一致性，避免只看一个方向 |
| MAE | 已接入 | 平均绝对误差，越低越好 |
| MSE | 已接入 | 平方误差，越低越好 |
| RMSE | 已接入 | 误差的原始强度尺度，更直观，越低越好 |
| NMSE | 已接入 | 归一化平方误差，适合跨病例/跨数据集比较，越低越好 |
| NRMSE | 已接入 | 归一化 RMSE，fastMRI/重建论文常见，越低越好 |
| NCC | 已接入 | 强度相关性，越高越好 |
| SNLI / inter-slice consistency | 已接入 | 层间连续性代理指标，衡量预测切片的 z 向曲率是否接近真实体数据，越低越好 |
| Gradient-MAE | 已接入 | 边缘/纹理梯度误差，补充 PSNR/SSIM 偏平滑的问题，越低越好 |
| Mask-PSNR | 已接入 | 自动结构区域 PSNR，越高越好 |
| Mask-SSIM | 已接入 | 自动结构区域 SSIM，越高越好 |
| Auto-Dice | 已接入 | 自动阈值结构重合，越高越好 |
| Auto-HD95 | 已接入 | 自动结构边界距离，越低越好 |
| Params | 已接入 | 模型复杂度 |
| FLOPs | 已接入 | 计算复杂度 |
| Visual QC | 已有 | 人工检查重建图、误差图、切片连续性 |
| Intensity sanity | 已有 | 检查强度偏移、过亮、过暗、崩坏 |

### 已预留但需要额外条件的指标

| Metric | 当前状态 | 原因 |
|---|---|---|
| LPIPS | 已预留入口，当前为 NA | 需要安装 `lpips` 包；后续适合对齐 CycleINR/I3Net 类论文的感知质量讨论 |
| Inference time | 建议下一步补 | 目前表里的 `Metric seconds/case` 是统计指标耗时，不等价于模型推理耗时 |
| GPU memory | 可选补 | 如果后续比较 Transformer / diffusion 大模型，需要记录峰值显存 |
| downstream segmentation Dice | 数据集特定 | TopCaw/CAS/OAI 有结构任务时可补，IXI/fastMRI 不一定适合 |
| topology / centerline metrics | 血管数据集强烈建议 | TopCaw/CAS 这类血管数据更需要中心线、连通性、拓扑保持指标 |

## 七、当前主线建议

现在不必立刻确定最终创新点，但可以先确定论文叙事方向：

```text
目标：
  做一个医学体数据层间插值 / through-plane SR 模型，
  在 IXI / fastMRI brain / TopCaw / CAS / OAI 等数据上，
  在 PSNR、SSIM、MAE、MSE、NCC、LPIPS、SNLI、结构指标上超过公开 baseline。
```

更稳的路线：

```text
阶段 1：统一数据与指标
  IXI T1/T2/PD x4
  brain_fastMRI_DICOM x2/x4
  已补 SSIMa/c/s、NMSE、NRMSE、SNLI、Gradient-MAE
  下一步补 LPIPS / inference time / peak GPU memory

阶段 2：重跑公开 baseline
  Linear / Cubic
  SAINT
  ArSSR
  CycleINR
  EDSR2D / RDN / RCAN / SwinIR 中选 2-3 个

阶段 3：接入同学的 I3Net 结果
  如果同学用 IXI 复现成功，直接纳入统一表
  如果 split / preprocessing 不同，需要重新对齐

阶段 4：提出 Ours
  不能只是 ResUNet residual
  应该加入明确的新机制：
    structure-aware loss
    data/cycle consistency
    arbitrary relative position
    cross-view consistency
    frequency / edge-aware refinement

阶段 5：结构验证和泛化
  TopCaw/CAS: 血管结构保持
  OAI/fastMRI knee: 跨解剖泛化
```

## 八、优先阅读和复现清单

### 第一优先级

| Paper / Method | 为什么优先 |
|---|---|
| SAINT | 医学切片合成经典 baseline，支持不同 upsampling factor |
| ArSSR | 3D MRI 任意尺度 SR，和 IXI 高度相关 |
| CycleINR | CVPR 2024，任意尺度 volumetric SR，强调 slice consistency |
| I3Net | 当前最接近的强方法之一，但同学在复现，先跟进结果 |

### 第二优先级

| Paper / Method | 为什么 |
|---|---|
| EDSR2D | 经典 CNN SR baseline |
| RDN | 强 CNN SR baseline |
| RCAN | 高频细节恢复强 |
| SwinIR | Transformer restoration baseline |

### 第三优先级

| Paper / Method | 为什么 |
|---|---|
| HAT | 强 Transformer SR，但较重 |
| TVSRN | 医学 volumetric SR，CT 上强 |
| IFRNet | 轻量视频插帧，可做跨领域对照 |
| AdaCoF / RSTT | 可引用为跨领域 baseline，优先级较低 |

## 十四、I3Net 风格实验表格模板（推荐采用）

I3Net 的表格组织方式更适合论文：

```text
1. 按数据集 / 模态 / 倍率拆表；
2. Method 放第一列；
3. 每个数据集块内放 PSNR + 多方向 SSIM；
4. 主表只放核心指标，结构指标、时间、消融单独成表；
5. best / second-best 用 bold / underline 标出。
```

I3Net 对 SSIM 的写法是：

```text
SSIMa = axial view SSIM
SSIMc = coronal view SSIM
SSIMs = sagittal view SSIM
```

我们目前代码只有 `SSIM mean`，后续如果要完全对齐 I3Net，需要补充三视图 SSIM：

```text
SSIMa: 在 axial slice 上算
SSIMc: 在 coronal slice 上算
SSIMs: 在 sagittal slice 上算
```

下面表格中：

```text
SSIMa/SSIMc/SSIMs 暂时用 TBD；
当前已有的 SSIM mean 先放在 SSIMa* 或备注中；
等三视图 SSIM 实现后再替换。
```
