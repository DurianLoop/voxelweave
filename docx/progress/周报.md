# 第三周周报：统一 T2/x4 实验口径与外部验证加固

时间：2026.6.1 - 2026.6.5

## 1. 本周目标

本周重点不是立刻提出创新点，而是继续把实验口径做扎实：统一数据集、方法、指标和划分方式，观察不同数据集上 baseline 的表现规律，为后续确定创新方向做准备。

本周目标主要有四个：

1. 扩容并规范 `fastMRI-brain-T2`，解决 DICOM/JPEG2000 解码问题。
2. 把 `IXI-T2 / fastMRI-brain-T2 / NingXia-T2` 放到同一张横向实验表中比较。
3. 将 `NingXia-T2` 从单一 test split 改成病例级交叉验证，提高外部验证可信度。
4. 梳理 `OAI-ZIB / BraTS / TCGA` 等数据集定位，判断哪些进入当前主线，哪些先作为后续扩展。

## 2. 本周完成内容

### 2.1 fastMRI-brain-T2 扩容与解码

本周补齐了 fastMRI brain DICOM 的 JPEG2000 解码依赖，包括：


处理后，`processing/fastmri_brain_t2_prepare.py` 可以优先使用 `pydicom.dcmread(...).pixel_array` 读取压缩 DICOM。这样之前不能转 NIfTI 的部分 DICOM 可以正常解码。

这使 fastMRI-brain-T2 从早期 sanity subset 变成了更适合作为正式公开验证集的 T2 数据集。

### 2.2 NingXia-T2 数据整理与病例级交叉验证

NingXiaData 已确认按 T2 口径处理。本周重新整理后得到：

| Item | Count |
|---|---:|
| T2 NIfTI series | 22 |
| cases | 8 |
| original train cases | 5 |
| original val cases | 2 |
| original test cases | 1 |

原先 test 只有 1 个病例，不足以支撑外部泛化结论。因此本周实现了病例级 8-fold CV：

```text
processing/ningxia_case_cv.py
processing/run_ningxia_case_cv.py
processing/summarize_case_cv.py
```

划分原则：

```text
每个 fold：6 个病例训练，1 个病例验证，1 个病例测试。
每个病例都作为 test 出现一次。
同一病例下的所有 series 不跨 split。
```

输出目录：

```text
dataset/NingXiaData/processed_saint_cv
ningxia_t2_saint_cv/runs
ningxia_t2_resunet_cv/runs
```

同时修正了 `processing/summarize_case_cv.py`：现在默认只汇总 `full` profile，避免把 `smoke` 结果混进正式 CV 统计。

因此 OAI-ZIB 暂时不进入 MRI 强度重建主表，只作为结构标签插值 sanity 支线。如果后续要做 knee MRI intensity 泛化，需要寻找 OAI 原始 MRI 强度数据。

### NingXia-T2 8-fold 外部验证结论

相对 Linear，SAINT-style 在 NingXia-T2 CV 上：

| Metric | Improvement |
|---|---:|
| PSNR | +1.1015 dB |
| SSIM | +0.0673 |
| MAE | -13.7912 |
| MSE | -9186.1631 |
| NCC | +0.0329 |

这说明学习型方法在外部临床 T2 数据上确实有收益。SAINT-style 略优于 ResUNet residual，但二者差距不算极大，后续需要继续观察模型复杂度、速度和视觉质量。

## 4. 关键发现

1. `IXI-T2` 相对干净，Linear/Cubic 已经较强，因此它适合开发和筛模型，但不能单独证明泛化。
2. `fastMRI-brain-T2 expanded` 明显更难，传统插值指标下降明显，学习模型收益更大，更适合做正式公开验证集。
3. `NingXia-T2` 是本地外部数据，来源和 IXI/fastMRI 不同。8-fold CV 结果显示学习模型优于传统插值，因此它可以作为外部验证，但病例数仍偏少。
4. `SAINT-style` 在三个 T2 口径中当前表现最好，说明相邻切片条件、相对位置编码和空间感知建模对当前任务有效。
5. `ResUNet residual` 仍然必须保留。它不是严格复现某篇论文，但作为简单 CNN residual baseline，可以判断复杂模型是否真的带来额外收益。

## 5. 当前问题

1. NingXia-T2 虽然已经做了病例级 CV，但总病例数只有 8 个，仍不能单独支撑强泛化结论。
2. 当前主表只有 Linear/Cubic、ResUNet residual、SAINT-style，还缺少 SwinIR、HAT、RSTT、I3Net、CycleINR 等更强的 published baseline。
3. OAI-ZIB 当前本地数据不是 MRI intensity，不能直接放进主表。
4. 目前主表以 PSNR/SSIM/MAE/MSE/NCC 为主，LPIPS、推理时间、显存、SNLI 等扩展指标还没有统一进入正式表。

## 6. 下周计划

1. 继续补强强 baseline 信息：重点整理和筛选 `SwinIR / HAT / RSTT / I3Net / CycleINR`，确定哪些需要复现，哪些只引用原论文结果。
2. 在 fastMRI-brain-T2 和 NingXia-T2 上继续做 visual QC，确认指标提升是否对应真实视觉质量提升。
3. 如果能获得 OAI 原始 MRI intensity，再重新整理 knee MRI intensity 分支；否则 OAI-ZIB 只保留为结构标签 sanity。
4. 补充 `Params / FLOPs / inference time / GPU memory`，用于说明方法效率。
5. 继续从“数据集难度、模型收益、指标变化”三个角度归纳规律，再决定创新方向，而不是马上硬造一个方法点。

## 7. 给老师汇报时可概括为

本周主要完成了实验口径统一和外部验证加固。fastMRI-brain-T2 已扩容到 160 个 T2 NIfTI，并完成 SAINT/ResUNet/Linear/Cubic 横向对比；NingXia-T2 从原来的单 test case 改为 8-fold 病例级交叉验证，结果显示 SAINT-style 和 ResUNet residual 均优于传统插值，其中 SAINT-style 当前表现最好。与此同时，我们发现 OAI-ZIB 当前本地数据是低灰阶标签式结构数据，不能直接进入 MRI intensity 主表，因此暂时作为结构 sanity 支线。下一步将继续补齐强 baseline 和缺失效率指标，再基于数据集难度和模型收益规律确定创新方向。

# 第二周周报：IXI / fastMRI / NingXia 上建立同口径 baseline

时间：约 2026.5.20 - 2026.5.28

## 1. 本周目标

第二周的重点是把研究主线从 TopCaw 小规模可行性验证，转到更适合作为论文主表的数据集上：`IXI`、`fastMRI-brain-T2` 和本地外部数据 `NingXia-T2`。目标是先建立可靠 baseline，而不是急着提出创新。

## 2. 本周完成内容

1. 整理了 IXI 数据集定位：IXI-T1/T2/PD 用于主开发和内部 benchmark，其中 T2 暂定为当前主线。
2. 在 IXI 上实现并测试了 deterministic `ResUNet residual` baseline。
3. 尝试复现 HiFi-Diff 思路，包括 low-fi residual/partial diffusion 和 strict HiFi-Diff-style 版本。
4. 发现 pure-noise / strict diffusion 在当前小规模训练下容易出现强度偏亮和分布不稳定，因此暂时不作为主线。
5. 开始搭建 `SAINT-style` baseline，用相邻切片和空间感知建模解决层间插值。
6. 接入 fastMRI brain DICOM，并逐步过滤 strict T2 subset。
7. 整理 I3Net、SAINT、SwinIR、HAT、RSTT、IFRNet 等可作为后续强 baseline 的方法清单。

## 3. 关键实验结果

IXI 三模态上的 ResUNet residual internal baseline 已经形成稳定记录：

| Dataset | Modality | Scale | Method | PSNR | SSIM | MAE | MSE | NCC |
|---|---|---|---|---:|---:|---:|---:|---:|
| IXI | T1 | x4 | ResUNet residual | 28.8887 | 0.8808 | 37.8351 | 8148.3277 | 0.9621 |
| IXI | T2 | x4 | ResUNet residual | 27.4698 | 0.8874 | 29.3855 | 5680.4368 | 0.9508 |
| IXI | PD | x4 | ResUNet residual | 30.2173 | 0.9212 | 30.2874 | 6170.1477 | 0.9846 |

第二周的重要判断是：ResUNet residual 虽然不是 published baseline，但它是一个稳定、低成本、强于传统插值的 internal baseline，可以作为 sanity check；真正论文主表后续还需要补 published strong baselines。

## 4. 当前问题与分析

1. HiFi-Diff strict 复现不稳定，不能直接写成“复现失败”，只能标注为 unofficial reimplementation / under reproduction。
2. ResUNet residual 效果稳定，但容易偏平滑，说明后续创新可以围绕边界、纹理和层间连续性展开。
3. 不同数据集难度差异明显：IXI 比较干净，fastMRI 和 NingXia 更接近真实复杂场景。
4. 论文大表不能把别人论文里的不同数据集结果直接和我们的结果混成公平比较；必须区分“引用表”和“我们统一重跑表”。

## 5. 下周计划

1. 固化 T2/x4 主表格式。
2. 在 fastMRI-brain-T2 和 NingXia-T2 上补 SAINT-style / ResUNet residual 对比。
3. 把 NingXia 从单 test case 改成病例级交叉验证。
4. 继续整理 published baselines，优先判断哪些适合真正复现。

# 第一周周报：接手项目、跑通 TopCaw GAN，并完成 GAN 阶段收口

时间：约 2026.5.11 - 2026.5.18

## 1. 本周目标

第一周的目标是接手师兄留下的项目，先弄清楚数据集、代码和原始 GAN 路线，完成最小复现，并判断这条 GAN 路线是否值得继续投入。

## 2. 本周完成内容

1. 梳理了项目中的主要数据集，包括 TopCaw2024、CAS、OAI-ZIB、IXI、fastMRI 等的定位。
2. 在 Windows + RTX 5090 环境下重新配置 conda 环境，解决 PyTorch / CUDA / 依赖兼容问题。
3. 跑通 TopCaw MR-only 的最小训练和推理流程。
4. 将原来的 `topcow_phase123` 流程整理为更清晰的 `topcow_gan`。
5. 实现 case-level split、best checkpoint 选择、early stopping / 学习率调度、visual QC、逐病例分析、结构性指标和真实血管标签引导的 holdout 评估。
6. 补充 GAN 与 Linear/Cubic 的定量比较和结构区域评价。

## 3. 关键实验结果

TopCaw GAN 阶段最终结论是：GAN v4 在当前 TopCaw 协议下优于传统插值，但这条线可以阶段性收工。

| Method | PSNR mean | SSIM mean | MAE mean | MSE mean | NCC mean |
|---|---:|---:|---:|---:|---:|
| GAN v4 | 35.7656 | 0.9057 | 8.0157 | 167.6570 | 0.9668 |
| Linear | 34.7714 | 0.9028 | 8.3485 | 210.8007 | 0.9575 |
| Cubic | 34.5561 | 0.8924 | 8.7594 | 224.7782 | 0.9548 |

结构区域评估显示，GAN 在 vessel-SSIM、vessel-MSE、vessel-boundary-MAE 等指标上优于传统插值，但在 vessel-PSNR / vessel-MAE 上并不是全面占优。

## 4. 关键发现

1. TopCaw 适合做方法可行性验证和血管结构保持验证，但不是 MRI super-resolution / inter-slice interpolation 方向最主流的 benchmark。
2. GAN 在 TopCaw 上能超过 Linear/Cubic，说明师兄路线不是完全无效。
3. 但 GAN 对结构连续性和边界保持的优势还不稳定，继续微调 GAN 的优先级不高。
4. 后续更应该转向 IXI、fastMRI 这类更权威的 MRI 数据集，同时保留 TopCaw 作为血管结构验证数据集。

## 5. 下周计划

1. 转向 IXI / fastMRI 上的 T2 x4 层间插值主线。
2. 尝试 diffusion / HiFi-Diff / ResUNet / SAINT 等更贴近近期文献的方法。
3. 开始整理论文大表需要的方法、数据集和指标口径。
4. 不急着提出创新，先通过复现和 baseline 观察规律。
