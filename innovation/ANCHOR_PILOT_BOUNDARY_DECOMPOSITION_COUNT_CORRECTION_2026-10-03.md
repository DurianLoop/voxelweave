# 边界分解方案的端点算术修正

事前保存的本分解方案（本身是已看过pilot结果后的探索）把逐人比较数写成 `36×3×3=324`，重复乘了一次域数。真实设计为6比较×2标签×3域=36汇总，再×3患者=108逐人比较。18条件记录×2标签×3域另得108条件分区行。

原方案文件和执行时绑定SHA保留，不改写为“从未出错”。实际脚本完整执行108逐人比较、36汇总和108条件分区；没有少算任何固定比较、患者、标签或分区。这是方案中的计数表述错误，不是结果缺失，也不改变失败判断。

post_fixed−post 的 JSON full 平均ΔTP为−133.33、ΔFN为+133.33，其中reference 1mm带内ΔFN为+119，带外+14.33。带外平均ΔFP减少72.67，虽然ΔTP也为负，Dice仍升高；不能把带外Dice正向称“病灶核心恢复”。RTSTRUCT方向相同。均值会掩盖逐人异质性，完整108行都保留。

计数复核见[独立Fraction/CSV核验](experiments/anchor_pilot_boundary_decomposition_cpu/independent_partition_and_csv_verification.json)。该复核属于软件证据，科学独立确认仍为0。
