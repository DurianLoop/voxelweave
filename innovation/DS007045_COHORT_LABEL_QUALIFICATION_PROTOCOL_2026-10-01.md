# ds007045 current-cohort label and geometry qualification

Frozen before the cohort request. Purpose: set an outcome-independent denominator for a future CPU-only IXI model comparison of full-foreground and tumor-region reconstruction errors. This stage reads no T2 voxels and runs no model.

- Cohort: all 363 subject IDs in the archived [current S3 key audit](literature/source_cache/ds007045_current_pair_audit_2026-10-01/result.json), sorted as recorded. This is the current unversioned S3 view whose dataset description identifies v2.0.1; it is not the paper's v1.0.1/337 cohort.
- For each exact subject key, request only its official `derivatives/segmentation/<id>/<id>_MNI152_tumor-mask.nii.gz` (expected size from archived S3 listing, at most 100,000 bytes) and bytes 0-65535 of `derivatives/processing/<id>/<id>_t2_MNI152_brain.nii.gz`. Require HTTP 206 for T2 range and no more than 65,536 compressed bytes. One bounded network retry is allowed for transport errors; parse/geometry failures are not retried. One request stream at a time, no GPU, and a 15 GB free-disk floor.
- Require current `dataset_description.json` bytes to match the prior archived v2.0.1 SHA-256 before and after the run. Store the complete compressed mask (about 10 MB in total) under `innovation/data/ds007045_label_qualification/`; store only a hash and parsed nonpixel fields from each T2 prefix. Never retain T2 pixels.
- Use nibabel to require 3D image and mask headers, matching shape and best affine within 1e-4 mm, finite positive voxel sizes, and mask labels within {0,1,2,3}. Record all failures without changing case order. For each passing mask use exactly the existing MSD target selection rule: for each residue 1 and 3, at least two interior slices with >=64 tumor voxels and at least two observed anchors on each side for phase 0 and phase 2; select the 1/3 and 2/3 candidate quantiles. Record target indices and label counts. Do not alter the rule after seeing eligibility.
- Qualifying a label is not proof of clinical independence or that processed MNI slices are native thin acquisitions. The later model experiment must check full T2 hashes, freeze the selected denominator and equal-processing linear comparator before reading withheld target pixels, report every exclusion, and use patient-level intervals. No publishable performance claim follows from this qualification alone.
