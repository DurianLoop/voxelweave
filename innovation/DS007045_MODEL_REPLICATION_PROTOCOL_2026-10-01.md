# ds007045 CPU model replication protocol (prospective to target pixels)

Objective: independently test the existing MSD observation that a fixed IXI-trained interpolation model can lower full-foreground reconstruction error while increasing tumor-region error relative to an equal-processing linear baseline. This is a processed-MNI-grid reconstruction-error study, not a lesion-detection, native-acquisition, or safety claim. Written before any `ds007045` model output or cohort target T2 pixel analysis. The earlier `sub-BA3` linear-only feasibility result was seen; it is included in the source denominator but did not set model outcomes or endpoints.

## Cohort and inputs

- Use the current official S3 objects whose archived `dataset_description.json` identifies OpenNeuro `ds007045` v2.0.1, CC0. Attempt all 363 current processed T2/mask filename pairs listed in [the official key audit](literature/source_cache/ds007045_current_pair_audit_2026-10-01/result.json). Include every case passing the separately frozen [mask/header qualification](DS007045_COHORT_LABEL_QUALIFICATION_PROTOCOL_2026-10-01.md); retain every failed case and reason in the original denominator. Do not pool with the paper's v1.0.1/337 cohort.
- Freeze each case's mask SHA-256, T2 first-65,536-byte compressed SHA-256, geometry and four selected target indices from the qualification records before retrieving full T2. Verify the full T2 prefix hash, listed size, full SHA-256, current dataset-description hash and a 15 GB disk-free floor. At most one exact processed-T2 file per eligible subject, 10 MB per object; mask bytes are already local. No raw T2, other modalities or whole-dataset bundle.
- Use the qualification's two targets in each residue 1 and 3, selected solely from label content. Simulate x4 phase-0 input at indices `0,4,8,...` along NIfTI axis 2. Withhold all other T2 planes from every estimator and from intensity normalization. Target pixels are used only in scoring.

## Frozen estimators and metrics

- Primary model: existing frozen IXI SwinIR checkpoint SHA-256 `6a819e47e65bd96c2d6e5b6d3adc212e1a46347080a0a661c602367be8a6f323`. Secondary model: IXI HAT checkpoint SHA-256 `2fae831ab933cf260972260ebec4349f3895106ac7b4d1af3ba368f407498eae`. Use the existing `prepared`/`predict` code in `innovation/experiments/remind_native_t2_ixi_pair.py`, CPU device, at most two Torch threads and `CUDA_VISIBLE_DEVICES=-1`. Do not touch the running training job.
- Primary comparator is model-pipeline linear: the same phase-0 anchor min/max, 256x256 resize, linear coarse image, clip to [0,1], and resize to the original plane without learned residual. Raw two-neighbor linear is secondary. Thus the adjacent observations, global anchor normalization, resize and clipping are matched for primary model/comparator.
- On each target use the original MSD acquired-anchor support rule: pixels where either adjacent observed plane exceeds 1% of its own absolute maximum. Tumor ROI is `(label>0) & support`, requiring at least 64 pixels; full ROI is support. No target-derived mask. For each estimator, record mean squared error divided by the squared positive phase-0 anchor range in both ROIs. Four-target arithmetic mean per patient is the analysis unit. Report raw intensity-unit MSE and MAE descriptively as secondary checks.
- Primary endpoints for SwinIR versus pipeline linear: patient-equal mean tumor normalized-MSE difference (expected >0), patient-equal mean full-support normalized-MSE difference (expected <0), and the fraction of patients with both signs simultaneously. A replication passes only if at least 250 cases from at least six site prefixes complete, the 5,000-draw patient-bootstrap percentile 95% interval is entirely above zero for tumor difference and entirely below zero for full-support difference, and the Wilson 95% lower bound for the simultaneous-sign fraction exceeds 0.20. Bootstrap seed `20261003`. HAT and raw-linear comparisons, class-specific ROIs, site strata, and absolute effect sizes are secondary; report all counterexamples and failures. No tuning, retraining or case selection from these outcomes.

## Interpretation gate

Even if the numerical replication passes, patient identity linkage to MSD/BraTS is unresolved, all source planes are MNI-registered outputs rather than independently acquired thin slices, and labels were produced from multiple modalities. The result can support only a carefully worded empirical regional-error claim after prior-art and clean-reproduction review. In particular, Verschuur 2022, Radmanesh 2022, Fischer/Kuestner/Baumgartner 2023, Morshuis 2024/2025 and Kuestner 2024 must be assessed for collision at the claim level; Kuestner 2024 full methods remain unread. Publishing weights or data requires separate rights review. A failed replication weakens this claim rather than authorizing revised endpoints on the same cohort.
