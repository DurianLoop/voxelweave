# ds007045 high-resolution 3D T2 CPU model pilot

Written after outcome-independent label/header and raw-acquisition metadata audits, before any ds007045 HAT/SwinIR inference. This is a feasibility and falsification pilot for the fixed IXI models, not a confirmatory clinical or publication claim.

- Eligible set: exactly the 34 subject IDs in `thin_3d_<=1_5mm` of [the archived sidecar summary](literature/source_cache/ds007045_raw_t2_sidecars_2026-10-01/summary.json), all 34 also eligible in the [separate geometry/label qualification](experiments/ds007045_cohort_label_qualification/summary.json). Preserve sorted case order and the original 363-case denominator in reports. Site distribution is NSK 31, BA 2, FO 1; no site-balancing by outcome.
- For each case download only its exact processed T2 named and size-frozen in the qualification JSON (max 10 MB), verify its first 65,536 compressed bytes against the archived T2 prefix SHA-256, and store full-object SHA-256. Use the already frozen exact mask and four tumor-positive targets, two per residue 1/3. Require image/mask same grid and all pixels finite. No raw T2 images, no other modalities, no locked IXI test.
- Run the exact frozen IXI SwinIR and HAT checkpoints on CPU with `CUDA_VISIBLE_DEVICES=-1` and one Torch thread. Use phase-0 observed planes only, the existing `prepared`/`predict` code, raw two-neighbor linear and model-pipeline linear defined in the [full-cohort prospective protocol](DS007045_MODEL_REPLICATION_PROTOCOL_2026-10-01.md). Keep its acquired-anchor support rule, `label>0` tumor ROI, normalized MSE, four-target patient averaging and failure accounting. Primary exploratory contrast is SwinIR minus pipeline-linear normalized MSE in tumor and full support, plus their simultaneous opposite-sign fraction. HAT/raw-linear comparisons are secondary.
- Attempt all 34 regardless of interim outcome, with one fixed first-case software preflight allowed. Report completed/failure counts, all case and target results, patient bootstrap 95% percentile intervals (5,000 draws, seed `20261004`), Wilson 95% interval for sign discordance, and site-specific means. A directional pilot signal requires at least 30 completed cases, tumor mean-difference interval wholly above zero, full-support interval wholly below zero, and simultaneous-sign Wilson lower bound above 0.20; it is still not a publishable confirmation because of extreme site imbalance and processed-grid truth.
- If the pilot fails, retain the negative result and do not tune targets or model on these 34 cases. If it passes, the next gate is a second genuinely high-resolution T2 source with aligned labels or a different independently supported endpoint; 327 thick-2D ds007045 cases cannot silently supply that confirmation.
