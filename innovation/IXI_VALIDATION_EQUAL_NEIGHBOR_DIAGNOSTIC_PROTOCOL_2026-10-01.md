# IXI validation-only same-neighbor diagnostic, after MSD regional result

Status: frozen after the MSD 483-case lesion/full-support analyses and the two-source full-support CSV check, before inspecting any IXI validation image pixels or calculating validation model-versus-linear metrics. This is a diagnostic use of the **58-case checkpoint-selection validation split**, not an independent holdout or a publication confirmation. Never open IXI `test_cases.txt` or test image pixels. Use only `dataset/IXI/splits/seed3407/val_cases.txt` and the matching exact T2 paths from `dataset/IXI/metadata/ixi_cases.csv`; require 58 distinct listed cases, all local source files, finite decoded float32 voxels and two frozen checkpoint SHA-256s.

Use the frozen IXI-trained HAT and SwinIR checkpoints from the earlier public-source experiments, with `CUDA_VISIBLE_DEVICES=-1`, `device="cpu"`, at most two Torch threads and no model training. Use the existing `prepared()`/`predict()` implementation from `experiments/remind_native_t2_ixi_pair.py`: all observed phase-0 anchors set the case min/max, observed neighboring planes and linear coarse plus position channel feed each model, 256-square input and native-shape output. Linear controls use exactly the two adjacent phase-0 observed planes, without access to the withheld target except for scoring. Raw linear is direct float64 interpolation; pipeline linear uses the same anchor min/max, plane resize, blend, clip and resize-back as the model coarse path without learned residual. The target is never an input.

Before decoding pixels, derive four target indices from the published depth in metadata. For each residue 1 and 3 modulo 4, enumerate odd target indices with at least two real positions on both sides in each of the phase-0 and phase-2 index grids; phase-2 is used only for this geometric eligibility check and its pixels are never decoded or supplied. Choose candidate positions `floor((m-1)/3)` and `ceil(2(m-1)/3)`, distinct, yielding two targets per residue and exactly four per case. This mirrors the MSD target-quantile geometry without label selection. Require at least two candidates per residue for all 58 cases; otherwise stop without replacing cases.

On each target, define the acquired-only support from the two immediate phase-0 anchors using the same 1%-of-each-plane-max absolute intensity rule as the MSD source code. Score raw linear, pipeline linear, HAT0 and SwinIR0 MSE on precisely that support. Also report MAE and the support count for auditing; reject empty support or nonfinite predictions. Average the two targets within each residue, residues equally within a patient, then all 58 cases equally. Report model-minus-raw-linear and model-minus-pipeline-linear patient-equal MSE means, positive/negative/tied patient counts and 5,000 patient-bootstrap percentile intervals with seed `20261012`, plus patient and target tables and all attempted/failure IDs. No subgroup, alternative target selection, normalization, threshold or checkpoint after seeing results.

The cohort is healthy/mixed IXI T2 validation data without a matching tumor ROI, whereas MSD is multi-modal registered BRaTS tumor data. A validation advantage over linear would show that the fixed code path is capable of improving whole-support fidelity in a familiar source; it would not causally attribute MSD lesion failure to domain shift or prove tumor-specific harm. A validation deficit would weaken the premise that the negative MSD result reflects transfer at all. Both outcomes remain exploratory because the split selected the checkpoints.
