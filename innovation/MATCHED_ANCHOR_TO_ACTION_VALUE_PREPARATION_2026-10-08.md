# 从理想定位空间到可验证的 MRI 动作价值

当前尚无可发表的新 claim。本轮比上一轮进一步区分了两个问题：真实观测标签的匹配支持足够集中，现实预测器仍常触及大量窗口；初始化费用的结论依赖实际流程。理想几何可行不保证修正有效，现实面积 gates 失败也不等同完整成本失败。

主候选为：**充分适配后，用合法观测预测具体修正动作的整患者任务增益，并按完整实测费用选择联合动作。**与误差定位的差别必须用配对实验验证：基线有误差的位置未必能被某一 SR/插值动作改善，动作还可能损害原正确区域。当前无实测增益、效应区间或确认结果；不把候选当原创性结论。

## 执行依赖与停止条件

1. 首先继续 poll 原 live session99542，不能重启、迁移或控制用户终端训练。两臂各19998/总39996更新，CPU4/interop1、float32、共同初始化/监督/增强、AdamW lr/wd=.0001、30h/8GB储备/250MB合同保持。真实训练 exit0且两臂最终冻结后，才运行原56FOV、全部6能力 gates和独立 strict。中间 loss/checkpoint 不用于 MRI 效益选择，旧 direct absolute gate 失败不被浮点解释覆盖。
2. GPU 已授权；新 GPU 作业仍须满足已定8GB可用显存余量。当前 free1394MiB/24455MiB（2026-10-08 00:18:03）不足；当前 CPU 训练继续原合同。后续充分适配 dense/direct+availability/合法SR，必须证明基线能力，不能用弱 baseline 制造收益。
3. 在新医学输入或训练前，另冻动作定义、合法输入、全FOV/边界/tail处理、成本预算和新输出目录。GT可用作开发监督端点，不能进部署定位；固定未修正基线也作为合法动作。保持本轮2mm/0.5诊断不追阈值、不事后改主方法。
4. 先对具体合法动作做完整患者配对评价：Δtask = Q(动作后完整输出)-Q(相同基线输出)。记录收益、损害、零收益和失败；选择前所有候选生成/探索都算成本。使用现有冻结端点及边界定义，不用 ROI 几何 Dice 代替分割 Dice，不把重建误差当临床端点。若充分适配后无稳定剩余收益，淘汰当前动作库并记录负结果。
5. 开发内整患者 cross-fitting；同患者所有 series 一起留出。至少控制：最强固定合法动作、同信息/容量误差或风险头、cost/defer、同预算随机、真实 union-aware greedy及相关已有控制方法。完整患者费用先合并再比较，初始化/定位/生成/探索/transfer/infer/后处理全计，费用流程A/B按实际实现固定。
6. 最终模型和每个实际布局重新核full/cached输出、硬预测和整FOV。对于联合/连续动作实测增益，不能把单动作收益相加或把同支持N+m·k外推累计编辑。遇到不等价或总费用超预算保留失败，不发行修复或加速 claim。
7. 方法、动作库、checkpoint、阈值、总预算及端点冻结后，才开启8确认患者/12series；4已见验证不更名新确认，locked IXI关闭，旧MIRA/MSValid84证据保留。fresh calibration 只限制正式风险保证，经验MRI效益论文不额外要求该条件，但没有它不发高概率风险证书。
