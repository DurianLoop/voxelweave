# Post-result, same-neighbor linear baseline audit on MSD Task01

Status: frozen after the 483-case neural and analytic-control results were read, before this joined comparison was computed. This is an exploratory diagnostic comparison, not a preregistered test or independent cohort. Its purpose is to check whether IXI-trained HAT and SwinIR have a lesion-region reconstruction advantage over a basic phase-0 interpolation on the same registered-release T2 target slices.

Use only the archived 484 official Task01_BrainTumour training case records in `experiments/msd_task01_tumor_roi_context/cases` and `experiments/msd_task01_analytic_context_control/cases`. Do not decode images, redownload data, load checkpoints, run inference, use GPU, or touch the locked IXI test set. The neural `lesion/local_control.shared.a_mse` is HAT0 and `.b_mse` is SwinIR0. The analytic `lesion/local_control.shared.b_mse` is linear0. Do not use analytic `.a_mse`: PCHIP0 uses four phase-0 planes and answers a different observation-budget question. The analytic archive did not save linear0's full-support MSE, so a full-support comparison cannot be reconstructed from these records and is outside this audit.

Before any aggregate calculation, require identical 484 sorted case IDs, completion flags, source-file member names and compressed SHA-256 values, four target `(z,residue)` pairs and frozen target lists, and exact lesion/local pixel counts. For each completed case require two targets per residue and finite, nonnegative MSE values. The one original failure (`BRATS_044`) stays in the 484-attempt denominator. For each matched target and each ROI, form HAT0 minus linear0 and SwinIR0 minus linear0 MSE in the original release intensity squared units; positive means the network is worse. Average the two targets within each residue, then the two residue means equally per case, then complete cases equally. Also compute each patient's ratio of model MSE to linear MSE only where the linear patient MSE is strictly positive; report median and interquartile range, not a mean percentage improvement vulnerable to small denominators.

Report the complete-case count, target count, patient-equal model and baseline MSE, patient-equal paired differences, positive/negative/tied patient counts and 5,000-draw percentile patient-bootstrap intervals for each network and each ROI, using seed `20261007`. The lesion ROI is the main descriptive endpoint. The equal-area same-slice label-negative control is the required contextual endpoint. Also report the patient-equal lesion-minus-local difference in paired network-minus-linear MSE, while noting that the ROI intensity distributions differ. No threshold, subgroup, alternative intensity normalization, target filter or bootstrap seed will be selected after looking at the joined results.

The model condition tensors contain the two adjacent phase-0 observed planes, their linear blend and a relative-position plane. The model's min/max normalization uses **all** phase-0 anchor planes in the case, with 256-square resizing, clipping and resize-back; raw linear0 uses only the adjacent two decoded planes. Thus this is matched for local observed *image planes*, not strict total-information or processing equivalence. IXI-to-registered-MSD transfer, release processing, model training loss and clipping can all affect performance. A positive network-minus-linear difference would document domain-shift/task-region harm under these fixed contracts, not prove a universal failure of learned interpolation or a new method. Any literature novelty or clinical claim requires separate review and confirmation.
