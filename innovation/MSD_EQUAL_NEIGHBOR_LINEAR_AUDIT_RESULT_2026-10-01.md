# MSD Task01: same-neighbor linear baseline versus frozen IXI networks

**Finding (post-result exploratory):** On the same 483 complete official MSD Task01 cases and 1,932 frozen target slices, both IXI-trained networks have higher squared error in the annotated tumor ROI than raw two-neighbor phase-0 linear interpolation. This is a fixed-contract, registered-release T2 observation, not a new reconstruction method or a diagnosis result. The [analysis rule](MSD_EQUAL_NEIGHBOR_LINEAR_AUDIT_PROTOCOL_2026-10-01.md) was written after the prior neural/analytic results but before this join was calculated. The [summary](experiments/msd_equal_neighbor_linear_audit/summary.json), [patient CSV](experiments/msd_equal_neighbor_linear_audit/per_patient.csv), [target CSV](experiments/msd_equal_neighbor_linear_audit/per_target.csv) and [script](experiments/msd_equal_neighbor_linear_audit.py) preserve the calculation.

The patient-equal *raw squared-error excess* is larger in tumor than in the nearby control: HAT +510.19 (+417.77 to +608.80), SwinIR +461.43 (+368.03 to +561.02), positive in 349/483 patients for each. This cross-ROI difference should not be interpreted as a calibrated lesion-selective failure effect: tumor and nearby label-negative pixels have different intensities, texture and baseline errors. Bootstrap intervals are descriptive after dataset/model/result selection and do not adjust for multiple exploratory decisions.

The exact 484 case IDs, completion flags, two compressed source-file member names and SHA-256 values, four targets per case, residue assignments and lesion/local ROI pixel counts matched across the frozen neural and analytic records. `BRATS_044` remained the one label-qualification failure, so 483 cases completed. Each method used the same withheld target and two adjacent phase-0 observed planes for local image content. Linear0 comes from analytic `shared.b_mse`; PCHIP0 `shared.a_mse` was excluded because it uses four phase-0 planes. Model outputs came from neural `shared.a_mse` (HAT0) and `shared.b_mse` (SwinIR0). A separate PowerShell CSV aggregation reproduced the HAT/SwinIR mean paired differences (+791.91727699596/+598.049920259976), their 453/435 positive-case counts, 1,932 target rows and equal lesion/local pixel counts on every target.

**Important processing caveat:** HAT/SwinIR inputs also use the global min/max from all phase-0 anchors, resize each 240-square plane to 256 square, add a position plane, clip normalized output to [0,1], and resize back to 240 square. The raw linear baseline interpolates decoded planes without that image-space pipeline. Therefore this is equal in adjacent observed *plane content*, not a strict equal-total-information or equal-processing comparison. The difference could reflect resizing, clipping, normalization, the fixed checkpoint, IXI-to-MSD domain transfer, registered BRaTS release processing or a combination. No in-domain IXI validation comparison using the same ROI and output contract has been run, so the result does **not** identify a causal domain-shift penalty. The archive lacks linear0 full-support MSE, so no matched full-support conclusion is claimed.

This finding further weakens a performance narrative for the existing MIRA context-switch result. The same MSD cohort already showed that PCHIP using all four available even planes beat the additional-context HAT0/SwinIR2 ensemble in tumor ROI for 482/483 patients; that four-plane comparator has a different budget from either single phase-0 model. The present comparison supplies the missing two-adjacent-plane baseline and still finds a network deficit. Neither result evaluates lesion detection, segmentation after reconstruction, a T2-only reader or native 2D acquisitions. The labels were generated from multi-modal, registered BRaTS data.

The subsequent [full CPU pipeline-linear replay](MSD_PIPELINE_LINEAR_CONTROL_RESULT_2026-10-01.md) showed that preprocessing itself raises tumor MSE by +263.03, but HAT/SwinIR remain +528.89/+335.02 above that pipeline-matched linear output. This limits, rather than resolves, the artifact explanation. Next tests are in the [CPU and later-run queue](MSD_EQUAL_NEIGHBOR_FAILURE_FOLLOWUP_2026-10-01.md). The [focused prior-art note](literature/2026-10-01_msd_linear_failure_prior_art.md) shows that abnormality loss, simple interpolation and downstream task evaluation have precedents; this result can presently be offered only as a reproducible negative control and hypothesis generator, not a publication-ready first claim.

A later [same-case full acquired-foreground replay](MSD_FULL_SUPPORT_EQUAL_NEIGHBOR_POSTRESULT_RESULT_2026-10-01.md) found HAT near raw linear in the patient mean and SwinIR better in the mean, despite the tumor ROI deficit. Thus the negative baseline is region-conditional in this archive; it is not evidence of a whole-image collapse on MSD.
