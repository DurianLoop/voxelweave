# Post-pilot, full MSD pipeline-linear decomposition

Status: frozen after seeing the four-target `BRATS_001` software preflight (raw/pipeline linear tumor MSE 468.49/915.93), before computing any other pipeline-linear case. This is a post-result, post-pilot explanatory control, not independent confirmation. It tests whether the fixed model image pipeline itself accounts for part of the previously observed HAT0/SwinIR0 versus raw-linear0 tumor deficit.

Use exactly the 484 official MSD case IDs from the prior archives and retain `BRATS_044` as the one pre-existing failure. For each of the other 483 complete cases, require both exact local compressed source members, verify their SHA-256 against the archived neural/analytic records, and decode only the official registered-release T2 channel and label. No download, checkpoint load, model inference, GPU use, IXI test read or running-training interaction. Require the existing four targets, residue, lesion/local ROI size and raw-linear MSE to replay at tolerance `1e-6` for every target. Any mismatch stops the run; no replacement or case filter.

For each target, use all phase-0 planes `z=0,4,...` only to obtain the same case-level min/max as model `prepared()`. Normalize the two immediate phase-0 neighboring planes with `(x-lo)/(hi-lo+1e-8)` in float32, resize each 240-square plane to 256 square with `skimage.transform.resize(preserve_range=True, anti_aliasing=True)` to match the frozen model code, form the relative-position linear blend in float32, clip to `[0,1]`, resize to 240 square with the same function, and restore intensity using `(hi-lo)+lo` to float32. No residual network, position-channel use or parameter fitting enters this comparator. The original raw linear0 is computed directly from decoded planes in float64. Score both under the exact original target and masks.

For each region, calculate patient means by averaging two targets within residue then the two residues equally; cases get equal weight. Report patient-equal raw-linear0, pipeline-linear0, HAT0 and SwinIR0 MSE, each method-minus-raw-linear0 and model-minus-pipeline-linear0 paired difference, signs, and 5,000 paired patient-bootstrap percentile intervals with seed `20261008`. Report `pipeline_minus_raw / (model_minus_raw)` only as a ratio of cohort mean differences, not as an identified causal mediation share; it may be unstable or negative in a case and the two models can interact with preprocessing. Report tumor and equal-area local label-negative regions together. Keep all 483 cases and 1,932 targets; if not, this full analysis fails rather than silently becoming a selected subset.

The model pipeline contains one more operation absent from this linear control: learned residual prediction, followed by clipping the resulting image. Therefore the control estimates a descriptive pipeline-associated shift, not an isolated architecture effect. IXI-to-MSD transfer, label derivation from multimodal registered BRaTS, source resolution and intensity remain limits. Full-support linear MSE and clinical outcomes are outside the archived contract.
