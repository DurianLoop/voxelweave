# MSD first-case source and ROI qualification

After the [frozen tumor-ROI protocol](MSD_TASK01_TUMOR_ROI_CONTEXT_PROTOCOL_2026-10-01.md), the exact official `BRATS_001` image and label tar members were fetched by bounded S3 HTTP Range into `innovation/data/msd_task01_brain_tumour/`. Both compressed files had the expected member size, full gzip CRC and NIfTI shape/affine. The [record](experiments/msd_task01_brats001_pixel_qualification.json) stores compressed SHA-256, source offsets via the tar index and label-code counts; no model prediction or GPU operation was performed.

The T2w channel is `240 x 240 x 155`. Label counts are background 8,816,276; edema 53,050; non-enhancing tumor 27,189; and enhancing tumor 31,485 voxels. The frozen selection chose residue-1 target planes 53 and 81, residue-3 planes 55 and 79. Their acquired-only supports contain 15,705–18,235 pixels; within-support lesion ROIs contain 1,916–2,069 pixels, and each deterministic local label-negative control has exactly the same area. This is a **single-case implementation/source feasibility** result, not a test of the primary MIRA effect or evidence of clinical benefit. All 484 cases remain in the attempt denominator.
