# MSValid 的 O 差异主要表现为误差对齐变化

这是[预先写下的结果后分解方案](MSVALID_ERROR_ALIGNMENT_DECOMPOSITION_PLAN_2026-09-30.md)的 CPU 结果，**不是**独立确认，也不是锚点身份的因果份额。输入为事前主结果已经保存的[479 目标表](experiments/msvalid_mira_confirmation/per_target.csv)，未重新读取影像或运行模型。完整[逐目标/逐患者与汇总](experiments/msvalid_error_alignment_decomposition/summary.json)保留输入、方案和脚本 SHA-256。

恒等式为 `O=0.5-rho*sqrt(A*B)/(A+B)`，其中 `rho` 是两模型的真实误差余弦，`A/B` 为参考/伙伴 MSE。固定同一目标和 HAT 参考，以两路径对称分配从共享到不相交伙伴的 `O` 差异；84 人按 residue 1/3 各半权，再患者等权。全部 479 目标的两项和与原 `Delta O` 最大差 `2.50e-16`，复算主估计量 `0.1975653410` 与原 JSON 一致。

| 患者等权量 | 点估计 | 结果后患者 bootstrap 95% 区间 |
|---|---:|---:|
| 共享误差余弦 | 0.94366 | [0.94076, 0.94643] |
| 不相交误差余弦 | 0.55043 | [0.54273, 0.55838] |
| `Delta O` | +19.7565 百分点 | [19.3244, 20.1614] 百分点 |
| 误差对齐项 | +19.6110 百分点 | [19.1802, 20.0184] 百分点 |
| MSE 失衡项 | +0.1456 百分点 | [0.1264, 0.1660] 百分点 |

把伙伴 MSE 比值限制在 `[1/1.05,1.05]` 时，75 个目标、47 人中目标等权 `Delta O=+17.56` 百分点，75/75 为正；10% 窗口 141 目标、68 人中 +18.08，141/141 正；20% 窗口 259 目标、82 人中 +18.63，259/259 正。这些是按**需要目标真值的结果**筛出的子集，不与 84 人完整样本估计混同，也不能推断未筛人群。

此分解排除了“主现象主要是伙伴 MSE 变化在公式分母中造成”的简单解释；但对齐项使用 `O` 和 MSE 的代数反推，并非独立测量。共享/不相交条件仍改变相位几何和邻层内容，不能把 19.61 个百分点称为“纯锚点身份因果效应”。当前适合论文的表述是：**在冻结跨架构外部队列对照里，增强的误差可观测性伴随大幅下降的真实误差余弦，伙伴质量失衡只解释公式上的很小部分。**
