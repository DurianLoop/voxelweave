# MSValid 剩余 60 人影响量留出检验：严格几何基线下无增益

这是在 P25–P84 响应计算前写下的[冻结分析](MSVALID_INFLUENCE_P25_P84_FROZEN_ANALYSIS_2026-09-30.md)的一次性结果。五个 12 人 CPU 批次全数完成，没有失败或剔除；先经[只看完整性与源影像哈希的闸门](experiments/msvalid_influence_p25_p84_integrity/summary.json)核验：60 人、120 个中位目标、1,080 上下文、60 份 NIfTI SHA-256 全匹配，五批方案/推理脚本/资格/两个 checkpoint 哈希相同。训练侧 P1–P24 为 24 人、48 目标；一共享锚点行训练 192、留出 480。[冻结结果目录](experiments/msvalid_influence_p25_p84_frozen_analysis/summary.json)保留每批输入 SHA-256、脚本/方案哈希、逐行预测和逐患者误差。未操作 GPU 训练或 IXI 锁定 test。

主模型在 P1–P24 拟合，八个 `residue:精确左右 offset` 类别 one-hot 加层距为基线；增强模型只多一个真实锚点响应影响量。两者同用训练样本标准化、岭 `alpha=1`。P25–P84 仅用于评分，未调参。下表的差为**类别基线 MAE 减类别+影响量 MAE**，正值才表示增益；区间是 5,000 次患者重抽的探索性区间。

留出 480 条一共享行中，影响量与误差余弦在同时调整目标和精确上下文后的全局 rank 残余相关为 `+0.0611`，只作描述。逐行 CSV 的 MAE、患者得失数已由单独的只读 Pandas 计算复核，与汇总 JSON 精确一致。P13–P24 的[结果后精确上下文敏感性](INFLUENCE_EXACT_CONTEXT_AUDIT_2026-09-30.md)同样无增量；它和这 60 人检验方向一致，但不能合成一个新的事前外部确认。

**判定：停止把连续影响量作为跨来源可行动预测/上下文选择评分主张。** 原稿 fastMRI/IXI 的同/跨架构正确锚点响应相对错配的内部机制证据仍可如实报告，但在新来源的严格基线下没有预测收益；SAINT 的身份错配结果亦混合。不能用较弱的线性 offset 几何基线的 P13–P24 正值覆盖这里的完整剩余患者负结果。原事前 MSValid **共享/不相交** `Delta O=+19.7565` 个百分点是另一端点，保持有效且不被此负结果“撤销”；它也不因此变成纯身份因果证明。

范围限制：中位目标抽样是在看过 P1 试跑后确定，P1–P24 又参与分析设计和模型拟合；P25–P84 此前已用于外部主 `O` 结果，故这里只能称**同一来源、结果后设计的剩余患者留出**。总共 84 人×2 目标的响应分析不等于原 479 目标的完整方案；幅度 `.005/.02/-.01`、真实物理 ID 反事实、病灶标注和真实薄层参考仍缺失。鉴于主预测问题已失败，继续昂贵的完整 479 目标响应推理目前没有充分依据；若未来重启须先明确新的科学问题和独立方案。
