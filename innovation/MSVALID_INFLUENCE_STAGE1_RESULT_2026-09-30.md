# MSValid 跨架构响应影响阶段 1：12 人探索性结果

状态：**结果后、P1 试跑后制定的探索性抽样；不是事前外部确认，也不是原 479 目标响应方案的完整执行。** 原[方案](MSVALID_INFLUENCE_FUTURE_PROTOCOL_2026-09-30.md)、试跑时[方案快照](MSVALID_INFLUENCE_PILOT_PLAN_V1_2026-09-30.md)和 P2–P12 的[运行方案快照](MSVALID_INFLUENCE_STAGE1_PLAN_2026-09-30.md)保留版本边界。P1 最初跑满 4 个目标，合并时仅按后来固定的规则取每个 residue 的中位目标；P2–P12 各取两个。合并 12 人、24 目标、216 个上下文，其中一共享锚点 96 行。全量逐上下文数据、脚本哈希和分析代码分别在[结果目录](experiments/msvalid_influence_stage1_analysis/summary.json)、[推理脚本](experiments/msvalid_cross_arch_influence.py)、[分析脚本](experiments/analyze_msvalid_influence_stage1.py)。

输入：HAT fastMRI checkpoint 固定原 phase-0 两锚点；SwinIR 在 `z±1/2/3` 六个真实非目标层组成的九种左右上下文中切换。每个目标的 mask 由 HAT 两个真实参考锚点形成，六邻层统一 min/max；四个固定 Rademacher 场、主幅度 .01，在 CPU float32 形成按物理层 ID 嵌入的响应。六邻层中有些层在原 x4 合同下本为“缺失层”，在本实验是**额外获取该层的回顾性反事实上下文**，并非原扫描已经采集。目标像素只用于预测/响应形成后的误差评估。该共同缩放也使用比单一部署上下文更广的观测，不是临床运行方案。

**更严格、结果后增加的反解释检查改变结论。** [精确上下文敏感性](experiments/msvalid_influence_geometry_sensitivity/summary.json)把每个目标和准确的左右 offset 类型同时作为固定效应时，一共享影响量与误差余弦的残余 rank 相关仅 **+0.0386**，患者 bootstrap 探索性 95% 区间 **[-0.2788,+0.3157]**；再调整需要目标真值的伙伴 MAE 后为 **+0.0215**，区间 **[-0.2674,+0.2961]**。因此上表的 span/asymmetry 调整和目标内置乱**未排除精确上下文模板的解释**，不能据此宣称外部队列已复制“连续影响超出几何”的机制。精确上下文检查本身也是看过结果后增加的，不能反过来当作事前否证检验；它是必须展示的脆弱性。

一共享组的伙伴 MAE 均值**高于**零共享组，所以表中 `O`/对齐差异不能简单说成“伙伴均值越差，分歧越大”；但伙伴误差在不同候选上下文间仍变动，不能据此实现纯锚点因果隔离。相关与置乱负对照均是结果后探索；置乱的是目标内**影响量分数**，不是原计划要求的物理锚点 ID 重派，因此不能冒充那个更强负对照。只有主幅度 .01 已运行，.005/.02/-.01 排名稳定性和完整 84 人仍缺失。任何正值都不修复原 acquired-only guard 的可操作 AP 失败，也不证明病灶、真实薄层恢复或单例正确性。
