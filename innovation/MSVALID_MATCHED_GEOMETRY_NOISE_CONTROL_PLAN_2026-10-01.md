# MSValid matched-geometry independent-noise control: frozen before inference

**Status:** Post-result synthetic mechanism experiment. The original MSValid/ReMIND shared-versus-disjoint results and native-linear controls are already known. This plan does not create new independently acquired slices, a prospective patient source or a clinical noise model. Report null and unfavorable results as readily as positive ones.

## Narrow question

Does sharing the **same synthetic measurement-noise realization** matter to paired-error observability when the companion sees the **same published slice locations and underlying anatomy**? This tests one small component of measurement identity while removing the phase-0 versus phase-2 image-content and signed-geometry changes of the principal experiment. It cannot identify an original-acquisition identity effect, because the two images at each location are simulated from one published magnitude plane.

## Frozen data and perturbation

Use all 84 geometry-qualified MSValid RRMS T2 patients and exactly the 479 original residue-1/3 targets. Retain only the original phase-0 anchors `0,4,8,...`; no target pixels enter model inputs, noise generation or foreground support. For each patient, define `scale` as the median of all strictly positive absolute phase-0 anchor pixels. If nonpositive/nonfinite, record a failure. At each anchor pixel generate four independent unit-normal arrays from `numpy.random.default_rng(20261003)` in fixed patient order: A real/imaginary and B real/imaginary. For `f in {0.01, 0.05}`, compute synthetic magnitude observations `A=sqrt((x+f*scale*nA_real)^2+(f*scale*nA_imag)^2)` and likewise B. Reuse the same base random arrays across both levels. Zero level is a deterministic input-identity sanity check: A=B=x and the shared/disjoint contrast is exactly zero by construction; it needs no additional model inference.

The original published magnitude plane is used only as the deterministic synthetic signal and withheld evaluation target, not as an independently acquired thin-slice reference. Each patient's **clean phase-0 anchor** min/max defines one common normalization range for both A and B. Normalize A and B with that fixed range and clip their model inputs to `[0,1]`; resize with the original 256 x 256 interpolation function. These clean extrema are available to the synthetic generator, so this normalization is a diagnostic control rather than a deployable recipe. Score on the original acquired-only phase-0 1%-threshold foreground mask computed from clean anchors; the mask and target stay identical between conditions and levels.

For each target and level, IXI-trained HAT on A gives fixed reference `a`; IXI-trained SwinIR on A is the shared partner, and SwinIR on B is the independent-noise partner. Both partners use exactly the same phase-0 geometric anchors and the same quarter/three-quarter target offset. Use the existing IXI model classes and `predict` path, CPU float32 with two torch threads, the frozen checkpoint SHA-256 values from the [MSValid IXI-weight protocol](MSVALID_IXI_WEIGHTS_SECONDARY_PROTOCOL_2026-10-01.md), and source-file SHA-256 values from the current extracted-image manifest. Refuse to overwrite the result directory.

## Outcome and interpretation

For each target and level, compute the original `O=mean((a-b)^2)/(4T)` on the fixed mask and `Delta O_noise=O(a,SwinIR(B),y)-O(a,SwinIR(A),y)`. Average targets within each residue, residues within patient and patients equally, exactly as in the original MSValid analysis. Report both levels without selecting one after inspection, each shared/independent mean, `Delta O_noise`, 5,000-draw patient-bootstrap percentile interval with seed `20261003 + level_index` (index 0 for 1%, 1 for 5%), direction counts, partner MAE and failures. Verify all target positions against the original 479-row table. If both intervals include zero or effects are tiny relative to the original +24.1856-point phase contrast, say so without treating this as a causal decomposition. A positive synthetic-noise effect still does not prove anything about actual independent MRI acquisitions, due to arbitrary synthetic noise levels, fixed clean extrema, magnitude-noise approximation and model distribution shift.
