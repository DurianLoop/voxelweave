# MSValid 结果后控制实验（探索性）

制定时间：已知 [84 人主结果](MSVALID_EXTERNAL_CONFIRMATION_2026-09-30.md)为正之后。因此本文件和后续区间均**不属于事前确认**，也不能替代新队列复制。目的仅是寻找会迫使 MIRA claim 收窄的反例。

保持首份 T2、84 人、479 个 residue 1/3 目标、原 acquired-only phase-0 双锚点 mask、原 HAT/SwinIR checkpoint、原 CPU float32 代码、患者内两 residue 等权和患者等权不变。每个目标计算 HAT 与 SwinIR 的 phase-0/phase-2 两相位预测，并使用真实双锚点原始强度线性插值作为无学习伙伴。原主对照 HAT0+SwinIR0 / HAT0+SwinIR2 必须逐层重现，否则停止解释后续结果。

预先写下三个探索性对照：

1. **相位反向：** HAT2 固定，对比共享 SwinIR2 和不相交 SwinIR0。若患者等权 `ΔO` 变号或多数患者不再为正，原论文须明确 phase-0 方向依赖；若同号，仅减轻单一固定参考方向的疑虑，完整上下文和归一化仍共同变化。
2. **线性伙伴：** HAT0 固定，对比共享的原始强度线性 phase-0 与不相交线性 phase-2。若也为正，现象不需要第二个神经网络；这有助于界定普适性，也削弱“特定神经架构相互作用”作为新意的说法。若不为正，则神经伙伴/学习机制需单独解释。
3. **归一化差异审计：** 报告两个真实锚点子体积 min/max 相对其并集动态范围的差异。小差异只能排除粗大的归一化漂移，不能证明归一化无因果贡献。

三个对照均报告患者等权共享/不相交 `O`、`ΔO`、阳/阴患者数、伙伴 MAE 和 5,000 次患者 bootstrap 百分位区间（探索性，种子 20261001）。不依据结果筛患者/层，不用任一探索性阳性替换原单一预设主端点。不宣称身份效应完全排除几何混杂。GPU 训练进程和 IXI 锁定 test 不参与。
