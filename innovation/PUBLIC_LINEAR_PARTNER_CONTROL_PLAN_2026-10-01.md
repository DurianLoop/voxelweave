# Public-source native-linear partner control: frozen before this run

Status: post-result exploratory negative control. The IXI-weight MSValid and ReMIND main results, common-scale/reverse controls, and earlier *different-weight* MSValid linear-partner result were known before this plan. This cannot become an independent confirmation or a preregistered discovery.

## Question and fixed comparison

How much of the shared-versus-disjoint `O` contrast persists when the companion is simple native-intensity linear interpolation instead of SwinIR? Reuse the same IXI-trained frozen HAT phase-0 reference, original target list, native target image and acquired-only phase-0 foreground mask as each source's main experiment. Replace **both** SwinIR partner predictions by exact linear interpolation between the two real phase-0 or phase-2 bracketing published planes at the target's physical fraction. Do not normalize or resize the linear prediction; the fixed HAT output is generated by the original `prepared`/`predict` functions. The linear partner sees only its two bracketing observed slices.

For every target, calculate `O=mean((a-b)^2)/(4T)`, `T=(MSE(a,y)+MSE(b,y))/2`, and `Delta O=O(a,b_phase2,y)-O(a,b_phase0,y)`. Check the fixed HAT MAE and support-pixel count against the existing IXI-weight per-target CSV before accepting each row. Average targets within residue 1/3, then residues equally within patient, then patients equally. Report shared/disjoint `O`, `Delta O`, positive-patient count and partner MAE. For MSValid use 5,000 paired patient-bootstrap draws with seed `20261001`; for ReMIND sample each protocol stratum separately using seed `20261002`, matching the frozen main analyses. Never pool the two patient sources or treat targets as independent units.

## Population and integrity

MSValid: exactly the existing 84 geometry-qualified RRMS T2 patients and 479 targets, from the first public Zenodo T2 per patient. ReMIND: the complete original 63-series TCIA inventory; preserve the same single header exclusion, score exactly 62 patients/248 targets across 35 ordinary T2 and 27 BLADE. Check the IXI HAT checkpoint, source manifest or ZIP hashes, qualification snapshot and original per-target result hash before inference. CPU float32, two PyTorch threads, no GPU access. New output goes only to `innovation/experiments/public_linear_partner_control/`; refuse to overwrite it.

## Interpretation before results

The linear control tests whether the context effect is specific to pairing two learned architectures. A large positive linear contrast would weaken a network-specific mechanism claim, while still supporting a more general published-slice context dependence. A small or negative contrast would be suggestive but would not itself prove SwinIR-specific causality because partner quality, inductive bias and output shape differ. Subtracting linear `Delta O` from SwinIR `Delta O` is descriptive, not an identified effect component: `O` has a condition-specific MSE denominator. This post-result analysis cannot repair the phase-content/geometry confounding or ReMIND's `MPR` provenance limit. Report all patients and failures without changing rules after any early result.
