# Public-source MIRA: observed runtime and code provenance

This is a **current-environment audit**, not a proven clean-install lock or permission to distribute data/weights. The [read-only check](PUBLIC_ONLY_RUNTIME_CHECK_2026-10-01.py) validates Python minor version, nine directly imported distributions and the ten local model/normalization source files used by the two published-source CPU scripts. The [observed requirement list](PUBLIC_ONLY_OBSERVED_REQUIREMENTS_2026-10-01.txt) captures the versions seen on Windows in `D:\conda\envs\MRI`; no new environment was installed and no GPU operation is required to run the check.

Observed Python was 3.12.13; NumPy 2.4.3, SciPy 1.17.1, scikit-image 0.26.0, PyTorch 2.11.0+cu128, nibabel 5.4.2, pydicom 3.0.2, pandas 3.0.2, pytorch-msssim 1.0.0 and tqdm 4.67.3. The CUDA-enabled wheel was used with explicit `device="cpu"` for the source analyses. This differs materially from root `environment.yml`, which requests `numpy<2`, does not list `pydicom` and leaves most versions unpinned. Changing the shared root environment during the ongoing training would be inappropriate; it was left intact.

Run `D:\conda\envs\MRI\python.exe -B innovation\PUBLIC_ONLY_RUNTIME_CHECK_2026-10-01.py` from the repository root. The script reads package metadata and source bytes only: no images, checkpoint loading, CUDA initialization or model inference. The original MSValid/ReMIND inference result JSONs already seal checkpoint/script hashes; the current model-source hashes were not embedded in those historical result files, so this audit cannot by itself prove the exact historical checkout. The positive [position-channel pilot](POSITION_CHANNEL_ONLY_PILOT_RESULT_2026-10-01.md) recently imported the same wrappers and passed all original-output checks on 35 targets, which is stronger behavioral evidence for the present checkout but still a post-result subset.

The check returned `errors: []` in the current environment; `python -m pip check` reported `No broken requirements found`. The initial audit run found a **transcription error in this new check's SwinIR model hash constant**, which was corrected against `Get-FileHash`; no model source or checkpoint was changed. These passes verify the observed installation and named source bytes, not a fresh installation from the requirement list.

Remaining reproducibility gate: construct a fresh environment from an approved artifact, replay all frozen checks and a small fixed inference case on another installation, and package only code/metadata that may be distributed. IXI-derived checkpoints, patient-labelled CSVs and downloaded images remain local until rights and author review. Do not call the observed-version list a cross-platform lock or a public release package.
