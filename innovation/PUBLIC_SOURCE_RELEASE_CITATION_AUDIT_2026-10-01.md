# Public-source manuscript: citation and release gate

**Scope:** the current IXI-trained HAT/SwinIR internal scientific draft covers MSValid, TCIA ReMIND and TCIA UPENN-GBM processed DICOM T2. This audit uses captured official metadata and current files. It is not legal advice, author approval or a completed submission checklist. No patient pixels or local identifiers are proposed for external release.

| Item | Evidence currently available | Safe manuscript treatment / remaining gate |
|---|---|---|
| MSValid collection | The [direct Zenodo API audit](literature/msvalid_zenodo_citation_audit_2026-10-01.md) records title *MSValid Data Collection*, DOI `10.5281/zenodo.10875606`, date 2024-03-26, CC BY 4.0 and creators in order: Francesco Pappalardo; Giulia Russo; Valentina Di Salvatore; Sebastiano Battiato; Francesco Guarnera; Alessia Rondinella. The original downloaded NIfTI integrity manifest and 84-patient selection are archived separately. | Cite these six creators and the DOI, with attribution and any required indication of modifications. The license record alone does not verify every local file's de-identification or permit releasing internal ID maps. |
| TCIA ReMIND collection | The [official NBIA source audit](REMIND_NATIVE_T2_SOURCE_AUDIT_2026-10-01.md) records DOI `10.7937/3RAG-D070`, CC BY 4.0, 63 frozen 2D T2 series and ZIP attribution/no-reidentification terms. A [fresh TCIA/DataCite citation audit](literature/remind_official_citation_audit_2026-10-01.md) now captures TCIA's required 18-creator, 2023, Version 1 dataset citation; DICOM `ImageType` contains `MPR`. | Use TCIA's full required data citation and DOI, in addition to any relevant publication citation. Do not infer independent raw acquisitions or publish source DICOM/ID maps from the CC BY label. |
| TCIA UPENN-GBM Version 2 | The [official TCIA/DataCite citation audit](literature/upenn_gbm_official_citation_audit_2026-10-01.md) records Bakas et al. (2021), DOI 10.7937/TCIA.709X-DN49, 31 ordered creators and CC BY 4.0. The selected 374-series DICOM stratum is wholly DERIVED/SECONDARY/OTHER. The [official label-space note](UPENN_GBM_LABEL_ALIGNMENT_GATE_RESULT_2026-10-01.md) says atlas NIfTI/segmentation do not align with DICOM by design. | Include the required UPENN dataset citation and processing boundary. Do not expose downloaded DICOM/patient identifiers or claim that NIfTI tumor masks validate the DICOM targets. The separate 69 GB aligned NIfTI/label route needs its own source and scientific review. |
| IXI training data | The [existing source audit](../design/paper/FINAL_SUBMISSION_PREPARATION/DATA_ETHICS_CITATION_AUDIT.md) records the official IXI source, Imperial College Biomedical Image Analysis Group attribution and CC BY-SA 3.0. The project uses locally implemented HAT/SwinIR wrappers and locally trained checkpoints, not official MRI weights. | Attribute IXI correctly; retain local-implementation wording. Before distributing checkpoints or training-derived assets, determine the actual CC BY-SA obligations and compatibility for those **specific artifacts** with the data steward/institution. Do not mark weight redistribution approved from a dataset-page license alone. |
| Current internal quantitative figure | The [three-source figure source note](figures/PUBLIC_THREE_SOURCE_FIGURE_NOTE_2026-10-01.md) records anonymous patient-level values, not patient pixels or source ID strings. Older fastMRI/NingXia figures are excluded. | Figure can be reviewed internally. External release still needs authors' approval, provenance check and source attribution in the final venue package. The original CSVs with source labels stay internal. |
| Code and environment | The [reproducibility supplement](PUBLIC_ONLY_REPRODUCIBILITY_SUPPLEMENT_2026-10-01.md) records the model and source hashes, but the root `environment.yml` has `numpy<2` while the tested environment has NumPy 2.4.3 and uses pydicom absent from that YAML. A git commit alone does not contain every current untracked research file. | Build and test a clean, distributable environment lock and code snapshot after rights review. Do not claim exact reproducibility from the current root YAML or from `HEAD` alone. |

On 2026-10-01, the configured `127.0.0.1` proxy failed, but a direct no-proxy HTTPS read of both the TCIA collection page and DataCite DOI record succeeded; the [official snapshots](literature/remind_official_citation_audit_2026-10-01.md) now close the ReMIND data-citation text gap. IXI-derived checkpoint licensing, a distributable code/environment package and real-author approval remain separate external-release gates; a dataset-page license alone does not settle them.

The UPENN citation and public-source provenance have also been archived, but adding that third source does not settle IXI-derived checkpoint redistribution. The old five-page PDF remains a two-source historical snapshot; only the Markdown and [new anonymous figure](figures/PUBLIC_THREE_SOURCE_FIGURE_NOTE_2026-10-01.md) currently reflect all three sources. Any external package still needs a rebuilt, reviewed PDF and the rights/code audit above.
