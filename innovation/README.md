## 先看结论



本轮重点证伪的问题是：**给定固定 base 与候选修正，能否只凭真实稀疏观测预测修正方向的收益，并在完整缺失层评分中取得收益且控制结构损害？** 这比单纯估计绝对误差更具体；收益公式和门控思想本身没有首创性。SafeRestore 已直接研究候选恢复动作与风险认证，DRIFT、CRIS、HiFi-Diff、SliceBridge 等也覆盖了许多看似自然的扩散、跨平面或联合生成组合。



后续完整 CPU 配对推理将这一假设限制得更窄：旧 orientation 有 +0.14815 dB 的局部真值 oracle 空间，但留一患者可观测 patch 回归只比固定混合好 +0.01382 dB，结构代理仍退化；修复版 wavelet3 的局部 oracle 额外空间仅 +0.01651 dB。这两对固定动作都不足以支持新 gate 训练或可发表的正向 claim。下一步转向[现有论文 claim 审计与观测模型失配](EXPERIMENT_QUEUE.md)，不在同一开发集上无限换专家。



历史开发集上的病例级与逐层开关也未给出足够的简单门控收益。逐层 PSNR 真值选择在 207 张缺失层上相对 control 为 +0.13201 dB，但 HD95 强度代理仍退化 +0.10942；仅比固定方向增强的 +0.09439 dB 多约 0.03762 dB。这不是局部 patch 融合的上限，也不是独立确认。DICOM 全系列头审计表明名义层厚大多是 5 mm，不能从名义字段反推出真实 slice response kernel。



另一个现有研究线 MIRA 已完成[事前冻结的 MSValid 外部确认](MSVALID_EXTERNAL_CONFIRMATION_2026-09-30.md)：84 名 RRMS 脑 T2 患者、479 个目标，冻结 HAT→SwinIR 的共享/不相交锚点对照使可观测误差比例增加 **19.76 个百分点**（患者 bootstrap 95% CI 19.33–20.16），84/84 人为正；phase-2 伙伴整体 MAE 未更差。这支持有边界的共享测量机制 claim，但不产生新插值器或部署可靠性保证。



[第二患者来源 ReMIND 的冻结确认](REMIND_NATIVE_T2_CONFIRMATION_RESULT_2026-10-01.md)在术前脑肿瘤 2D T2 发布层网格上完成 62/63 人、248 固定目标：`Delta O=+26.40` 个百分点，5,000 次分层患者区间 +25.69 至 +27.17，普通 T2 与 BLADE 两组均正；63 份 ZIP 哈希与全部统计由只读脚本复核。此方案是在看过 MSValid 后设计的另一个来源单配对，并非全架构矩阵重复。DICOM 均带 `MPR`，无法证明原始独立采集层；相位切换也共变邻层内容、几何与归一化。



[同一 MSValid 队列的 IXI 权重次级复制](MSVALID_IXI_WEIGHTS_SECONDARY_RESULT_2026-10-01.md)在运行前冻结方案并完成全量 84 人/479 目标 CPU 推理：`Delta O=+24.19` 个百分点，患者区间 +23.71 至 +24.67，84/84 人正，伙伴平均 MAE 未变差。它是看过第一轮结果后的**同队列新权重对照**，不能算第二个独立患者来源或事前外部确认；结果支持探索只使用公开 IXI/MSValid 来源的重新构稿路线。



结果后控制在同一 84 人上给出反向固定 HAT2 `+19.50`、线性伙伴 `+14.62`、共同锚点 min/max `+19.48` 个百分点，均 84/84 人为正。共同缩放使原效应减少 0.28 个百分点，排除了独立归一化差异作为唯一原因；仍未隔离邻层内容/相位几何，也不是新增的独立确认。[两篇近期误差/歧义论文](literature/2026-09-30_mira_uncertainty_neighbours.md)限制了“新不确定性框架”说法。



[连续影响量加严审计](INFLUENCE_EXACT_CONTEXT_AUDIT_2026-09-30.md)显示：原稿 fastMRI/IXI 四层在目标与精确上下文调整后仍为正相关（+0.24 至 +0.34），但病例留出预测的增量很小，三层探索性区间跨零。MSValid P13–P24 的线性几何留出正收益在加入精确上下文类别基线后消失并轻微反向。因此连续影响量目前是有边界的机制线索，不能写成外部队列已证实的可行动评分。



进一步只读 834 个原稿 acquired-only 响应文件的[物理锚点错配负对照](ACQUIRED_RESPONSE_ID_PLACEBO_RESULT_2026-09-30.md)显示，fastMRI/IXI 四层正确响应配对相对错配的残余相关优势为 +0.185 至 +0.304；[MSValid 误差对齐分解](MSVALID_ERROR_ALIGNMENT_DECOMPOSITION_RESULT_2026-09-30.md)显示主 `ΔO` 的质量失衡项仅 +0.146 个百分点。二者均为结果后机制敏感性，不能改称独立确认或身份因果效应。



[同一旧队列的 HAT→SwinIR 跨架构复核](CROSS_ARCH_ACQUIRED_RESPONSE_RESULT_2026-09-30.md)中，正确锚点响应相对错配仍有 +0.212（fastMRI）/+0.114（IXI）的精确上下文残余相关优势；病例留出预测增量却很小，IXI 区间跨零。它把内部机制线索延伸到跨架构，但没有消除 MSValid 外部增量失败。



[SAINT 严格审计](SAINT_EXACT_CONTEXT_AUDIT_2026-09-30.md)在两旧队列的精确几何控制后仍为正，但原始响应错配揭示混合结果：fastMRI 的正确配对不明显优于错配 A，IXI 也不优于错配 B；因此不能把第三架构列为稳健物理身份特异性复制。[MSValid 剩余 60 人冻结留出](MSVALID_INFLUENCE_P25_P84_RESULT_2026-10-01.md)在全部五批及源影像哈希通过后，精确上下文基线加入影响量的误差余弦 MAE **变差 0.000168**，患者区间跨零，目标内排序不变。连续影响量作为外部可行动评分的研究分支停止；事前主 `Delta O` 机制现象仍成立。
