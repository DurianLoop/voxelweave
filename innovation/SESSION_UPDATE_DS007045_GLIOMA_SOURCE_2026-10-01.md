已核读 Filimonova 2026、UCSD-PTGBM 2025、LUMIERE 2022 三篇全文，分级结论见[论文与来源报告](literature/2026-10-01_three_glioma_label_sources_result.md)。Filimonova 的 OpenNeuro `ds007045` 是目前最可访问的同空间处理后 T2/专家复核标签来源，但论文 v1.0.1/337 人与当前公开 v2.0.1/363 人不同；当前 README 2018-2025 与论文队列段落 2024-2025 也不能直接等同。原始 T2 不可直接用 MNI152 标签。UCSD 数据与 BraTS 2024 部分重合，LUMIERE 的体素分割并非人工真值。

随后仅用三页官方 S3 清单完成当前文件级分母审计：处理后 T2 与肿瘤标签各 363 个受试者，363 对一一对应，八站点计数与当前 README 一致，未发现清单缺配或重复键。这不是逐例 affine/标签质量或患者身份独立性的证明；原始 XML 和摘要在[当前配对清单](literature/source_cache/ds007045_current_pair_audit_2026-10-01/result.json)。
