# 动作收益监督目标的有限 CPU 数值审计

依据已读 learning-to-defer/cost-sensitive 原文，在 MRI 策略尚未训练前检查两个目标：预测 `P(gain>0|observed)` 后以 .5 选择动作，与预测 `E[gain|observed]` 后以 0 选择动作，是否等价。它们一般不等价是已知决策理论，本审计只作实现/目标资格，不作创新定理或 MRI 收益。

固定四个二值位置；GT 取全部15个非空掩膜，两个候选预测各取全部16个掩膜；同一可见 observed 不能区分的两种 GT 状态分别以3/4、1/4出现。枚举 15x15x16x16=57,600 个有序配置，不选有利子组。GT 非空，hard Dice 分母总非零；没有替换本项目真实空值约定。动作0为基础预测、动作1为修正后预测，无额外观测信息。

用 Fraction 精确计算两状态 Dice、配对 gain、期望 cost（1-Dice）和正 gain 频率。独立用集合交集重算全部240个 GT/预测 Dice。逐配置核“期望 gain 最大”与“期望 cost 最小”决策完全一致；记录正 gain 概率策略的全部目标不一致数及前10个固定遍历顺序反例、期望损失后悔。零收益时统一保留基础动作；无训练、无阈值调节。

预算 <=60秒、输出 <5MB，标准库 CPU、无 MRI/GT 文件读取、无神经前向/更新/GPU。所有结果包括零反例的可能性都保留。它不会验证真实 observed 是否能估计这些条件分布，不证明收益头泛化，也不改变当前低 LR 训练。
