# 动作收益监督目标：已完成的 CPU 资格检查

[事前协议](TASK_GAIN_TARGET_CPU_AUDIT_PROTOCOL_2026-10-07.md)、[主结果](experiments/task_gain_target_cpu_2026_10_07/attempt01.json) 与 [独立布尔成本重放](experiments/task_gain_target_cpu_2026_10_07/independent_boolean_cost_replay_attempt01.json) 均保存；两脚本实际 exit0、complete=true、errors=[]。主枚举约 .95 秒，标准库 CPU，无 MRI/GT 文件读取、神经前向、训练或 CUDA。已知决策理论的数值核验，不是创新定理或患者收益。

4 个二值位置、15 非空 GT、16 候选预测、两种条件 GT 状态（概率3/4和1/4）；完整57,600有序配置。集合交集与 bit-count 独立核全部240种 Dice。按期望配对 gain 与按期望 cost（1-Dice）的决策 **全部相同**，证明在这项有限实现中“收益选择”就是成本敏感选择，不能包装成新算法。

以 `P(gain>0)>.5` 决定行动，与期望 Dice 最大的动作有 **4942** 个目标差异：744 个接受负期望收益，3814 个错过正期望收益，384 个在零期望收益时动作不同但无后悔。严格正后悔4558个，全部由独立实现复算。这里是穷举人工配置，不是57,600患者，也不是实际MRI失败率。

一个实际核出的反例：四位置基础预测全部为前景，动作移除一个位置。多数状态 GT 在另一个位置，Dice 从 .4 到 .5，gain=+.1；少数状态 GT 恰好在被移除位置，Dice 从 .4 到0，gain=-.4。收益为正的概率 .75，但期望 gain=`.75*.1+.25*(-.4)=-.025`。概率策略会行动，最大期望 Dice 的策略应保留基础预测。这不需要噪声、模型拟合或未知条件概率估计来解释。

它带来的准备变化：如果后续主目标是完整 FOV 的期望任务改善，收益监督必须保留大小，或直接学习两路径成本；不能只给 `gain>0` 二分类标签后自动以 .5 决策。若目标是“受益概率”或风险约束，概率标签仍可能合理，但须另明确定义目标与坏事件幅度，不能混称最大平均 Dice。此检查没有证明真实 observed 能估计条件收益，更没有通过本项目强任务/独立确认门槛。

真实空 GT、empty prediction、四域分母的原定义保持。合成 GT 非空仅用于保证这个固定算术审计无 undefined，不能照搬为患者筛选条件。
