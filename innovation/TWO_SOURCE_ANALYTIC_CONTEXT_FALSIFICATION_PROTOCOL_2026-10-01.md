# Two-source analytic context falsification protocol

Frozen after all original MSValid/ReMIND neural and linear-partner results, but **before** computing the new PCHIP-reference predictions. This is a post-result exploratory negative control, not a third confirmation or a method validation. Question: does a purely analytic fixed-reference pair reproduce a substantial shared-to-disjoint published-neighbor observability contrast on the same 727 external targets?

Use exactly the 84 MSValid patients/479 targets and 62 ReMIND patients/248 targets in the original IXI HAT/SwinIR `per_target.csv` files. Require their registered SHA-256 hashes, original source-image/ZIP hashes, qualification records and exact patient/target IDs. Retain the original phase-0 acquired-anchor foreground support: a pixel is supported if either immediate phase-0 anchor exceeds 1% of its own max absolute intensity; verify the count against the original result. Use the original raw decoded float32 image planes and cast to float64 for interpolation/metrics. For each target z, set `left=4*floor(z/4)` and make fixed `a` the SciPy PCHIP estimate from phase-0 planes `[left-4,left,left+4,left+8]`. Make shared `b0` raw-intensity linear interpolation from `[left,left+4]`; make disjoint `b2` raw-intensity linear interpolation from bracketing phase-2 planes `[2+4*floor((z-2)/4), 6+4*floor((z-2)/4)]`. Reject any missing plane, nonfinite value, empty support or zero paired error denominator. No learned model or checkpoint is loaded.

On each original target/support, compute `MSE(a,y)`, both companion MSEs, `mean((a-b)^2)`, `O=mean((a-b)^2)/[2*(MSE(a,y)+MSE(b,y))]`, `Delta O=O(a,b2,y)-O(a,b0,y)`, and the raw disagreement and paired MSE components. Preserve both residue groups; average targets within residue, then residues equally per patient, then patients equally per source. Report all eligible patients/targets and failures. For MSValid draw 5,000 patient bootstrap replicates with seed `20261007`; for ReMIND draw 5,000 replicates within its 35 ordinary-T2/27 BLADE strata with seed `20261008`, weighted by their patient counts. Intervals are exploratory. Join the original neural per-target `Delta O` on exact patient/z IDs, compute patient-level analytic-minus-neural differences and paired bootstrap intervals using the same source-specific draws. Do not pool different sources as extra independent confirmation or claim a neural-specific contribution from the difference: marginal errors differ.

Report descriptive positive-patient counts, shared/disjoint O, companion and reference MSEs, and a fixed-shared-denominator sensitivity. No success threshold is set. A large positive analytic effect would falsify any assertion that the cross-source context contrast needs learned architectures; a small/null effect would not prove architecture specificity. Neither outcome identifies original acquisition identity, makes a deployable error score, or demonstrates improved equal-information reconstruction or clinical benefit. Run CPU only with no GPU, training-process interaction or locked IXI test.
