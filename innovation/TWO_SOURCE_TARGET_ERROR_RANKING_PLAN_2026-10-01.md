# Two-source target-error ranking check: frozen before calculation

**Status:** Post-main-result analysis. The source-specific context contrasts, native-linear control and fixed-denominator sensitivity are known. This plan fixes a new, narrower question before reading the score-to-error associations. It uses only original hashed CSVs, no images, model inference, GPU or locked test data. Report both sources and all scores even if the result is unfavorable.

## Question and data contract

The large mean change in disagreement energy does not by itself imply that disagreement identifies the **higher-error target**. For the original IXI-trained HAT reference, compare four output-only disagreement scores on every original target: HAT versus SwinIR under shared phase 0 (`S_shared`) or disjoint phase 2 (`S_disjoint`), and HAT versus native linear interpolation under the same two contexts (`L_shared`, `L_disjoint`). The outcome is the original fixed HAT phase-0 MAE against the withheld target on the fixed acquired-only mask. Scores use root mean squared output difference `sqrt(D)`, where `D=4*T*O` is reconstructed from the stored paired MSE and `O`. For the linear partner, `T=(HAT_MSE+linear_MSE)/2` using the matching original HAT MSE. Confirm exact target keys, support, fixed HAT MAE and source hashes between the main and linear CSVs. ReMIND's stored disagreement MSE must agree with reconstructed `D`.

No score is normalized by target-derived error, and no score contains the withheld target at inference time. However the disjoint-context scores require phase-2 published planes that are **not available** when only phase-0 x4 anchors are observed in the intended sparse-input task. This is a retrospective information test, not a deployable error detector. The analysis uses target truth only to evaluate rankings.

## Fixed endpoint

Within each patient and residue (1 or 3), enumerate all unordered target pairs. Compare the score difference with the HAT-MAE difference: concordant=1, discordant=0, exact score or outcome tie=0.5. For each score, average pairs within residue, then residues equally within patient, then patients equally. All qualified MSValid 84 patients/479 targets and ReMIND 62 patients/248 targets are required; each patient/residue must contain at least two targets. Report the four means, two within-partner disjoint-minus-shared differences and the disjoint SwinIR-minus-disjoint-linear difference. Report direction counts by patient and the number of evaluated pairs. No score tuning, thresholds or patient exclusions after inspection.

Use 5,000 paired patient-bootstrap draws for differences, seed `20261004` for MSValid and `20261005` for ReMIND. ReMIND must resample its 35 ordinary T2 and 27 BLADE patients separately and weight by completed group count. This is an exploratory post-result interval conditional on cohort/model selection, not a new prospective test. A mean above 0.5 would show within-residue ranking in this archive, not calibrated risk. If disjoint SwinIR does not clearly beat shared and simple linear scores in both sources, stop any claim that the large `Delta O` supplies a superior target-error ranking signal. Even a positive result cannot be called clinically deployable without an acquired-only protocol and independent validation.
