# UCSF-PDGM as a possible independent T2/label confirmation source

This is a read-only source gate, written before reading the official collection page or any UCSF-PDGM image/label bytes in this workspace. The question is whether the official release contains a usable T2 image and expert glioma mask for the **same patient, scan and spatial grid**, with a separable identity from the processed MSD Task01/BRaTS cases. It is not a license to transfer a full collection or run another post-result tumor experiment immediately.

First archive the official TCIA UCSF-PDGM collection page, its exact URL, response SHA-256, readable text and linked official data/citation routes. Read the associated data descriptor if openly available. Check patient count, T2 protocol and whether segmentation is manual, automatic or derived; document whether T2 and label files are NIfTI, DICOM-SEG or another form and whether their release grids align. Identify the smallest lawful file-level header pilot and usage/citation terms. Do not decode patient pixels or download bulk images during this gate. A header pilot requires a fixed case and file list, exact IDs, source hashes, shape/affine comparison and recorded failures before a tumor-metric protocol.

Independent-source status also requires patient/collection overlap review against MSD Task01/BRaTS and UPENN; a different dataset name alone is insufficient. If original acquisition metadata show 3D or derived volumes, keep claims at the release-grid level. If there is no directly accessible aligned expert label, record the failure and continue searching; do not borrow a mask from another release without a verified transform.
