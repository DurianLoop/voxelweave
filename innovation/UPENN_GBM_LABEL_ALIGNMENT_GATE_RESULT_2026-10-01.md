# UPENN-GBM tumor-label alignment gate for the DICOM T2 audit

The [official TCIA collection page snapshot](literature/source_cache/upenn_gbm_collection_page_2026-10-01.html), SHA-256 12dfaa491640338ab7ba553776bf95aef29f9a349a725c0535af9ebfa9cb24c2, describes computer-aided, expert-corrected tumor-subregion labels and corresponding co-registered mpMRI **NIfTI** volumes. Its submitting-group note explicitly states: "The NIfTI images are all registered to a common atlas (SRI) using a uniform preprocessing and the segmentation are aligned with them. Therefore the NIfTI images will not align with the DICOM images, by design." The same page lists a separate 69 GB NIfTI/segmentation package, whereas the [frozen 374-patient MIRA result](UPENN_GBM_PROCESSED_T2_CONTEXT_RESULT_2026-10-01.md) uses selected processed **DICOM** T2 series. The note is direct source evidence against treating the released labels as same-grid truth for those DICOM targets.

The selected DICOMs are already marked DERIVED/SECONDARY/OTHER; their exact processing lineage relative to the atlas NIfTI is not documented in this audit. Patient identifiers alone cannot supply a slice-to-label transform. No NIfTI label, patient pixel or locked IXI test image was downloaded/read for this check. The first read-only NBIA SEG query failed through the system proxy (WinError 10061). A [direct-route replay with archived raw responses](literature/source_cache/upenn_gbm_label_routes_2026-10-01/index.json) then returned HTTP 200 with an empty body for SEG. The no-modality query returned 3,680 series, all MR, whose SeriesInstanceUID set exactly matches the [earlier frozen MR inventory](literature/source_cache/upenn_gbm_getSeries_2026-10-01.json). This establishes no DICOM SEG **in that NBIA series inventory at this retrieval**, not the absence of separately released or later labels. The [read-only metadata script](literature/audit_upenn_gbm_label_routes.py) and both response hashes are archived.

**Decision for the existing DICOM endpoint:** do not compute lesion Dice, volume error, recall or lesion-region MSE using the atlas labels as if they indexed the 1,496 frozen DICOM target planes. First obtain an official DICOM-to-atlas transform chain or a separately authoritative DICOM-space annotation and verify physical mapping on every intended case under the [clinical-task label gate](CLINICAL_TASK_LABEL_SOURCE_GATE_2026-10-01.md). A *new* NIfTI-space MIRA protocol could use the aligned NIfTI/labels together, but would test a different, atlas-registered release with its own patient selection and target geometry; it cannot be retroactively called a clinical validation of the frozen DICOM result.

This closes the immediate shortcut to clinical labels, not the broader clinical-task research direction. The official collection and citation remain [Bakas et al., UPENN-GBM Version 2, DOI 10.7937/TCIA.709X-DN49](literature/upenn_gbm_official_citation_audit_2026-10-01.md), CC BY 4.0.
