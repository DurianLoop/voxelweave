# UPENN atlas NIfTI official inventory and bounded header pilot

Frozen after the public package root was successfully listed and before any NIfTI file request. The official TCIA page links to Faspex package 604 and the public web client itself uses `authorize_public_link`, token exchange and the API v5 package-file browser. Use only that documented public-link session and read-only listings. Never store or print a bearer token, authorization code, signed download URL or the full transfer spec. Do not request the 69 GB package.

1. Reconcile the full `/images_structural`, `/images_segm` and `/automated_segm` listings against the official 671-row availability/acquisition CSVs. Parse exact scan IDs, keep corrected and automated labels separate, and report all missing/extra IDs. A CSV `Available` flag alone is insufficient eligibility.
2. Preselect the lexicographically first corrected-label, approximately 0.9 mm T2 scan with both a structural directory and `images_segm` entry; present inventory suggests `UPENN-GBM-00002_11`. List its structural directory and require exactly one T2 file and one corrected segmentation file of the matching scan ID. Record only paths, sizes and source response hashes.
3. Ask only for the two selected paths through the official client API's partial-file transfer-spec endpoint. If a supported small-file HTTP transfer can be completed without the Aspera Connect plug-in, cap received bytes at 10 MB and archive both exact files/hashes. If not, stop and record the route without guessing authorization or transferring the whole package.
4. Decode only the first 352 bytes of each gzip NIfTI file (header plus extension flag) with standard-library gzip/struct. Check NIfTI magic, dimensions, datatype, pixdim, qform/sform codes and affine or qform transform. Do not read image voxels. If one-to-one same-grid equality fails, stop; if it passes, freeze a new atlas-space tumor-region experiment before decoding pixels. This pilot proves release-space pairing only, never native-acquisition thin truth or clinical benefit.

No GPU, training process or locked IXI test image is involved. The existing 374-patient DICOM analysis remains separate.
