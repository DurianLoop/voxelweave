# 已见开发例的固定动作收益上限试验

本方案只用已保存的 VS-SEG-001 七条件重建体积，不重跑推断。001 属于分割模型训练名单，且已用作本项目软件开发；所有结果都是可行性诊断，不能成为独立确认或可发表 claim。当前固定 45 CISS + 1 TSE 队列不读动态效果量、不改参数。用户的 GPU、原终端训练和锁定 IXI test 均不进入此试验。

## 与既有工作的区别和先例

原 fastMRI 23 人的 local correction oracle 已比较 PAST control/orientation，并有重叠 patch 与患者守卫，改进有限；不能重新给它命名当作创新。此次问题是新的已见 CISS 病例、强 PCHIP 基底到固定 IXI HAT 的动作方向，在原网格上按局部平方误差收益限制幅度，是否仍有空间。m/d 二次公式本身是常规恒等式；oracle 看隐藏层真值，不可部署。

只检验 raw PCHIP→HAT 与 pipeline PCHIP→HAT 两个预写动作。raw PCHIP 是强解析对照；同处理 PCHIP 用于排除缩放/裁剪管线混杂。SwinIR 已保存但不择优换成动作。输入和源数组 SHA256 必须与既有 attempt01/独立 preflight proof 一致。

## 固定计算

保存体积原生为 384×384×80 float32；phase 0 观测 0,4,…,76。仅 57 个内部缺失层的观测相邻前景并集支持域进入图像目标。观测层逐位保留；最后三层仍复制末观测，保持原设计。标签来自该开发例保存的原 JSON 掩膜，只用于诊断病灶误差，不能用来选择部署 α。

令基底 b、候选 r、δ=r-b、残差 e=y-b。支持域内某非重叠 tile 的 d=sum(δ²)、m=sum(δe)。α=clip(m/d,0,1)，d=0 时 α=0。输出 b+αδ；预写 patch size 为 16、32、64，主可行性粒度为32，不按最好结果改选尺度。完整层单一 α 与完整体积单一 α作为较简单 oracle；固定 α=0,.25,.5,.75,1 为无需真值的基线。像素 α为更自由动作空间的描述性上限。

非重叠 tile 使固定支持域的每个局部优化可独立相加，验证收益恒等式 sum[(b-y)²-(b+αδ-y)²]=2αm-α²d；不把重叠 α 的平滑拼合冒称同一最优上限。所有计算用保存的 float32 数组转 float64，既有方法终点可核对；只描述该动作线段上的平方误差，不能保证 PSNR以外指标、病灶误差、3D连续性或分割任务不降。

每策略保存支持域的目标等权/像素加权 NMSE、原 JSON 病灶的相同两种汇总、目标层误差分布、tile α/d/m/实际收益、α取0/1/内部值的比例、仅观测得到的 d 与真实收益符号的关系。不把单开发例 patch 数当患者样本数，不计算患者置信区间。

## 预写后续门槛与解释

只在32像素主粒度相对于两个全局固定输出中支持域误差较佳者，支持域目标等权误差改善至少0.1 dB，并且原 JSON 病灶两种 NMSE各不高于该指标在两个固定输出中的较小值时，称该开发例存在值得扩展到多开发患者的动作空间。每个病灶指标都过自己的较强参照，不能以整图获胜的参照掩盖另一输出更好的病灶误差。否则不因像素 oracle 或另一个粒度好看而启动收益头训练。0.1 dB 是开发资源筛选阈值，不是临床重要差异。

即使门槛满足，也不能直接训练/宣布新方法；必须在其他已有训练/开发患者或明确划分的开发来源建立稳定空间，并比较观测可用的固定/phase/spacing策略、普通误差头和动作收益头。已经用于当前固定研究的45例评分后仍只能做诊断，不能作为下一新方法的未见确认。任务保真仍需要真正分割结果；这次不追加全体积任务推断与分割 α调参。

本试验先运行数值与保存数组一致性检查，且 independent verifier 用不同的向量化/线段投影实现复查总误差与每tile系数。若源文件/数值核验失败，保留错误并停止，不能重新生成更有利数组。队列优先，最多一个轻量数组计算进程，不额外启动模型 worker。
