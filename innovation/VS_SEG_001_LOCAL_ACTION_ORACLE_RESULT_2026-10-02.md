# 局部固定动作上限：一个已见开发病例的小幅空间与反证

在已保存的 VS-SEG-001 上，主粒度32像素的 raw PCHIP→HAT oracle 相对支持域较好的固定输出 HAT 多出0.11825 dB，两种病灶误差守卫通过；pipeline PCHIP→HAT 多出0.10078 dB，但病灶目标等权误差守卫失败。系数使用隐藏层真值，只有一个已见开发患者；这不是可部署方法、独立确认或可发表 claim。

57个内部缺失目标全部评分，支持域8,306,193像素；病灶有效目标10个、5,649像素。目标层和 tile 都不是独立患者，不能用它们扩张样本数或计算患者显著性。取得更好的支持域 oracle 也不意味着完整分割任务改善。

两个动作的体积单一系数 oracle 都选α=1，即 HAT；按层系数只有很小额外空间。16像素和像素 oracle 空间更大，但自由参数也更多，且不是主门槛；pipeline 动作的16像素病灶两指标较好，不能据此把失败的32像素方案改写为主要成功。固定0/.25/.5/.75/1全部公开，简单混合也能改变病灶误差。

## 可观测残差幅度的诊断

[幅度与收益诊断](experiments/vs_seg_001_local_action_oracle/observable_energy_diagnostic.json)只以两固定输出差的 d/支持像素数作为可部署特征；收益正负需要隐藏真值。每个粒度只作该患者内描述，未训练预测头，没有患者划分、校准或泛化保证。[独立平均秩复查](experiments/vs_seg_001_local_action_oracle/observable_energy_independent_rank_verification_v2.json)与脚本的 tie-aware AUC 全部一致，不生成p值或患者区间。

| 主32像素动作 | 完整 HAT 动作改善支持域的 tile 比例 | 大幅度→有益动作 AUC | oracle α=0 的 tile |
| --- | ---: | ---: | ---: |
| raw PCHIP→HAT | 7,244/8,208 = 88.26% | 0.45408 | 87 |
| pipeline PCHIP→HAT | 5,761/8,208 = 70.19% | 0.71628 | 616 |

幅度的排序关系依赖动作及粒度，不能把“大分歧”直接等同于“大风险”或“值得修正”。raw动作AUC低于0.5也不能在这一患者上选反向评分并称新发现；这只是提示后续预测收益时需把普通误差头、动作幅度和固定混合作为强对照。它没有证明任意幅度评分都不能用。

## 验证强度与下一步

独立复查重读保存数组/输入哈希，用批量 tile 最小二乘和边界/内部导数检查系数，用不同的像素区间投影重算 pixel oracle，再独立聚合误差。检查86,184个tile和88个策略终点，零错误；tile 最大浮点差6.54e−13、汇总最大差1.73e−18。这是实现正确性，不是第二个临床/患者验证。

本结果允许继续扩大 raw动作的开发可行性，尚不允许启动收益头训练或把当前45病例改作新方法训练/确认。先等待完整任务研究：若没有稳定任务缺口，任务保真训练分支不能只凭该0.118 dB空间启动。即使有缺口，仍需多个开发患者的患者级空间、同观测特征能预测 m、普通误差头/固定混合的同容量/预算对照，以及新的未用于设计的确认来源。旧fastMRI 23人有限增益和本次pipeline失败同时保留。
