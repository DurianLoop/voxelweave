# Original-native T2 task software preflight on the fixed development patient

Use only VS-SEG-001, the already inspected original-paper training subject, and the unchanged cached native T2/RTSTRUCT pair. This patient was used for reconstruction preflight, so its results cannot establish independent clinical or cross-pathology confirmation. Never replace it because of a score. All 46 original segmenter test subjects remain outside this preflight.

Before segmentation, validate source ZIP hashes against the original header index, load the existing TV rasterization and sort images by their physical normal. Construct the native affine from DICOM row/column directions, pixel spacing, first physical plane and 1.5 mm plane spacing; convert LPS to RAS. Apply only axis permutation/flips to RAS for the image and label, with no spatial interpolation. Record original and canonical axis codes and shapes. Independently inspect the first structure of the author's original T2 contour JSON, map every contour to its nearest native physical plane, record maximum plane mismatch, and rasterize only if all errors <=0.001 mm. Compare this planar mask with the RTSTRUCT planar mask, but do not call either a reproduction of SlicerRT's surface-based mask conversion.

Load the official strict CPU segmenter using authenticated unmodified network files and staged MONAI 0.4.0, best checkpoint SHA-256 9105ad78fed0561bb04a82e660eed6083c3d182fc43642bc332f68a272ede0a7. Use exact MONAI NormalizeIntensity defaults on the RAS native image, then Gaussian sliding_window_inference with ROI 384x384x64, sw_batch_size=1 and default 0.25 overlap. The model receives only the image. Select tumor class by argmax, and compute native-volume Dice, predicted and reference voxel counts and confusion counts against the planar TV reference. Retain output segmentation and a normalization/geometry/runtime/hash record. No reconstruction condition, threshold tuning, case selection, uncertainty score or clinical claim is evaluated here.

Require CUDA_VISIBLE_DEVICES=-1, one Torch/inter-op thread, CUDA initialization denied, >=8 GB available RAM and >=15 GB free workspace disk, and lower only this script's own priority. Use existing sources without a new MR download. Keep failures and do not change the author's crop or normalization to obtain a better score. Passing this software preflight permits preparation of a new prospective full-volume task protocol; it does not prove original native baseline reproduction or resolve label-boundary sensitivity.
