# CPU compatibility probe before task-image inference

The official T2 archive and text logs are authenticated and retained. This is a software-only probe; no MRI pixels, lesion masks, reconstruction or task outcomes are inputs. Read the official best_metric_model.pth only with PyTorch weights_only=True and map_location='cpu'. Stage the author's unmodified network source from the fixed Git tree and the official MONAI 0.4.0 wheel under innovation/tools/vs_seg_cpu_compat. Verify the Git blob hashes and PyPI SHA-256. Do not install into or modify the user's MRI environment.

Build the published UNet2d5_spvPA with the parameters in the frozen VSparams.py (one input, two output channels, channels 16/32/48/64/80/96, anisotropic strides/kernels, two residual units, batch norm, dropout 0.1 and attention). Set CUDA_VISIBLE_DEVICES=-1 before importing torch, use one compute/inter-op thread, eval mode and inference_mode. If required, isolated compatibility shims must be logged and must not alter convolution/attention math or checkpoint tensor names/shapes. Require strict state-dict loading. Feed one deterministic synthetic 32x32x8 input, require finite 1x2x32x32x8 logits and repeatability. This proves only basic CPU compatibility, not original baseline reproduction or task validity.

Never execute VS_train.py, VS_inference.py or VSparams.py initialization, which hardcodes cuda:0 and creates mutable results folders. Do not read locked IXI test or touch the active user terminal training. Preserve probe failures and exact commands; success still leaves original-mask conversion, full-size CPU resource feasibility, original-native baseline reproduction and an independently frozen reconstruction-to-segmentation protocol outstanding.

After a successful small-input strict-load probe, permit one synthetic 384x384x64 forward pass with the exact official sliding-window shape, only if the Windows memory-status API reports at least 8 GB available physical memory. Keep the one-thread limit, prohibit CUDA initialization, lower only this probe process's priority, and record runtime and peak resident memory. This single full-window pass does not repeat the small-input determinism check and must not be described as native-image baseline reproduction. If the resource gate fails, retain that failure and prepare later inference without changing the official window to obtain a passing result.
