# 固定 CISS 队列的完整体积 CPU 研究协议

这是新研究的执行协议，写于独立队列的图像解码、重建和任务推断之前。它不把旧 >=100 人、四目标层确认的失败改写为成功。旧结果、001 开发例的全部七条件结果和后续技术检查均继续保存。本协议与程序、来源、标签、权重一起写入 run_contract.json 后才算冻结；本地冻结不是外部预注册。

## 问题与研究范围

唯一主要比较为冻结 IXI HAT 减同处理四锚点 PCHIP。双主要终点分别为患者级支持域 NMSE 与完整体积对原 JSON 标签的 Dice。候选联合方向是两者均下降，即图像误差改善、当前冻结分割器的任务得分降低。开发病例 001 的 HAT Dice 高于该 PCHIP 约 0.00554，未支持任务降低方向；这段反证必须公开。不因 SwinIR 或其他参照出现更合意结果而改变主要比较。

任务模型的作者官方 test 名单固定 46 人，全部来源和两种参考掩膜已经完成非影像像素核验。主名单为其中固定 45 名 ORIGINAL、3D、1.5 mm CISS；VS-SEG-248 的 ORIGINAL 3D TSE 单列为次要个例。名单及顺序从来源索引取得。禁止按肿瘤体积、层跨度、>=64 像素、目标层数、原生 Dice 或技术结果删人。任一技术失败保留在固定分母并记录，45 人全部完成及复查前只能称不完整研究。

这里“独立”指重建器的 IXI 训练来源之外、且属于已认证分割器 test 名单的新任务患者；仍是同一个中心/来源。研究不证明临床伤害、临床治疗决策、跨中心泛化或真实 6 mm 厚层恢复。每四层抽样只把 1.5 mm 层中心间隔增至 6 mm，原层响应/厚度没有因此变成 6 mm。

## 冻结输入与重建

使用原生 DICOM，按其方向法线排序并核对完整 SOP 顺序，逐层应用 RescaleSlope/Intercept，保持 float32 原生网格。标签来自认证原 JSON + 官方 SlicerRT 5.12.4/34645 与已认证原 helper 的转换 attempt 02；同一网格的 RTSTRUCT 标签为敏感性参考。未证明与作者历史 NIfTI 逐字节一致的限制保留。标签和隐藏层真值只用于评价，不进入重建、观测归一化或参数选择。

七条件固定为 native、raw linear、raw local PCHIP、pipeline linear、pipeline local PCHIP、HAT、SwinIR。phase 0 的唯一观测层为 0,4,...,76（TSE 为 0,4,...,36）。恢复全部内部缺失余数 1/2/3；所有重建方法逐位保留观测层。四锚点局部 PCHIP 使用 i-1,i,i+1,i+2，缺外侧锚点时回退到同相邻 linear；raw PCHIP 不裁剪。末观测之后的三个尾层均复制末观测层，不进入图像终点。native 条件使用原完整体积，作为任务能力基线。

pipeline 方法和两冻结模型沿用认证的 prepared/predict：仅观测层估计归一化范围、面内抗混叠缩至 256，缺失层归一化输出裁剪到 [0,1]，再抗混叠恢复原网格并逆归一化。HAT 权重 SHA256 为 2fae831ab933cf260972260ebec4349f3895106ac7b4d1af3ba368f407498eae；SwinIR 为 6a819e47e65bd96c2d6e5b6d3adc212e1a46347080a0a661c602367be8a6f323。

## 图像与任务评价

每目标层支持域为相邻两观测层各自 >1% 最大绝对强度前景的并集，所有方法相同。NMSE 定义为 `(prediction-reference)^2 / observed_range^2` 在支持域内的均值，并非除以参考图像能量。患者主要值为全部内部目标层等权均值；45 人再等权汇总。空支持域属于技术失败。原 JSON 病灶∩支持域、RT 病灶∩支持域同时保存目标等权及像素加权 NMSE，空病灶层为未定义、零像素，不能填成零误差。保存每层分母、SSE、全图 NMSE 及重建数组内容哈希。

任务在原网格 RAS 定向后采用作者 MONAI 全体积 NormalizeIntensity 和已证明逐位等价的 tuple 滑窗。ROI 384×384×64、batch 1、Gaussian 模式；默认 overlap/sigma 沿用官方 0.4 源码。448×448×80 的八窗路径先用零填充的开发例 001 检查，不使用独立病例调整代码。

每个条件保存二值预测、仿射、文件及数组 SHA256，以及 TP/FP/FN、Dice、有符号/绝对相对体积差、漏检、ASSD、MASD、HD95。这里漏检明确指非空参考对应完全空预测，不将低 Dice 冒称无肿瘤检出。主 Dice 为原 JSON 完整体积；不作连通域筛选或预测后处理。

物理边界为 6 邻接腐蚀得到的前景边界体素中心，距离使用实际各轴 mm 间距。ASSD 为两向最短距离向量拼接后的平均；MASD 为两个方向各自均值再等权平均；HD95 为拼接向量的 NumPy linear 95 分位。它们是明确的体素中心实现，没有表面积加权，不能与不同 surfel/边界约定的论文数值直接比较。一方为空：Dice 按非空分母为 0，边界标记为 one_empty_infinite、数值 JSON null；两方为空为 undefined，保留计数。

固定敏感性包括同一预测对 RT 标签重新评分、观测锚点夹住的原轴向范围 [0,last] 重新评分、排除距参考边界体素中心 <=1 mm 的带后重新计算 TP/FP/FN。最后一项是离散网格敏感性，不是精确连续解剖表面不确定性。参考核心为空时 Dice 为 undefined，保留患者及计数。裁剪范围后产生的边界距离也只作为该有限范围的描述。

## 患者统计与判定

全部 45 主病例完成后，等权患者配对 bootstrap 5,000 次，NumPy default_rng seed 20261012，分别给出均值差与双侧 percentile 95% 区间。只有 HAT − pipeline PCHIP 的支持域 NMSE 和原 JSON 完整体积 Dice 的区间上限都 <0，才支持该固定联合方向。交并规则不额外挑选终点；相关性由同一患者配对保留。不从不断增长的子集产生显著性判断，也不在中途调整名单。

HAT/SwinIR 对 raw PCHIP、两种 linear 及 pipeline PCHIP 的全部结果和固定敏感性均公开。次要区间为描述性、未作 familywise 调整，不据此宣布单项显著成功；不把次要比较提升为主要 claim。边界无限/未定义结果按计数与病例记录报告，不以删除后有限均值伪装完整分布。native、绝对体积误差和两种病灶 NMSE 汇总方式共同帮助解释结果。

即使固定双主要方向通过，仍须检查 raw PCHIP 强对照、标签/范围/边界敏感性和效果量，完成实现独立核验，再判断能否提出范围受限的新意。单来源、单冻结分割器和其标注依赖均保留；统计通过不是发表保证。

## 覆盖与后续新方法

旧四目标规则在固定 45 CISS 中的标签级最大覆盖已为 RT 18 人、原 JSON 19 人，这尚未求交图像支持域。后续图像解码后记录真正覆盖及其与体积/层跨度的关系；未看到全队列结果前不宣布筛选造成性能排序反转。相关分析为次要探索，不能修改主要名单。

当前 wavelet/残差路线的 GPU 后续尝试须先以本队列判断是否存在稳定任务缺口。分割损失、任务引导扩散、残差 flow、小波模块和 conformal 误差头均已有先例。拟尝试应区分“修正方向是否有益”与“修正幅度/不确定性较大”，使用同观测强对照，并在另一个未用于设计的验证来源复核；本独立队列一旦评分，不再成为以后新方法的全新未见确认集。

## 执行、续跑与复查

一 CPU worker、Torch/interop 各一线程；隐藏 GPU 并在本进程阻止 CUDA 初始化；仅本进程 below normal priority。运行前及每条件保持磁盘 >=15 GB、可用物理内存 >=8 GB。保持用户当前训练进程和锁定 IXI test 的既有边界。

合同冻结所有程序、协议、认证来源、掩膜、权重和相关项目 Python 依赖的 SHA256。成功条件按 prediction 文件哈希与合同匹配续跑，失败尝试和 traceback 单独保留；不覆盖已成功结果。为控制磁盘，逐条件的重建体积在内存消费后释放，长期保留预测、逐层统计、重建数组哈希及源数据；可按固定程序重新生成重建并核对内容哈希。预测写入与条件成功记录采用临时文件后原子替换。

执行命令：`D:\conda\envs\MRI\python.exe -B innovation\experiments\vs_seg_full_volume_cohort.py`；可用 `--max-patients 1` 按固定顺序完成下一例后干净退出，其他病例保持待完成。正式入队之前需要 development_checks 的物理坐标全对距离/空预测/bootstrap 检查、001 七条件逐位重建等价、一条件分割逐位等价、448 八窗路径均通过。结果复查使用独立 full-grid 距离计算与混淆计数，不重复运行分割器；另外重建内容再生成核验，不把统计自校验说成像素重建独立复现。
