# Source-only gate for the fixed 46-patient task roster

The authenticated published segmenter has 46 test patients (45 CISS and one TSE), none overlapping the stopped 14-case reconstruction attempt. Freeze exactly this roster from split_verification.json before source downloads. This stage reads DICOM headers and original contours and performs CPU label conversion only. It does not decode or score any held-out model prediction, run a reconstruction model on these patients, inspect locked IXI test, or change a training process.

In patient-ID order, retrieve the exact T2 image series from the archived TCIA/NBIA inventory (<=75 MB compressed per case) and the author's original T2-space JSON from the fixed Git tree. Reuse the independently authenticated public T2 RTSTRUCT archives. Preserve transferred file SHA-256, original JSON Git blob and URL, every failure and a per-patient record. One download/qualification worker; retain >=15 GB free and >=8 GB available physical memory. Failed objects remain visible and are not replaced by other patients.

Require the correct patient and mapped series, unique MR SOPs, same image dimensions/orientation/pixel spacing, one frame, a uniform orthogonal native grid, and exact RTSTRUCT references to that T2 frame/SOP list. Do not rasterize or snap the original JSON to native planes. The original JSON and RTSTRUCT's first structure must match by source order/name; no exact-TV filter, minimum lesion pixel count, target count or native Dice filter is permitted. Record all structure names and any unresolved disease semantics.

Record native acquisition type, ORIGINAL/DERIVED flags, sequence description, slice thickness and physical plane spacing with 0.0001 mm tolerance. The native thin-3D CISS main-source qualification requires 3D, ORIGINAL images and thickness/spacing <=1.5 mm + tolerance. Retain the TSE case's source record and label regardless of its resolution; it is a single-case secondary description and cannot support a TSE population result. Eligibility is decided before reconstruction/task scores.

Build reference grids and contour input records with the same authenticated author contour functions, LPS-to-RAS conversion, smooth end capping and official export path validated on development cases 001/182. Convert both original JSON and RTSTRUCT with the matched official standalone PythonSlicer runtime, retaining full reference extent/affine and all first-structure masks. Source masks are solely evaluation references, never inputs to reconstruction or data-driven crops/normalization. Full-volume task and statistical protocol must be frozen after technical/source qualification and before held-out reconstruction task inference.
