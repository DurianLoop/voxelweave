# 旧筛选与完整评价的次要分析准备

本方案写于固定完整体积研究运行中，已见开发例 001 和独立首例 202 的结果，故是后结果的次要探索方案，不是主要问题的新预注册。HAT 减 pipeline PCHIP 的双主要方向、45 CISS 名单、七条件、来源与冻结代码均保持原合同。本方案不读动态子集的效果量，只有整个主队列完成且逐患者输出复查通过后才计算。

## 来源与问题

实际旧规则覆盖已完成 45/45 人，并由不同实现复查。原 JSON 19 人、RTSTRUCT 18 人可提供满足条件的四目标；另外报告旧 literal TV 名称交集（16、15 人），不把它作为本分析默认规则。原 JSON 入选/排除的病灶体积中位数为 5.228/0.701 cm³，阳性层数中位数 15/8。这是本地规则的组成变化，未证明性能排名改变。

来源为 [实际覆盖结果](experiments/vs_seg_full_volume_coverage/attempt_01.json)与[独立复查](experiments/vs_seg_full_volume_coverage/independent_verification.json)。四目标索引来自保存的确定性规则：内部目标余数 1/3，四锚点完整，每层病灶与支持域交集至少 64 像素，两位置取值不得重合。不增加数据解码、模型推断或 GPU 任务。

## 固定次要比较

HAT、SwinIR 各减 raw linear、raw PCHIP、pipeline linear、pipeline PCHIP，全部八对公开。参考掩膜分别用原 JSON、RTSTRUCT，名单资格也各按对应参考掩膜计算，不混用。只使用已经保存的原生网格预测与逐层误差。

图像指标包括支持域、对应病灶域的目标等权和像素加权 NMSE；NMSE 沿用观测范围平方归一化，不改称标准能量 NMSE。完整任务指标为对应标签的完整体积 Dice、观测锚点范围 Dice、绝对相对体积误差。病灶指标无有效目标时保留 null 和分母，不填零。任务指标的资格敏感性是在同一个完整体积预测上改变患者子集，不是截断病灶或另跑四层体积的任务模型。

每个图像比较记录：A 为全 45 人、全部内部缺失目标的患者均值差；B 为旧规则入选者、同一全部目标的均值差；C 为同一入选者、仅旧四目标的均值差；E 为排除者、全部目标的均值差。保留每种指标的有限人数。在全体分母都有效时核验：A = pB + (1-p)E；C-A = (B-A) + (C-B)。这只是精确描述性分解，不是选择偏差的因果归因或新定理。确定性资格使排除者没有被旧评价纳入的机会，不能用简单逆概率加权从旧四目标结果恢复全队列。

任务结果只比较 A、B、E，因为四目标的图像抽样不能产生另一个合法完整体积 Dice。记录点估计方向是否相反，同时明确“点估计方向改变”不等于统计确认的排名反转。不按结果选模型、标签、指标或病灶大小阈值。

## 统计、运行门槛与停止规则

描述性配对患者 bootstrap 5,000 次，seed 20261021。每次从同一 45 人列表有放回抽样，然后在同一抽样内计算全体、入选、排除和旧四目标的均值与差，保留这些量的相关性。样本内没有某个组或有限病例时，该重复值为 undefined，报告有效重复次数；不填成零。每个对比公开两侧 percentile 95% 区间；多指标区间未作 familywise 控制，不能择优改主要结论。

脚本在加载效果数值前要求：队列已 complete、完成分析已写出、合同 SHA256 与现有冻结值匹配、coverage 与独立 proof 的哈希链匹配、45 人的七条件均成功、每人的独立 proof 明确重建已再生成且无错误、其预测文件哈希与所有条件一致。任何条件缺失，写门槛结果但不计算统计。冻结的推断/复查程序不会为此修改。

验证程序使用有明确答案的模拟队列检查：一个预设患者组成导致方向改变的例子、所有患者同效应无方向改变的例子、空病灶 null、四目标子集、缺病例时拒绝，以及不同的逐抽样循环复查 bootstrap 区间。软件检验通过不能当作真实患者结果。

实际运行：`D:\conda\envs\MRI\python.exe -B innovation\experiments\vs_seg_selection_sensitivity.py`。当前长队列未完成时只写未满足门槛，不执行推断或读取病例效果量。模拟检查：`D:\conda\envs\MRI\python.exe -B innovation\experiments\verify_vs_seg_selection_sensitivity.py`。

如患者组成和四目标改变均无稳健方向/效果量变化，保留负结果，不包装为评价体系创新。即使有变化，也只支持本来源、固定模型与本旧规则的次要描述；要形成新评价方法贡献，还需要另一来源或预先锁定的新规则验证。
