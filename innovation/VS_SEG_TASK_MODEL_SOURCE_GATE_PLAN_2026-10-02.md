# VS-SEG task endpoint: source gate before reconstruction or segmentation scoring

The active objective is an independently verified publishable MRI claim. The preceding exact-TV experiment was stopped after 14 attempts and one completed patient. Its >=100-completer gate is unreachable: an independent RTSTRUCT-only relaxation across all 242 mapped patients gives an upper bound of 96. Do not lower that gate or retrospectively call the experiment positive. A label-name mapping and floating-point geometry repair are justified implementation changes but cannot repair the sample-size contract.

Before selecting a new endpoint, inspect only metadata and released code for the official pretrained T2 vestibular-schwannoma segmenter linked by KCL-BMEIS/VS_Seg, Zenodo DOI 10.5281/zenodo.6323472. Freeze author source files at the already archived Git tree 33410a2d44e3f57b4df1c3ed005e6d40c0824aa6; verify each downloaded Git blob. Archive the model release metadata, license, archive sizes, training/validation/test split, architecture, preprocessing, inference device and any use of a ground-truth-derived crop. No model weights, MR images, or task scores are read in this gate.

Questions to resolve: Does the release provide the T2 checkpoint without retraining? Is its checkpoint-associated patient split identifiable? Which of the 46 paper test cases occur in the current 242/241 public inventory? Does inference use labels only for evaluation, or also to select a spatial crop? Can a CPU-only isolated runner reproduce the original T2 test endpoint without importing CUDA? Does the original mask conversion interpolate surfaces across planes, making a planar RTSTRUCT rasterization an insufficient reference?

The outcome of this gate is a feasibility record and a precise next protocol, not clinical evidence. Any later experiment must expose all prior reconstruction observations, use original segmenter-held-out subjects for its primary endpoint, keep acquired anchors identical, compare raw and model-pipeline analytic baselines, reconstruct complete missing-plane volumes without target or mask inputs, and preserve smaller lesions rather than selecting only cases with four large missing-lesion planes. An all-target patient mean or full-volume segmentation endpoint changes the original estimand and must be described as a new study. Sample-size and detectable-effect criteria must be set before its scores, without tuning on the observed HAT/SwinIR direction.

User resource limits persist: no interaction with current terminal training, no GPU allocation, no locked IXI test. Metadata downloads are bounded and stored inside innovation; existing source artifacts are reused. Every failure remains visible. The active goal remains incomplete until source, independent endpoint, prior art and reproduction requirements actually pass.
