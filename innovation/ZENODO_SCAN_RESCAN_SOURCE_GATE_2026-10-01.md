# Zenodo 8234101 scan-rescan source: metadata lead, license gate failed

Official [Zenodo record 8234101](https://zenodo.org/records/8234101) and [API record](https://zenodo.org/api/records/8234101), checked 2026-10-01, describe *Whole-Brain 3D MRF and MRI Multi-Scanner, Scan-Rescan Dataset at 3T*, DOI `10.5281/zenodo.8234101`. The release says five de-identified healthy subjects were scanned on three 3T scanners twice each (30 acquisitions); each acquisition includes MRF T1/T2/ADC maps, T1w MPRAGE, T2w SPACE and T2w FLAIR. It links to a 3.8 GB image ZIP plus a license PDF and acquisition-parameter PDF. These are publisher metadata claims; no image ZIP or pixels were downloaded or verified. Five subjects and scanner changes would be weak for a broad patient-level confirmation even if access were granted.

The API reports license ID `other-open`, but the record's [LICENSE.pdf](https://zenodo.org/api/records/8234101/files/LICENSE.pdf/content) contains a restrictive CWRU end-user agreement. Its §1 limits use to noncommercial academic/research activity at nonprofit academic institutions; §3 requires prior written consent for copying, modifying, showing to third parties or distributing the Software and Data. The license PDF fetched for this audit had SHA-256 `1d0c9efb647e8ff5c2f09dd94661da97896dca30950172facf5696951450ac59`; the API provided MD5 `d674fe8ef14eb2c27728f75d4856696c`. The small PDFs were not incorporated into the project paper archive or used as data. A generic `other-open` tag cannot override the accompanying terms.

**Decision:** do not download or analyze the image ZIP, create patient targets, or include this cohort in the public-source manuscript under the present evidence. If the real authors/institution obtain appropriate written permission and approve its scope, first verify scan-level timing, 3D SPACE/FLAIR geometry and whether independently repeated observations can actually be aligned to one fixed target before freezing a pixel experiment. A permission email or a dataset title alone would not prove exact matching planes or acquisition-identity causality. This lead is retained only to avoid rediscovering it as apparently unrestricted public data.
