# Bounded OpenAlex first-page screen: low sensitivity, no priority inference

The [frozen query plan](2026-10-01_context_overlap_openalex_plan.md) was executed once on 2026-10-01. Four searches returned 25 records each and 96 unique OpenAlex work IDs in the [raw responses and parsed index](search_snapshots/openalex_context_overlap_2026-10-01/index.json). The archive retains query URLs, result counts, raw JSON SHA-256, title, DOI, year, primary source and any available abstract. All 96 titles were screened; this was not full-text review of 96 articles.

**The index was not a useful direct-collision search.** Its default ranking emphasized highly cited, old and often unrelated records (particle physics, astronomy, segmentation and generic reviews). Returned years spanned 1997--2025, with no 2026 item among the first pages despite known relevant 2026 preprints in this archive. Therefore the absence of an exact same-target published-slice context audit in these 96 records provides essentially no positive evidence of priority. A venue-specific or field-filtered search is still needed before submission.

Two records reinforce boundaries already in the manuscript:

- *Uncertainty modelling in deep learning for safer neuroimage enhancement: Demonstration in diffusion MRI*, NeuroImage 2020, DOI `10.1016/j.neuroimage.2020.117366`. The OpenAlex abstract reports heteroscedastic and approximate-Bayesian uncertainty for diffusion-MRI super-resolution, correlation with reconstruction errors and subject-/voxel-level risk assessment. Europe PMC indexed it as PMID 33039617 but not open access in that endpoint; **abstract only was checked here**, not its full text or numerical claims. It further rules out broad novelty language about MRI uncertainty-based failure detection.
- *On Hallucinations in Tomographic Image Reconstruction*, IEEE TMI 2021, DOI `10.1109/TMI.2021.3077857`. The indexed abstract proposes generalized measurement/null-component decomposition and a hallucination map in a stylized tomographic simulation. This is a conceptual predecessor to measurement-versus-prior audits, but the abstract does not establish that it tested this project's two-model, same-target published-slice context switch. **Abstract only was checked here.**

Neither abstract should be treated as an experimental baseline defeated by MIRA. The already archived [Hu MRI full-text audit](2026-09-30_hu_mira_overlap.md), [Guo uncertainty full-text audit](2026-09-30_mira_uncertainty_neighbours.md) and [Lee/Choi-Bhutto MRI full-text check](2026-10-01_shared_context_neighbours_fulltext.md) remain stronger evidence for the current narrow language. The new search mainly establishes that generic OpenAlex text ranking is inadequate for a final novelty certification.
