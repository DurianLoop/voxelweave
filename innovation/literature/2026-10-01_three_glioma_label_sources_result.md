Task: independent, same-grid lesion-region evidence for single-T2 x4 missing-slice reconstruction. Full texts are archived in [`source_cache/three_glioma_descriptors_2026-10-01`](source_cache/three_glioma_descriptors_2026-10-01/index.json). This is a targeted source audit, not a systematic literature review or a novelty certificate. No GPU or locked IXI test was used.

## OpenNeuro official-source gate

The [bounded metadata probe](source_cache/ds007045_metadata_2026-10-01/index.json) obtained a DataCite record for v1.0.1 (HTTP 200), an OpenNeuro GraphQL dataset ID and latest snapshot `2.0.1` (HTTP 200), and a public S3 file listing. The generic OpenNeuro page HTML alone is only a shell and proves no file inventory; GitHub API was rate-limited, so the S3 listing is the file-level evidence. DataCite's v1.0.1 `rightsList` is empty; it does not establish that version's license.

The [current S3 metadata and one-case inventory](source_cache/ds007045_pair_inventory_2026-10-01/index.json) show `dataset_description.json` with `DatasetDOI=...v2.0.1` and `License=CC0`; the README states 363 patients and acquisition dates 2018-2025. `CHANGES` states v2.0.0 grew 337 to 363, added Karlsruhe cases, removed one no-tumor case and several duplicates, and replaced a duplicated file. The paper's cohort paragraph instead states April 2024-November 2025 for 337. These statements cannot be silently reconciled; the current S3 content is only identified as v2.0.1, and exact v1.0.1 file membership has not been audited. In particular, the v1 duplicate correction prevents an unqualified independence claim.

A [complete current-key inventory](source_cache/ds007045_current_pair_audit_2026-10-01/result.json) used three bounded S3 list pages, with no image bytes. It finds 1,452 processing files and 363 segmentation files, yielding exactly 363 distinct processed T2/mask subject pairs, zero unmatched or duplicate keys. Site counts (BA 3, BO 171, FO 8, JS 11, KA 110, ME 7, NSK 39, TO 14) match the current README. This is file-name completeness, not 363 proven same-affine/valid masks or a patient-level independence audit.

The frozen [two-header protocol](../DS007045_TWO_HEADER_PROTOCOL_2026-10-01.md) selected `sub-BA2`. Its parser completed the range reads but [failed while serializing NumPy values](../DS007045_BA2_HEADER_ATTEMPT_FAILURE_2026-10-01.md); BA2 was not repeated. The preselected follow-up `sub-BA3` [passed](../DS007045_BA3_TWO_HEADER_RESULT_2026-10-01.json): processed T2 and tumor mask are both `182 x 218 x 182`, 1-mm spacing, with identical best affines (maximum absolute difference 0 mm). This establishes one same-grid pair, not voxel-level label quality or cohort-wide compatibility.

The frozen [single-case CPU pilot](../DS007045_SINGLE_CASE_CPU_PILOT_PROTOCOL_2026-10-01.md) downloaded only that pair and [recorded](../DS007045_BA3_CPU_PILOT_RESULT_2026-10-01.json) matching header-prefix hashes and whole-object SHA-256. The mask contains labels 0/1/2/3. At x4 phase 0, 135 missing targets include 51 lesion-bearing slices; linear interpolation yielded normalized MAE 0.00650 in 76,130 labeled tumor voxels and 0.01817 in 1,138,278 non-tumor brain voxels. Those regions differ anatomically and in texture; this one-case contrast is **not** evidence of lower clinical risk in tumor, a model comparison, a task endpoint, or an independent-acquisition effect. It demonstrates only that the proposed ROI accounting is technically feasible on the current processed grid.

## Decision and falsifier

The most concrete new experiment is an **independent processed-grid replication of the existing global-versus-lesion error sign discordance**, using a fixed IXI model pair and a strictly equal-observation linear comparator. The existing MSD analysis already found many patients with global error advantage and tumor-region deficit; this dataset could test whether that pattern persists outside MSD. An earlier MRI interpolation/segmentation paper (Verschuur et al. 2022) and fixed-input pathology-fidelity/segmentation uncertainty work prevent a broad first-clinical-impact claim. This would remain an empirical replication, not a new reconstruction method.

Before target pixels of a confirmatory cohort: choose exactly v2.0.1 or recover pinned v1.0.1; freeze patient list, exclusions, x4 axis/phase, intensity and resize pipeline, labels/brain masks, endpoints (patient-level tumor and whole-brain MSE differences, sign-discordance rate, linear baseline), uncertainty intervals and a stop rule. Check patient/source overlap against IXI/MSD/BraTS at available identity resolution, report unresolved linkage, and do not call the MNI-resampled target native thin-slice truth. A multi-patient result that fails the sign-discordance hypothesis or loses the effect against an equal-processing linear comparator falsifies this route. The pilot's lower mean tumor MAE also argues against assuming that a raw lesion-versus-background error excess will emerge.

Current publication status remains **not ready**: Kuestner 2024 full methods, independent clinical replication, weight redistribution rights, clean environment reproduction, and author/venue review are still open.
