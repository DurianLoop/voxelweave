# 固定动作收益与无真值风险估计：有界补查方案

承接已见001的固定动作oracle和仍运行的45例队列。本阶段不读取队列的动态分数，不改变335文件合同，不启动GPU或第二模型队列。科学目标仍active，尚没有可发表且独立验证的claim。

冻结四个Europe PMC标题/摘要查询，时间截至2026-10-02，每条最多15个core记录：

1. MRI / magnetic resonance + Stein / SURE / ENSURE。
2. ensemble Stein unbiased risk。
3. correlated noisy images + risk / Stein。
4. MRI reconstruction + risk estimation / model selection。

目的不是补齐所有UQ，而是核对：SURE/GSURE/ENSURE测哪个风险、如何处理同测量导致的相关性、能否给出单个固定缺层患者的修正收益。标题/摘要筛查与正文核读分别计数；仅取得HTTP200不能计正文。最多优先获取三篇直接方法近邻的公开正文，保留原响应、URL、UTC时间、SHA256和失败路径，不使用凭证或绕过访问限制。

正文核读项目：观测operator与噪声；完整/投影/加权风险；随机采样或同患者重复测量条件；训练和评估人员单位；用途是训练、模型选择还是逐患者certificate；是否真正比较固定动作相对基底的风险差。零结果/访问失败不证明没有相关论文。

若正文提供明确可计算的假设差异，允许仅用合成向量做CPU代数审计，预写条件/反例并公开全部结果。这类审计只检验已有数学与实施假设，不作为新MRI方法、真实患者验证或理论首创。实际001/45病例上不存在的噪声、随机mask或重复观测不能用合成实验补造。
