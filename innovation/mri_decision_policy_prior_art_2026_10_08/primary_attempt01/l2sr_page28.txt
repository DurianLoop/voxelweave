Appendix C. Implementation Details
In this section, We will show the implementation details of all methods. In
section Appendix C.1, we show the basic settings of all algorithms. In
section Appendix C.2, we show the implementation details of L2S and L2SR. In
section Appendix C.3, we show the implementation details of competing methods.
Appendix C.1. Basic Settings
Both our methods and competing methods, are performed with the same basic settings.
SSIM V alues. SSIM hyperparameters are kept to their original values in [38].
The dynamic range is set to the maximum pixel value of the ground truth volume.
Loss F unction. Since we leverage the SSIM value as the similarity metric, for
consistency, all algorithms use negative SSIM values as the loss.
Appendix C.2. Our Methods
Pre-training the reconstructor is the same as the competing method ‘Random’, as
detailed in the following subsection. We implement the A2C algorithm based on the
stable-baselines3 [42] which is a popular framework for reliable implementations of RL
algorithms. The learning rate is set to 0.0003, the update timestep is set to T , and
the other hyperparameters are to the default values. The reconstructor is trained by
Adam optimizer for 10 epochs in the alternating training stage. The learning rate for
both θπ and θR decays at a rate of 3 at each alternate training. We refer you to our
official code for more details.
