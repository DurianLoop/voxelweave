3.9 Training data
Hypotheses (exploratory). If the healthy training data
were a neutral background to a comparison of methods,
giving every method the same alternative training set
should leave the contrasts between methods unchanged.
And if a training set could be chosen per method from
validation data, the choice should be stable under resam￾pling of the 24 validation subjects.
Holding the evaluation fixed and giving all four meth￾ods the same alternative training set reversed a signifi￾cant contrast (Fig. 13a). REFLECT − UCCD Dice was
−0.042 [−0.060, −0.025] with all methods trained on IXI￾HH+Guys and +0.100 [0.079, 0.121] with all trained on
MOOD+IXI, both pH < 0.005. The method × training￾set interaction carried 0.115 of Dice variance across the
five training sets, and the four-method order differed
from the IXI-HH+Guys order in 50% to 92% of defen￾sible universes, depending on the comparison set. The
MOOD+IXI comparison needs a caveat: it adds T1 data
for every method, and cDDPM’s MOOD+IXI training set
was 72% T1, so it compares the same sources with multi￾contrast training. The comparison on IXI-HH+Guys is
the clean one.
Choosing a training set per method on 24 validation
subjects was itself unstable (Fig. 13b). The primary se￾lection rule (median validation slice Dice) chose IXI￾HH+Guys for REFLECT in only 36.8% of 104 bootstrap
resamples (MOOD+IXI 37.9%, MOOD+IXI-HH 22.8%),
at a test regret of 0.055 Dice. Across resamples each rule
produced between 27 and 137 distinct joint choices for the
four methods, and the most frequent joint choice never
exceeded 37.5%. Both hypotheses are therefore rejected,
which is the empirical case for fixing a common train￾ing set by design, as we did. H1 and H2 held with every
common training set (Appendix E). All twenty method–
training-set combinations and the verdicts of the hypothe￾ses with each set of training data are in Appendix E.
3.10 Latent aggregation for REFLECT
Hypothesis. REFLECT’s four latent channels need not
agree on where an anomaly lies, and its published map
averages them. If their disagreement carries signal, ag￾gregating the channels by it should sharpen the map and
raise Dice at equal burden. The median absolute deviation
across channels (MAD) is retained as the recommended
aggregation only if its interval does not overlap that of
the best other aggregation.
